# 构建器：build.py

把一份按格式写好的 Markdown 早报，变成**一个能看、也能逐条听的单文件 HTML**。

## 依赖

```bash
pip install edge-tts        # 仅语音版需要；缺失会自动降级成无语音网页
```

Python 3.8+，纯标准库 + edge-tts，无需 ffmpeg。

## 用法

```bash
# 图文 + 内嵌语音（默认）
python scripts/build.py <早报.md>

# 纯图文，跳过语音（快，小）
python scripts/build.py <早报.md> --no-audio

# 语音改外链（不内嵌；体积小，但换环境会丢音频）
python scripts/build.py <早报.md> --no-embed

# 换音色 / 语速
python scripts/build.py <早报.md> --voice zh-CN-YunxiNeural --rate +15%
```

## 产出

| 文件 | 说明 |
|---|---|
| `<同名>.html` | **唯一交付物**。默认音频已 base64 内嵌，自包含单文件，拿到哪都能播 |
| `<同名>.audio/NN.mp3` | 分段语音缓存。重建时复用，**别删**；换音色才需要先删 |
| `<同名>.mp3` | 全篇合集（拼接），附赠，方便整份带走听 |

## 内嵌 vs 外链

**默认内嵌，这是刻意的选择。**

外链模式下 `<audio>` 走相对路径指向 `.audio/` 目录，一旦把 html 单独搬到手机、小程序或任何没带上目录的地方，**音频全部失效**。
内嵌后 html 自包含，走到哪都能播——代价是单文件 5–10 MB。

> **体积只能靠文案变短来压。** 音频固定 24kHz/48kbps，本脚本不重编码。
> 每条砍掉一半文字，文件就能瘦一半——文风精简和文件变小是同一件事。

## 数据流

```
Markdown ──parse()──> 结构化条目
                        │
                        ├─ flatten() 给每条编全局序号
                        ├─ item_speech() 洗成朗读稿 ──> edge-tts 逐条合成
                        └─ render() 组装 HTML（卡片 + 播放器 + 内嵌音频）
```

## 页面形态

- 顶部**播放列表控制器**：曲目名、上/下条、进度条、倍速（1×/1.25×/1.5×/2×）、连播开关
- **每张卡片有自己的播放按钮**，播完自动接下一条
- 每个领域标题右侧有「▶ 本节」，只播这一组
- 响应式，手机上单栏显示

音频是**分段拼接**的，不是一整段。所以可以"只听某一条""只听某一节"。

## 换音色

`--voice` 传 edge-tts 支持的任何音色。常见中文音色：

| 音色 | 风格 |
|---|---|
| `zh-CN-XiaoyiNeural` | 女声，默认，清脆 |
| `zh-CN-YunxiNeural` | 男声，沉稳 |
| `zh-CN-XiaoxiaoNeural` | 女声，温柔 |
| `zh-CN-YunyangNeural` | 男声，播音腔 |

> 换音色**必须先删掉 `.audio/` 目录**，否则会复用旧语音。

## 故障排查

| 现象 | 处理 |
|---|---|
| 某条没声音 | 脚本会自动重试 3 次；仍失败只影响那一条，**别重跑整份** |
| 模块找不到 edge_tts | 自动降级为无语音网页，不报错退出 |
| 单文件偏大（>14 MB） | stderr 会提醒。把文案写短，别无他法 |
| 想重建但不想重新合成 | 直接重跑，已存在的分段 mp3 会复用 |
