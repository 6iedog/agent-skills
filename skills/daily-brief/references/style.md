# 文风：早餐桌上的语气

这份文档是 `daily-brief` 的**灵魂**。早报好不好，九成看文风，一成看选题。

## 唯一目标

**一耳朵听懂。** 读者可能刚醒、在刷牙、在地铁上，只有一只手和半个脑子给你。
任何需要"再听一遍"才能懂的句子，都是失败的句子。

判断标准不是"写得专业不专业"，而是**"念出来顺不顺、听懂要几秒"**。

## 七条铁律

### 1. 说人话，像在微信里跟朋友聊

✅ 允许：这玩意儿、听着玄、一记闷棍、说白了、有点意思、别忘了、说白了就是
❌ 禁止：赋能、闭环、助力、标志着、彰显、进一步、持续推动、深度赋能、生态位

> 「标志着 XX 进入新阶段」→「XX 换了个活法」

### 2. 短是硬指标

| 部位 | 上限 |
|---|---|
| 标题 | ≤ 20 字，一句话，不套定语 |
| 正文 | 80–150 字 |
| 为什么值得看 | ≤ 60 字，最多两句 |
| 导语 | 一句半 |

超过三句就该砍。砍掉不影响理解的：机构全名、职位全称、型号后缀、发布地。

### 3. 一条最多留一个数字

除非这个数字**本身就是新闻点**，否则不列数据。

| ❌ | ✅ |
|---|---|
| 涨 4.06%、跌 2.36%、涨 1.92%，存储板块分化 | 存储板块一家反弹，一家继续跌 |
| 运行成本较上代降低约 75% | 便宜四分之三 ← 数字就是新闻点，留 |

### 4. 抽象概念必须用比喻落地 ★

**这是本技能的招牌。** 遇到技术概念、机制、因果，先想"这东西像生活里的什么"。

| ❌ 原样搬运 | ✅ 打个比方 |
|---|---|
| 微软发布 MXC，一个策略驱动的执行隔离层，组织可定义 Agent 的文件与网络访问边界 | 微软给 AI Agent 造了个笼子：管理员能规定它只准碰哪些文件、只准连哪些网 |
| 攻击者通过 CA 的域名控制权校验，签出未授权证书 | 小偷没撬锁，先改了门牌号——CA 照着新门牌核对，把"写着你家名字"的钥匙签给了小偷 |
| Haiku 5.5 成本降 75%，首次支持可调 effort 参数 | 最便宜的那款 Claude 又降价了，便宜四分之三。以前只能干杂活，现在能接正经活——像实习生突然考出了从业资格 |

比喻要**贴切**，不能为了俏皮牺牲准确。宁可朴素（"像给门加把锁"），不要花哨（"如同在数字巴别塔上镌刻符文"）。

### 5. 标题一句话，不套定语

| ❌ | ✅ |
|---|---|
| Anthropic 发布 Claude Haiku 5.5：运行成本降 75%，小模型第一次能调推理强度 | 最便宜的 Claude 降价四分之三，还能干正经活了 |

### 6. 导语像开场白

点出今天的**味道**，不复述内容。一句半，可以带点情绪。

> 「今天是假期结束的第一天——A股开门，美联储的纪要也刚好在同一分钟砸下来。」

### 7. 允许有态度，但每句得带信息

觉得妙就说妙，无聊就说无聊，是坑就直说。但"这个挺有意思"后面必须给出**为什么有意思**，不能只有情绪。

## 自检清单（写完每条过一遍）

- [ ] 数一遍字数，超标了吗？
- [ ] 数字留了一个还是三个？多于一个就砍
- [ ] 标题能不能再短一半？

## 反面教材（真实改前改后）

**改前**（专业腔，96 字概念堆砌）：
> 微软在 Windows & Surface 活动上宣布 Microsoft Execution Containers 正式 GA。这是一个策略驱动的隔离层，由组织定义 Agent 的文件系统与网络访问边界，并在执行时强制生效，同时提供资源访问审计报告以支撑最小权限策略。

**改后**（口语 + 比喻，71 字）：
> 微软给 AI Agent 造了个笼子：管理员能规定它只准碰哪些文件、只准连哪些网，跑完还给你一份"它想碰什么"的报告。头一回，给 AI 上锁成了操作系统自带的活。

差别不在信息量（改后甚至更全），在**入口**：改前要读者先懂"策略驱动的隔离层"，改后谁都能立刻懂。
