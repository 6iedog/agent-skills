# 交互习惯基线（通用）

**定位**：这是**团队规范缺失时的起草素材**。效果最关键的一份内容，是**团队自己的规范 / 踩坑记录**——用户一旦提供，**优先采用并替换本节**。

下面是主流组件库（antd 一类）通行的通用惯例，作为起点，不是终稿。写成项目提示词时要**换成项目自己的措辞与场景**。

## 危险 / 破坏性操作

- 二次确认：弹确认框，破坏按钮用危险色、放在右侧（主操作位）；默认焦点**不落在危险按钮**上。
- 说明后果：文案说清「删了什么、能不能恢复」。
- 批量删除给出数量；不可逆操作要点名对象。

## 加载态

- 结构已知（表格 / 列表）用**骨架屏**；长度不确定用 spinner。
- 短于约 200ms 不显示 loading，避免闪烁。
- 提交类按钮 loading 时**禁用**，防重复提交。

## 空 / 错误 / 无权限

- 三种分开：「无数据」「无结果（筛选后）」「无权限」文案与引导不同。
- 空状态给**一句说明 + 一个主引导操作**，别只放个图标。
- 错误就近提示、可恢复；表单错误定位到具体字段。

## 反馈

- 轻操作结果用 toast；需要用户决策的用弹层。
- 长任务可取消 / 可看进度，不能静默卡住。

## 弹层关闭

- 非强制弹层：点遮罩、ESC 可关。
- 有未保存内容时关闭 → 二次确认。
- **强制弹层必须有明确理由**，并给出退出说明。

## 状态语义

- `disabled` 与 `readonly` **分别定义**：disabled 不可交互、不进表单值；readonly 可读可聚焦、值照常提交。
- 覆盖全：default / hover / focus-visible / active / disabled / readonly / loading / error。

## 键盘与无障碍

- 所有可交互元素键盘可达；focus-visible 可见（禁止无替代的 `outline: none`）。
- Enter / Space 激活；Esc 关闭弹层；列表类方向键移动。
- 图标按钮必须有可访问名称（`aria-label` 等）。

## 移动端（PC 优先也要预留）

- 触摸目标 ≥ 44×44；用 tap 触发，不依赖 hover。
- 弹层倾向底部弹层 / 全屏，不照搬 PC 居中弹窗。
- 下拉 / 悬浮受限时改用底部选择器。
