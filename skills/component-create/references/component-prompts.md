# 组件描述提示词骨架

生成组件时套用对应类型的骨架。**七段缺一不可**，尤其第 4 段（状态全枚举）和第 6 段（Do & Don't）——前者是最常漏的部分，后者是规范落地的关键。

生成前必须已加载：`interaction-ux.md` + 项目 `.ui-kit/tokens.json`。

---

## 通用骨架

```markdown
## 1. 角色定义
<这个组件在产品中承担什么职责>  
**职责边界**：<它不负责什么，什么时候该用别的组件>  
**使用场景**：<列举 2-3 个真实场景>

## 2. 使用流程
用户视角的完整流程，按时间顺序：
1. <用户看到什么>
2. <用户做什么>
3. <系统如何响应>
4. <用户如何知道成功了>
...
**异常路径**：加载中 / 出错 / 空 / 无权限 分别怎么表现

## 3. Props 契约
| 名称 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
...（必须显式写出默认值来源：tokens 中的哪个值）

**变体体系**：<variant / size 有哪些档位，取自 tokens>
**可组合性**：<是否支持 compound components，暴露哪些子组件>

## 4. 状态全枚举 ★
逐条写明视觉与行为，不可省略：
| 状态 | 触发条件 | 视觉表现 | 行为 | 交互限制 |
|---|---|---|---|---|
| default | | | | |
| hover | | | | |
| focus | | | | |
| active | | | | |
| selected | | | | |
| disabled | | | | 原因说明？ |
| readonly | | | | 与 disabled 的区别 |
| loading | | | | 是否阻塞交互 |
| error | | | | 文案口径 |
| empty | | | | 首次空 vs 筛选后空 |

**disabled 与 readonly 必须分别定义**，不可合并。

## 5. 键盘与无障碍
- Tab 顺序：...
- 快捷键：...
- 焦点管理：打开时焦点去哪、关闭时回哪
- ARIA：role / aria-* / label 关联
- 触屏与键盘的差异处理

## 6. Do & Don't ★
从 `interaction-ux.md` 提取本组件适用的条目，逐条落到实现：
- **Do**：<条目> → <本组件如何满足>
- **Don't**：<条目> → <本组件如何避免>
- **本组件明确不适用**：<条目> → <原因>

## 7. 可扩展插槽
- 需要预留哪些变体轴（variant / size / state）
- 哪些子节点可替换（prefix / suffix / 空状态 / 加载态）
- 扩展时的约束：<哪些不应被扩展>
```

## 类型专用补充段

按组件类型追加到第 3 段之后。

### 选择类（Select / Radio / Checkbox / TreeSelect / Cascader）

```markdown
**数据契约**：<数据来源、规模量级、是否远程搜索>
**选择模型**：<单选 / 多选 / 自由输入 / 范围>
**多选上限**：<N 或无限制；无限制时的收纳策略 maxTagCount>
**选项渲染**：<optionRender 场景；label 与 value 不一致时的处理>
**搜索行为**：<本地过滤 or 远程搜索；optionFilterProp 用哪个字段；防抖与请求时序>
**弹层**：<placement / 挂载节点 getPopupContainer / 宽度策略 / 虚拟滚动>
**孤儿值**：<选中值不在选项中时的兜底渲染>
**联动**：<与其他组件的联动关系与数据流方向>
```

**反模式**：能滚不分页用 Select 装上千条；用 `mode="tags"` 硬凑 AutoComplete。

### 输入类（Input / InputNumber / DatePicker / TextArea）

```markdown
**输入约束**：<长度、数值范围、格式；约束在输入时生效还是失焦时>
**校验时机**：<失焦 / 实时 / 提交；与项目表单策略对齐>
**错误呈现**：<位置、文案口径、是否可复制>
**格式化**：<展示格式与取值格式是否不同>
**粘贴处理**：<粘贴非法内容如何处理>
**输入法**：<中文输入法组合态是否触发校验>
**字数统计**：<是否需要；超限如何反馈>
```

**反模式**：输入过程中就报错打断用户；中文输入法拼音态触发校验。

### 反馈类（Modal / Drawer / Popconfirm / Alert / Result）

```markdown
**层级**：<第几层弹层；嵌套上限>
**关闭方式**：<X 按钮 / ESC / 遮罩 —— 逐项写明，并说明与其他弹层是否一致>
**焦点管理**：<打开时焦点目标、关闭时焦点回归、焦点陷阱>
**确认语义**：<确认按钮文案（动词，非「确定」）、危险色、后果描述>
**内容约束**：<内容最大长度、超长如何处理>
**加载与失败**：<提交中状态、失败时弹层是否保留>
```

**反模式**：Modal 里放表单（用户不理解为什么要确认）；用 Modal 承载成功提示；遮罩可关与不可关混用。

### 布局类（Card / Collapse / Splitter / Layout）

```markdown
**尺寸约束**：<最小宽度、推荐宽度、响应式断点>
**内容适配**：<内容超长时截断 / 换行 / 滚动>
**折叠行为**：<折叠时状态是否保持、是否记忆>
**分隔可调**：<Splitter 的最小/最大、是否持久化、双击复位>
**嵌套规则**：<允许嵌套的层级上限>
```

### 数据展示类（Table / List / Descriptions / Timeline）

```markdown
**分页策略**：<分页 / 虚拟滚动 / 无限加载；选择理由>
**列优先级**：<窄屏时哪些列折叠、哪些进详情>
**空状态**：<四态区分：首次空 / 筛选后空 / 加载中 / 无权限>
**批量操作**：<选择方式、影响条数提示、二次确认文案>
**操作列**：<数量上限、折叠策略、危险操作位置>
**排序筛选**：<是否反映到 URL、是否可分享回退>
```

## 生成后的自检

产出组件代码前，逐条确认：

- [ ] 七段全部覆盖，无一段被合并或省略
- [ ] 状态表 12 行齐全，disabled 与 readonly 分别定义
- [ ] 所有尺寸/圆角/间距/色值标注了 tokens 来源，**无硬编码**
- [ ] Do & Don't 至少覆盖 3 条适用规范
- [ ] 明确列出了不适用的规范条目及原因
- [ ] 类型专用段已按组件类型补齐
- [ ] Props 表的默认值全部写实，未用「—」或「视情况」
- [ ] 键盘路径完整，焦点管理明确
