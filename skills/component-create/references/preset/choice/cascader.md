# 级联选择

**逐级收窄**：选了上一级，下一级候选才确定（省 → 市 → 区），最终按一条**路径**定位结果。

## 角色与边界

- **是什么**：列式面板，每一列对应一层，列随选择逐级展开。
- **解决什么**：选项有**明确的父子层级**，且通常按「路径」选一个结果。
- **不解决什么**：
  - 无层级 → 单选下拉 / 多选下拉
  - 层级 + 需**跨层级多选** → 树选择
  - 只是把选项分组展示（无联动） → 分组的单选下拉即可
- **什么时候不用**：层级只有一层却硬套 → 多一次无意义点击；数据是「标签式多选」而非父子 → 树选择 / 多选下拉。

## UI

### 结构解剖
- **触发器**：一行，显示已选**路径**（面包屑式标签）或占位符，右侧下拉箭头
- **路径回显**：如「浙江省 / 杭州市 / 西湖区」，可整段显示或用带分隔的标签
- **列面板**：浮层内多列并列，每列一层
- **选项行**：文本 + 右向箭头（有下级时）+ 勾选标记（可选时）
- **搜索框**：可搜索时固定在面板顶部
- **面包屑 / 头部**：多选或深层时可显示当前已选层级
- **加载 / 空 / 错误位**：按列独立显示（懒加载）
- **清空按钮**：有选中值时出现

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响触发器高度、列宽、项行高
- 列数：随选择动态增减；每列独立滚动
- 状态类：默认 / 错误 / 警告 / 禁用 / 只读
- 变体：单选 / 多选（每级多选）/ 可搜索 / 可清空 / 异步懒加载

### 视觉状态
| 状态 | 触发器 | 面板 / 选项 |
|---|---|---|
| default | 边框默认、占位符浅色 | 仅第一列 |
| hover | 边框加深 | 悬停项背景微亮；hover 展开模式下加载下级列 |
| focus-visible | 焦点环 | — |
| open | 边框高亮 + 箭头翻转 | 面板出现，定位到已选路径 |
| selected（末级） | 显示完整路径 | 该行高亮 + 勾选 |
| active（在途，已选非末级） | 可显示在途路径 | 该行高亮，右侧列为其子级 |
| disabled（单项） | — | 不可展开、不可选，降透明 |
| disabled（整控件） | 降透明、不可展开 | — |
| readonly | 外观正常、不可展开 | — |
| loading（某列） | — | 该列骨架 / spinner |
| error | 边框红 + 文案 | 该列错误 + 重试 |
| empty（某列） | — | 该列空状态文案 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 多列并列，列宽固定或按内容自适应；总宽超容器时面板横向扩展或列内滚动
- 面板最大高度受限，**每列独立纵向滚动**
- 打开时应自动展开到**已选路径**所在列
- 靠近视口边缘自动翻转 / 平移

### 移动端
- 多列面板在窄屏放不下：改为**逐级页面**（点一层进下一屏）或底部弹层内单列逐级推进
- 触摸目标 ≥ 44×44
- 面包屑式路径在窄屏可换行 / 折叠

## 交互

### 展开与开合
- 打开：点触发器 / 聚焦后 Enter、Space / 方向键下
- 逐级展开：**点选项行**展开其子列（默认）；或**悬停项**即展开下级（hover 展开）
- 关闭：再次点击、Esc、选中结果、点击外部、Tab 移出
- hover 展开与点击展开**不能在同一列混用**，否则误触

### 选中行为
- **只选叶子**：只有最末级（无下级）可被选中并收起
- **可选任意层**：父级也可被选中，选中父级即代表该子树——语义须明确
- **父级可选开关（级联独立性）**：开启后选父不自动选子、选子也不影响父，父与子各自独立、可在同一路径上并存；关闭则父子强联动
- 点击某级：更新在途路径，展开下一列；到达可选层级时确认值
- 重复点已选：收起，不取消
- 清空：回到未选

### 键盘
| 按键 | 行为 |
|---|---|
| `Enter` / `Space` | 打开触发器；面板内确认当前高亮项并展开 / 选中 |
| `Esc` | 关闭且**不改变值**；深层时可回退一列（可选） |
| `↑` / `↓` | 当前列内移动高亮 |
| `←` / `→` | 在列间移动（回上一级 / 进下一级） |
| `Home` / `End` | 跳到当前列首 / 末项 |
| 字母键 | typeahead 跳到以该字母开头的项；搜索模式下由搜索框接管 |

### 指针与手势
- 点击项：展开 / 选中
- 悬停项：hover 模式下展开下级
- 移动端：点项进入下一级页面

### 焦点管理
- 关闭后焦点**回到触发器**（不得丢到 body）
- 可搜索模式：面板打开即聚焦搜索框

### 动画与过渡
- 新列展开：轻微横向位移 + 淡入，约 100–200ms
- 箭头翻转；不引起布局抖动

### 反馈
- 选中路径即反馈；异步列加载显示加载 / 空 / 错误三态
- 路径回显在触发器上

### 边界交互
- 层级深 / 数据大：按列虚拟滚动，只渲染可见列
- 搜索：**跨层匹配**，结果里显示并**高亮完整路径**；点击结果直接定位到该路径
- 搜索命中在未展开的层时，需自动补全中间层级 / 展示路径上下文

## 数据流

### 输入
- **树形数据**：节点 `{ 值, 展示文本, 是否禁用?, 子级? }`；子级可预置或按需加载
- 配置：是否可搜索、是否可选任意层（父级可选开关）、可选层级（仅叶子 / 任意层）、是否多选、分隔符、占位符、默认值、尺寸与状态
- 数据来源：静态树 / 远程接口

### 内部状态
- 面板开合
- 在途路径（已展开到第几级、每列高亮）
- 搜索词与搜索结果
- 各列加载 / 错误（懒加载）
- 各列滚动位置

### 输出
- **值变化事件**：**完整路径**（各层值的数组）或**末级值**——**必须先明确**，两者影响回填与比较
- 也可抛出行进中的「在途路径」事件（供外部联动）
- 多选时输出多条路径

### 受控 / 非受控
- 受控：值由外部持有，组件只抛出新路径，自身不存值
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「点了不展开」或「外部改了路径不回显」

### 异步与竞态
- **按需加载子级**：首次展开某节点时才拉其子级，显示加载 / 空 / 错误三态
- **竞态**：快速在多个节点间切换时，后发请求先返回会串数据；按「父节点标识 + 请求序号」丢弃过期结果
- 已加载的子级应缓存，避免重复请求

### 校验与错误
- 组件只负责「当前路径」；必选 / 层级规则校验在表单层
- 错误由外部传入（标记 + 文案），组件负责呈现

### 回填与序列化
- 初值路径 → 逐级加载 / 定位，展开到对应列并高亮
- 若为懒加载，回填需**依次请求每一级**，期间显示加载
- 比较按各层值（id）逐级比较；对象值不能按引用比较
- 输出形态（完整路径 vs 末级值）在序列化时统一

## 无障碍
- 触发器：`combobox` + `aria-expanded`、`aria-haspopup`
- 每列：`listbox`；选项 `option` + `aria-selected`
- 路径回显对屏幕阅读器可读（用分隔符分隔各层）
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）
- 禁用项标 `aria-disabled`

## 常见误用
- 把「分组」当「层级」→ 分组只是视觉归类，无联动，应用分组下拉
- 层级深（> 3）却不支持搜索 → 用户点到手酸
- 需要多选却用级联 → 应树选择
- 无层级数据硬套级联 → 多一层无意义点击
- 返回形态不明确（完整路径 vs 末级值）→ 回填与比较错乱
- hover 展开与点击展开混用 → 误展开、误选

## 边界与代价
- 层级 > 3：**必须**可搜索，否则定位成本过高
- 移动端：多列面板放不下，需改逐级页面或底部弹层
- 懒加载 + 回填：每级都要请求，回填慢且需处理逐级失败
- 异步竞态不处理 → 出现「展开 A 显示 B 的子级」
- 父级可选开关语义不清 → 选中值是否代表整棵子树无从判断
