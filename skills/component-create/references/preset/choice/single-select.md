# 单选下拉

从一组选项中**选一项**，收起后触发器上只显示当前值。

## 角色与边界

- **是什么**：一个可展开的选项容器，同一时刻只有一个值被选中。
- **解决什么**：选项多到无法平铺、又必须从中选一个。
- **不解决什么**：
  - 不解决多选 → 多选下拉
  - 不解决层级联动 → 级联选择
  - 不解决「层级 + 跨层多选」 → 树选择
  - 不承担必填 / 格式校验 → 校验属于表单层，本组件只呈现错误态
- **什么时候不用**：选项 ≤ 4 → 单选按钮组 / 分段控件（直接可见更快）；真二元语义 → 开关。

---

## UI

### 结构解剖
- **触发器**：一行。左为「选中值」或占位符，右为下拉箭头；可含前缀图标
- **占位符**：未选时的浅色提示文字
- **面板**：浮层，含选项列表
- **选项行**：展示文本（+ 可选图标 / 副文本 / 说明）
- **分组标题**：分组模式下每个分组的标题行
- **搜索框**：可搜索时固定在面板顶部
- **清空按钮**：可清除且已有选中值时出现（常 hover 才显形）
- **状态占位**：面板内的加载 / 空 / 错误位

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响高度、内边距、字号、选项行高
- 状态类：默认 / 错误（红边）/ 警告 / 禁用
- 外观：带边框 / 无边框（工具栏内）/ 填充式
- 触发器可挂：前缀图标、后缀图标、计数、标签

### 视觉状态（逐条）
| 状态 | 触发器 | 面板 / 选项 |
|---|---|---|
| default | 边框默认、占位符浅色 | — |
| hover | 边框加深 / 背景微亮 | 悬停的选项行背景微亮 |
| focus-visible | 明显焦点环 | — |
| open | 边框高亮 + 箭头翻转 | 面板出现 |
| selected | 显示选中值 | 该行高亮 + 勾选标记 |
| active（按下选项） | — | 选项行背景加深 |
| disabled | 整体降透明、禁用指针 | 打不开 |
| readonly | 外观同 default，但不可展开 | — |
| loading | 触发器可显示 spinner | 面板内骨架 / spinner |
| error | 边框红 + 下方错误文案 | — |
| empty | — | 面板内空状态文案（+ 可选引导） |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 面板宽度默认与触发器对齐；内容超长时可加宽
- 面板最大高度受限，选项多时**列表内滚动**
- 靠近视口底部时**向上翻转**，避免出屏
- 超长选项文字截断，悬停显示完整值

### 移动端
- 桌面式下拉在小屏体验差：改为**底部弹层选择器**（半屏 / 全屏）
- 触摸目标 ≥ 44×44
- 选项列表占满宽度，不做窄浮层

## 交互

### 触发与开合
- 打开：点击触发器 / 聚焦时 Enter、Space / 方向键下
- 关闭：再次点击、Esc、选中一项、点击外部、Tab 移出
- 面板自动避让视口边缘

### 选中行为
- 点击选项：立即选中并收起（单选即时生效）
- 打开时高亮应落在**当前选中项**（无选中则第一项）
- 重复点已选项：收起，不取消选择
- 清空：仅当该字段允许为空时提供

### 键盘
- `Tab`：聚焦 / 离开
- `Enter` / `Space`：打开；打开后 `Enter` 选中高亮项
- `Esc`：关闭且**不改变值**
- `↑` / `↓`：选项间移动高亮
- `Home` / `End`：跳到首 / 末项
- 字母键：跳到以该字母开头的项（typeahead）；搜索模式下由搜索框接管
- 搜索模式：`↑`/`↓` 在结果间移动，`Enter` 选中

### 指针与手势
- 移动端：点触发器 → 底部弹层；点选项 → 选中并关闭
- 悬停选项行高亮

### 焦点管理
- 关闭后焦点**回到触发器**（不得丢到 body）
- 可搜索模式：面板打开即聚焦搜索框

### 动画与过渡
- 面板出现 / 消失：轻微位移 + 淡入淡出，约 100–200ms
- 箭头翻转
- 不引起布局抖动

### 反馈
- 异步选项：打开时显示加载；失败显示错误 + 重试入口
- 选中本身不额外提示（值即反馈）

### 边界交互
- 超长列表：内部滚动，并在打开时滚动定位到当前值
- 选项动态变化：已选值若从数据中消失，须明确处理（标记「已失效」或清空）
- 快速连续操作：打开 / 请求需防抖、防竞态

## 数据流

### 输入
- **选项数据**：`{ 值, 展示文本, 是否禁用?, 分组? }` 的列表
- 数据来源：静态数组 / 远程接口
- 分组结构：组名 + 组内选项
- 其他配置：占位符、默认值、尺寸、状态（错误 / 禁用）、是否可搜索、是否可清除

### 内部状态
- open（开合）
- 高亮索引（键盘导航）
- 搜索词（可搜索模式）
- 加载 / 错误（异步）
- 列表滚动位置

### 输出
- **值变化事件**：新值（可选带旧值）
- 打开 / 关闭事件（供外部联动）
- 搜索事件（异步搜索时把搜索词抛给外部）
- **值形态必须明确**：是 id 还是整个选项对象——这决定回填与比较

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值，自身不存值
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「点了不变」或「外部改了不刷新」

### 异步与竞态
- 远程加载要处理加载 / 空 / 错误三态
- **竞态**：后发请求先返回时丢弃过期结果（按请求标识或时间戳）
- 搜索防抖；同一关键词可缓存，不重复请求

### 校验与错误
- 组件只负责「当前值」；必填 / 格式校验在表单层
- 错误由外部传入（错误标记 + 文案），组件负责呈现

### 回填与序列化
- 初值 → 显示：按值查选项取展示文本；查不到时兜底（显示原始值 或 留空）
- **值比较**：对象值须按 id 比较，不能按引用

---

## 无障碍
- 触发器：`combobox` / `button` + `aria-expanded`、`aria-haspopup`
- 面板：`listbox`；选项 `option` + `aria-selected`
- 选中值对屏幕阅读器可读
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）
- 禁用项标 `aria-disabled`

---

## 常见误用
- 只有 2–3 项仍用下拉 → 单选按钮组 / 分段控件
- 选项 > 约 15 条却不做搜索
- 拿它承载层级数据 → 级联 / 树选择
- 拿它承载多选 → 多选下拉（并设上限收纳）
- 移动端照搬桌面下拉

## 边界与代价
- 选项 > 约 15 条：**必须**可搜索
- 移动端：必须换底部弹层选择器
- 值形态不明确（不按 id 比较）→ 回填与选中态错乱
- 依赖 hover 才能看到完整值 → 触摸端信息不可及
- 异步竞态不处理 → 出现「搜 A 显示 B 的结果」
