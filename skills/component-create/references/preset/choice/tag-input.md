# 标签输入

在一个输入框里**累积多个值**，可删可加，并可**允许用户自造**新值。

## 角色与边界

- **是什么**：单行输入区，用回车之类的动作把当前输入「提交」成一个标签，标签以胶囊形式排在输入区内。
- **解决什么**：值是多个、数量不定，且**用户能自己输入**（标签、关键词、收件人、@ 提及）。
- **不解决什么**：
  - 只能从固定选项里选、不许自造 → 多选下拉
  - 选项固定且要看清「已选 / 未选」对照 → 穿梭框
  - 值为单个 → 普通输入框
  - 层级 / 联动 → 级联选择 / 树选择
- **什么时候不用**：候选项固定且 ≤ 10 条 → 复选框组（一眼可见、防错输入）；值有强格式要求又无联想 → 普通输入 + 表单校验更省事。

## UI

### 结构解剖
- **输入区容器**：一行或自动换行，标签与输入光标同行排列
- **标签胶囊**：文本 + 删除按钮（×）；可选图标 / 头像 / 颜色
- **输入光标**：始终停在最后一个标签之后，宽度随文字增长
- **占位符**：无标签时显示，出现第一个标签后消失
- **候选浮层**：带联想时出现，位于输入区下方
- **清空按钮**：有标签时出现（常 hover 才显形）
- **计数**：设了上限时可显示「已用 / 上限」

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响容器高度、标签内边距、字号
- 外观：带边框 / 无边框（填充式）
- 状态类：默认 / 错误 / 警告 / 禁用 / 只读
- 变体：自由输入 / 仅选既有 / 带联想 / 带上限

### 视觉状态
| 状态 | 容器 | 标签 | 候选浮层 |
|---|---|---|---|
| default | 边框默认 | 正常底色 | 未出现 |
| hover | 边框加深 | 悬停标签显示删除按钮 | 悬停项背景微亮 |
| focus-visible | 明显焦点环 | — | — |
| focus-within | 边框高亮 | — | 有候选则出现 |
| 标签被键盘选中 | — | 高亮描边 | — |
| 输入中（组合态） | 光标带下划线（IME 组合） | — | 联想项可开 |
| disabled | 整体降透明、不可聚焦 | 删除按钮不可点 | 不出现 |
| readonly | 外观正常、值可复制 | 无删除按钮 | 不出现 |
| error | 边框红 + 下方文案 | 非法值标红 | — |
| full（已达上限） | 输入被拦 | 显示计数 | 候选置灰 |
| loading | 可选 spinner | — | 候选区骨架 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 容器高度**随标签换行自动增长**；设最大高度后超出改为内部滚动
- 标签之间固定间距；删除按钮与文本基线对齐
- 长标签**截断**并保留 tooltip 显示完整值（截断宽度按容器设定）
- 候选浮层宽度默认与容器对齐

### 移动端
- 触摸目标 ≥ 44×44，删除按钮热区要放大（别只给图标本体）
- 标签换行后键盘弹出会遮挡输入区，需滚动让光标可见
- 联想浮层尽量改为整宽列表，避免窄浮层

## 交互

### 触发与创建
- **输入即候选**：自由输入模式下，输入任意内容，按创建键即成标签
- **创建键**：回车、逗号、分号、Tab、失焦——都要能创建，触发的键可由配置决定
- **仅选既有模式**：只接受候选里的值，回车只选高亮候选，手打的新值不落地
- **输入为空**：按回车不创建空标签
- **粘贴**：粘贴含分隔符（逗号 / 换行 / 分号）的一段文本，**自动拆成多个标签**并逐个规范化
- **IME 组合态**：输入法未上屏时，回车 / 逗号**不得触发创建**（否则中文拼音会被误拆）——必须在组合结束后再判定

### 选中 / 输入行为
- 输入时对候选做**过滤 / 联想**，高亮第一项
- 点候选：加入该候选为标签，清空输入，焦点保持
- 重复值：**按规范化规则去重**（是否区分大小写 / 去首尾空格 / 统一大小写由配置决定），重复项不重复加入，可给「已存在」提示
- 上限：已达上限时输入被拦截或创建被拒绝，并给出超限反馈
- 删除：点标签上的 ×，或选中标签后按删除键

### 键盘
| 按键 | 行为 |
|---|---|
| 回车 | 创建当前输入；有候选时选高亮项；编辑标签时确认编辑 |
| `,` / `;` | 创建（可配置），**组合态下不触发** |
| `Tab` | 一般用于移出焦点；若开启「Tab 创建」则先创建 |
| `←` / `→` | 在标签与输入光标之间移动 |
| `Backspace` | 输入为空时删除最后一个标签；非空时删字符 |
| `Delete` | 删除当前选中的标签 |
| `↑` / `↓` | 候选浮层内移动高亮 |
| `Esc` | 关闭候选浮层；再按可退出标签选中态 |
| `Ctrl/Cmd + A` | 输入为空时全选标签（可选） |

### 指针与手势
- 点标签删除按钮 → 删除该标签
- 双击标签 → 进入**编辑**：标签变回可编辑文本，回车确认、Esc 取消
- 悬停标签显示删除按钮（触摸端删除按钮常显）

### 焦点管理
- 焦点留在容器内的隐藏输入上；删标签后焦点**不丢失**
- 编辑标签时焦点临时移到编辑态输入，结束后回到主输入
- 候选浮层打开不抢输入焦点

### 动画与过渡
- 标签加入 / 移除：轻微缩放 + 淡入淡出，约 100–150ms
- 容器高度变化平滑过渡，避免抖动

### 反馈
- 创建成功：标签轻微入场动画（值即反馈，不额外提示）
- 去重命中：可给「已存在」轻提示
- 超限：输入框抖动 + 文案提示
- 校验失败（如邮箱格式）：标签标红 + 文案；**「先加入再标红」还是「直接拒绝创建」须先明确**

### 边界交互
- 大量标签：容器限高 + 内部滚动，或超 N 个折叠为「+N」
- 超长单标签：截断 + tooltip
- 连续快速粘贴：分批解析、去重后一次性落地

## 数据流

### 输入
- **候选数据**（带联想 / 仅选既有时）：`{ 值, 展示文本, 是否禁用? }` 列表
- 配置：占位符、默认值、是否允许自造、触发创建的按键、分隔符、去重与规范化规则、数量上限、校验规则、尺寸与状态
- 数据来源：静态数组 / 远程接口

### 内部状态
- 当前输入串
- 候选浮层开合、高亮索引
- 选中（编辑）中的标签索引
- IME 组合态标记
- 加载 / 错误（异步联想）

### 输出
- **值变化事件**：字符串数组（可选带本次被增 / 删的项）
- 输入事件（异步联想时把输入串抛给外部）
- **值形态必须明确**：默认是**字符串数组**；若允许对象标签（带 id / 展示文本），须明确按 id 去重与比较

### 受控 / 非受控
- 受控：值由外部持有，组件只抛出新数组，自身不存值
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「删了又回来」或「外部改了不刷新」

### 异步与竞态
- 远程联想：输入防抖；处理加载 / 空 / 错误三态
- **竞态**：后发请求先返回时丢弃过期结果（按请求标识或时间戳）
- 创建不依赖联想结果，联想失败**不应阻塞**自造值

### 校验与错误
- 组件负责呈现错误（错误标记 + 文案），规则由外部传入或内联
- 常见规则：格式（邮箱 / 域名 / 数字）、长度、数量上限、是否允许自造
- 非法值：允许加入再标红，还是直接拒绝创建——**必须先明确**

### 回填与序列化
- 初值数组 → 逐个渲染为标签；若为对象值，按 id 查候选取展示文本，查不到兜底显示原始值
- 序列化：提交时按值形态输出数组；去重与规范化在**输出前**统一做一次

## 无障碍
- 容器：`combobox` 语义；`aria-expanded`（浮层）、`aria-haspopup`
- 标签列表：`list` + `listitem`；删除按钮有可读名称（如「移除 标签X」）
- 候选浮层：`listbox` + `option` + `aria-selected`
- 超限提示用 `aria-live` 播报
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 候选固定却允许自由输入 → 脏数据；应改为「仅选既有」
- 不做去重 / 规范化 → 出现「React / react」重复标签
- 不设上限又说可用作收件人列表 → 易被撑爆
- IME 组合态误触发创建 → 中文被拆成乱码标签
- 无校验却宣称支持邮箱列表 → 会收进非法值
- 把单值场景做成标签输入 → 多余的胶囊噪声

## 边界与代价
- 无上限时标签会撑爆控件，长文本标签尤甚 → 必须设上限 + 折叠策略
- 长标签不截断 + 无 tooltip → 容器被单值撑爆且信息不可读
- 触发分隔符与业务冲突（值本身含逗号）→ 需可配置分隔符或转义
- 异步联想不做竞态处理 → 出现「输入 A 显示 B 的候选」
- 触摸端删除按钮热区过小 → 误触 / 删除困难
