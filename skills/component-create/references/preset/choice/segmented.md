# 分段控件

若干互斥选项**并排成一段**，选中项被高亮（常带滑动指示块），用于紧凑的视图 / 模式 / 密度切换。

## 角色与边界

- **是什么**：一个整体呈「条状」的互斥选择控件，同一时刻只有一个值，通常带滑块式高亮指示器。
- **解决什么**：2–5 个互斥、切换**即时生效**、且空间紧张的场景（列表 / 卡片视图、时间范围、密度）。
- **与单选按钮组的差异**：单选按钮组是「一列 / 一行独立圆点选项」，强调逐项可读可比；分段控件是**一体化等宽分段 + 滑块指示器**，强调紧凑与「切换」手感。二者语义相同（互斥），形态与用途不同。
- **不解决什么**：
  - 需要逐项说明 / 图标语义复杂 → 单选按钮组 / 单选卡片
  - 选项 > 5 → 单选下拉
  - 需要多选 → 复选框组
  - 内容随选项整体切换且项数多、每项是独立页面 → 标签页
  - 需要填进表单最后提交的正式字段 → 单选按钮组更贴切
- **什么时候不用**：选项文字较长（每段 > 约 4 字，易被截断）→ 放大尺寸或改单选按钮组；本质是「提交型表单项」→ 单选按钮组。

---

## UI

### 结构解剖
- **分段容器**：条状外框（可带底槽 / 分隔线），内部容纳所有段
- **段（segment）**：每个可选项，等宽或自适应宽度
- **段内容**：文字，可选前置图标；可含计数角标
- **滑块指示器**：选中段背后的高亮块，随选中项平移（核心视觉特征）
- **分隔线**：段与段之间的细分隔（有滑块时常省略）
- **角标 / 计数**：段内右侧的小数字（如「全部 12」）

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响段高、内边距、字号、滑块尺寸
- 宽度策略：**等宽**（每段同宽，最规整）/ **自适应**（按文字宽度，短文字不浪费空间）
- 外观：底槽式（有背景槽 + 滑块）/ 描边式（外框 + 选中填充）/ 纯分段（无槽，仅选中变色）
- 指示器：有滑块 / 无滑块（仅文字变色）
- 状态类：默认 / 禁用 / 只读
- 可选：前置图标、计数角标、仅图标模式

### 视觉状态（逐条）
| 状态 | 容器 / 段 | 滑块指示器 |
|---|---|---|
| default | 段文字常规色、背景透明 | 位于当前选中段下方 |
| hover（未选中段） | 文字加深 / 背景微亮 | 不移动 |
| hover（已选中段） | 保持选中样式 | 不移动 |
| focus-visible | 明显焦点环（落在当前段） | 不移动 |
| selected | 段文字加重 / 对比色 | 高亮块与选中段对齐 |
| active（按下段） | 段内容轻微缩放 / 压暗 | 待选中 |
| disabled（整体） | 整条降透明、禁用指针 | 保持静止 |
| disabled（单段） | 该段灰显、不可选 | 不覆盖该段 |
| readonly | 外观同 default，但不可切换 | 静止 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 段内文字 / 图标水平垂直居中；计数角标贴段右内侧
- 等宽模式：各段宽度 = 容器宽 / 段数；自适应模式：按内容宽 + 统一内边距
- 滑块尺寸与目标段一致，位置由选中索引决定
- 段数变化（动态增删）时，等宽宽度与滑块位置需重算
- 整条控件宽度可占满容器，也可按内容收缩（工具栏中）

### 移动端
- 每条段触摸目标 ≥ 44×44（高度优先保证）
- 段数多时避免横向滚动；超出则减小内边距或改用单选下拉
- 触摸端 hovers 状态无意义，选中态需足够明显
- 滑块动画在低端设备可降级为直接跳变

## 交互

### 核心操作
- 点击某段 → **立即选中并生效**（切换即时，无需确认 / 提交）
- 无「开合」概念，整条控件常驻可见
- 分段控件**不支持多选**，点击已选中段不取消（始终保有一个值）

### 选中 / 输入行为
- 点击段 ≈ 命中整个段区域
- 选中新段时旧段取消，滑块平滑移动到新段
- **不允许「清空为空」**：必须有且仅有一个选中段；若需「全部」等语义，作为一个显式段承载
- 切换可触发外部联动（视图重渲染 / 数据重查），组件本身只抛值

### 键盘
| 键 | 行为 |
|---|---|
| `Tab` | 聚焦**当前选中段**；再按离开整条（段内不逐项停留） |
| `→` / `↓` | 选中下一段（滑块右 / 下移） |
| `←` / `↑` | 选中上一段 |
| `Space` | 选中当前聚焦段 |
| `Home` / `End` | 跳并选中首 / 末段 |

- 同单选组：整条是一个 Tab 停靠点，内部用方向键切换。

### 指针与手势
- 移动端：点按段即切换；不做滑动切换（与页面滚动冲突）
- 悬停未选中段给出可点提示

### 焦点管理
- 焦点落在当前段；方向键切换后焦点随选中段移动
- 整条禁用不可聚焦；单段禁用时跳过
- 切换导致内容重载时，焦点不应被抛出容器

### 动画与过渡
- **滑块平移是核心动画**：位移过渡约 150–250ms，缓动自然（缓入缓出）
- 文字颜色过渡同步进行
- 段数 / 宽度变化时滑块需重新定位，避免闪跳
- 不引起布局抖动；低端设备可关闭滑块动画

### 反馈
- 选中即反馈（滑块到位 + 文字加重）
- 控件本身无错误态（非表单字段）；若用作表单字段需由外部另加错误呈现
- 切换引发异步加载时，应在内容区给加载反馈，而不是控件内假死

### 边界交互
- 仅 2 段：即「二元切换」，评估是否该用开关（开 / 关语义）而后再定
- 段数动态变化：选中项若被移除，须明确回落到某项
- 极窄容器下段文字截断：优先缩短文案或降段数，不依赖 tooltip 兜底

## 数据流

### 输入
- **选项数据**：`{ 值, 展示文本, 是否禁用?, 图标?, 计数? }` 的列表
- 数据来源：多为静态短枚举
- 其他配置：默认选中值、宽度策略（等宽 / 自适应）、尺寸、外观、是否带图标 / 计数、状态（禁用 / 只读）

### 内部状态
- 受控模式下几乎无内部状态
- 非受控：内部当前值、滑块位置缓存（段数 / 宽度变化时重算）
- 焦点项（与选中项同步）

### 输出
- **值变化事件**：新值（标量，可选带旧值）
- 可选：切换完成事件（供内容重载）
- **值形态必须明确**：是 id 还是整个选项对象

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值，自身不存值
- 非受控：内部持有，给默认选中值
- **二选一必须明确**；混用会出现「点了滑块不动」或「外部改了滑块不跟随」

### 异步与竞态
- 选项通常静态，异步少见；若异步，加载中应禁用切换或显示占位
- 切换触发的数据请求需防竞态（快速来回切换时丢弃过期结果）
- 选中态不受异步内容加载影响（滑块应即时到位）

### 校验与错误
- 分段控件一般**不作为必填表单字段**，因此无常驻错误态
- 若被当作表单字段使用，校验与错误呈现须由表单层接管
- 「即时生效」意味着不适用「提交时才报错」的模型

### 回填与序列化
- 初值 → 显示：按值定位选中段并让滑块到位；查不到时兜底到默认段
- **值比较**：对象值须按 id 比较，不能按引用
- 序列化输出选中段的标量值

## 无障碍
- 容器可用 `radiogroup` 语义；段用 `radio` + `aria-checked`
- 整条为单一 Tab 停靠点，方向键切换必须实现
- 仅图标段必须有可读文本（`aria-label`），不能只靠图形语义
- 禁用段标 `aria-disabled`
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）
- 滑块为纯装饰，不应成为可聚焦元素或干扰读数

---

## 常见误用
- 段文字过长仍硬塞 → 每段过窄、文字截断
- 段数 > 5 仍用分段 → 应改单选下拉
- 用它做「表单必选项」 → 单选按钮组更贴切
- 内容整体切换且项多 → 应用标签页
- 需要多选 → 根本不适用（分段只互斥）
- 仅图标且无语义标签 → 用户看不懂、屏幕阅读器读不出

## 边界与代价
- 选项 > 约 5 项：改用单选下拉或标签页
- 每段文字 > 约 4 字：易截断，需放大尺寸或换组件
- 不支持多选、不适合长文本，这是形态固有限制
- 快速来回切换触发异步加载 → 必须防竞态，否则内容与选中态错位
- 段数 / 容器宽度动态变化 → 滑块定位若不重算会错位
