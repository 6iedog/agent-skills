# 单选按钮组

若干互斥选项**全部平铺可见**，点选其一即生效，整组只允许一个值。

## 角色与边界

- **是什么**：一组同名的单选控件，天然互斥，同一时刻**只有一个**被选中，取值是标量。
- **解决什么**：选项数量少、需要用户**一眼看全所有可选**、并能直接比较后再选一个。
- **不解决什么**：
  - 选项多到放不下 → 单选下拉
  - 本质是「视图 / 密度 / 模式」的紧凑切换 → 分段控件
  - 选项需大图或长说明、占用空间大 → 单选卡片（带图 / 富文本的单选，形态相近但更重）
  - 需要多选 → 复选框组
  - 必填 / 业务规则校验 → 属于表单层，本组件只呈现错误态
- **什么时候不用**：选项 > 5（尤其横向会挤压换行）→ 单选下拉；追求等宽紧凑、更像「切换开关」→ 分段控件。

## UI

### 结构解剖
- **组容器**：承担分组与布局（横向 / 纵向），并承载组标签与错误文案
- **组标签**：整组的标题（如「通知方式」），可选
- **单项**：控件圆点 + 文本；控件与文本为一个整体命中区
- **圆点标记**：未选为空心圈，已选为实心（+ 内点）
- **文本标签**：可换行；可含副文本 / 说明行
- **图标 / 缩略图**：选项可选带前置图形
- **说明行**：每项下方的一行解释文字（卡片式变体更常见）
- **辅助位**：组下方的帮助文案 / 错误文案

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响圆点直径、行高、字号、间距
- 排列：**横向**（一行平铺）/ **纵向**（一列堆叠）
- 外观：默认（圆点 + 文本）/ **按钮样式**（外观像一组按钮的互斥）/ **卡片式**（含图标或说明的方块选项）
- 状态类：默认 / 错误（整组标红）/ 禁用（整体 / 单项）
- 可挂：组标签、每项图标、每项说明、组级帮助文案

### 视觉状态（逐条）
| 状态 | 组容器 | 单项 |
|---|---|---|
| default | — | 空心圆点 + 常规文本 |
| hover | — | 圆点描边加深 / 背景微亮 |
| focus-visible | — | 明显焦点环（**通常只落在当前项上**） |
| selected | — | 圆点实心 + 文本加重 |
| active（按下项） | — | 圆点轻微缩放 / 背景加深 |
| disabled（整体） | 整组降透明、禁用指针 | 全部不可交互 |
| disabled（单项） | — | 该项灰显、不可选中 |
| readonly | 外观同 default，但不可改选 | 保持可读 |
| error | 组标签 / 圆点变红 + 组下错误文案 | 圆点描边变红 |
| loading | 可显示骨架或禁用整组 | 占位项 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- **横向**：各项等间距排开，优先对齐首行基线；项数 > 5 或文本较长时**改用纵向**
- **纵向**：最稳妥，项与项等距堆叠，长文本不挤压
- 横向换行时，第二行应与第一行对齐起点，不居中错位
- 圆点与文本垂直居中对齐；带说明行时，圆点应顶部对齐首行而非整块居中
- 卡片式：各卡片等宽 / 等高（同排），选中态整块描边高亮

### 移动端
- 纵向排列优先，触摸目标 ≥ 44×44
- 横向排布在小屏应换行为纵向或两列，避免横向滚动
- 间距加大，防止相邻项误触（圆点误选代价是「改错了值」）

## 交互

### 核心操作
- 点击任意项 → **立即选中该唯一项**，无需二次确认
- 组内没有「开合」「提交」步骤；选中即生效（作为表单字段时通常在提交时统一使用）
- 已选项再次点击 —— **默认不取消**（单选组一般必须始终有一个值）
  - 仅当「允许为空」显式开启时才可取消；是否允许为空必须在设计阶段明确

### 选中 / 输入行为
- 点击项 ≈ 点击圆点 ≈ 点击文本，命中区一致
- 选中新项时，旧项**自动取消**（互斥由组统一管理，不存在两个同时选中）
- **必选组不应提供「清空为无值」的操作**；若必须允许空，用「其他 / 不选择」作为一个显式选项承载
- 键盘方向键在组内移动并**即时改选**（见下）

### 键盘
| 键 | 行为 |
|---|---|
| `Tab` | 进入组时聚焦**已选项**（无则第一项）；再按离开整组（组内 Tab 不逐项停留） |
| `→` / `↓` | 移到下一项并**选中**它 |
| `←` / `↑` | 移到上一项并**选中**它 |
| `Space` | 选中当前聚焦项 |
| `Home` / `End` | 跳到首 / 末项并选中 |
| 字符键 | （可选）typeahead 跳到文本以该字符开头的项 |

- 关键：单选组整体是一个「Tab 停靠点」，内部用方向键切换，而不是每项都各自 Tab。

### 指针与手势
- 移动端：点按项即选中；不做滑动切换（滑动切换与滚动手势冲突）
- 悬停项高亮，提示可点

### 焦点管理
- 焦点应始终落在组内某一项上；**选中项与焦点项保持一致**（方向键即时改选时两者同步）
- 整组禁用时不可聚焦；单项禁用时该项跳过 Tab 与方向键
- 错误态出现后，若与某次交互相关，焦点可移到组内但不要抢走用户正在做的操作

### 动画与过渡
- 圆点选中态切换：实心 / 空心变化，约 100–150ms
- 卡片式可加轻微描边 / 背景过渡
- 不引起布局抖动（说明行、错误文案出现时预留或平滑撑开）

### 反馈
- 选中即反馈（圆点实心 + 文本加重）
- 组级错误由外部传入，显示在组下方
- 单项禁用不给点击反馈（或给出可读原因），不做「点了没反应」

### 边界交互
- 组内仅一项时：等价于「确认 / 展示」，需评估是否该用开关或纯文本
- 选项动态增删：已选值若从数据中消失，须明确处理（标记失效 / 回落到默认项）
- 选项文本超长：纵向换行，不截断关键语义

## 数据流

### 输入
- **选项数据**：`{ 值, 展示文本, 是否禁用?, 图标?, 说明? }` 的列表
- 数据来源：静态数组 / 远程接口（选项一般较稳定，异步较少）
- 其他配置：默认选中值、布局方向、尺寸、外观（默认 / 按钮 / 卡片）、状态（错误 / 禁用）、是否允许为空
- 组级：组标签、帮助文案、是否必填（供表单层使用）

### 内部状态
- 受控模式下几乎无内部状态（值由外部持有）
- 非受控：内部当前值、可选的焦点项
- 焦点项（键盘导航时与选中项同步）
- 加载 / 错误（异步选项时）

### 输出
- **值变化事件**：新值（标量，可选带旧值）
- 可选：失焦 / 变更完成事件（供表单联动）
- **值形态必须明确**：是 id 还是整个选项对象——决定回填与比较

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值，自身不存值
- 非受控：内部持有，给默认选中值
- **二选一必须明确**；混用会出现「点了不变」或「外部改了不刷新」

### 异步与竞态
- 选项远程加载时处理加载 / 空 / 错误三态，加载中避免用户选中后又被打断
- 若选项随搜索变化，已选项须保留，避免选中态丢失

### 校验与错误
- 组件只负责「当前值」；必填校验在表单层
- 错误由外部传入（错误标记 + 文案），组件负责呈现；错误态应作用于**整组**而非单项
- 「必选」通常体现为：组下提示「请选择一项」，而不是禁用提交按钮

### 回填与序列化
- 初值 → 显示：按值查选项定位到对应项并置为选中；查不到时兜底（保持全不选 或 标记失效）
- **值比较**：对象值须按 id 比较，不能按引用
- 序列化时输出该值的原始标量（id / 字符串），不输出控件对象

## 无障碍
- 组容器：`radiogroup` + `aria-labelledby`（关联组标签）
- 单项：`radio` + `aria-checked`；组内需形成单一 Tab 停靠点的角色语义
- 键盘方向键切换必须实现（这是单选组的标准交互，不是可选项）
- 禁用项标 `aria-disabled`
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）
- 组级错误文案应与 `radiogroup` 建立关联，供屏幕阅读器读出

## 常见误用
- 选项 > 5 仍平铺 → 占满屏、反而难选，应改单选下拉
- 横向排列长文本 → 挤压换行，应改纵向
- 与复选框组混用语义 → 单选互斥、复选可多项
- 没有默认值却要求必填 → 用户容易整组漏看
- 给「必选组」提供清空为无值的操作 → 破坏互斥必选语义
- 用单选按钮组做「视图切换」 → 分段控件更贴切

## 边界与代价
- 选项 > 约 5 项：改用单选下拉
- 横向 + 长文本：必须改纵向，否则文字被挤压 / 截断
- 键位语义不清（每项各自 Tab）→ 破坏单选组的标准键盘模型
- 「选中项」与「焦点项」不同步 → 方向键行为混乱、无障碍失败
- 值形态不明确（不按 id 比较）→ 回填错位、选中态错乱
