# 穿梭框

左右两栏——左侧「候选」、右侧「已选」，中间一组箭头按钮，用户把项**在两栏间搬移**。

## 角色与边界

- **是什么**：两栏并列的复合控件；搬移是显式动作，右栏内容即当前值。
- **解决什么**：候选较多、多选，且用户**需要同时看清「已选 / 未选」的对照**，选择要慎重、可见。
- **不解决什么**：
  - 选项少、平铺即可 → 复选框组
  - 候选多但无需对照、要轻量快选 → 多选下拉
  - 层级数据 → 树选择（树形穿梭是它的重载变体）
  - 单值 → 单选下拉
- **什么时候不用**：需要频繁反复改选、单次只剩 1–2 个判断 → 多选下拉更顺手；窄屏 / 移动端 → 换多选下拉或分步选择。

## UI

### 结构解剖
- **左栏（候选）**：标题 + 计数 + 可选搜索框 + 项列表（每项前有勾选框）
- **中间操作列**：指向右 / 指向左的箭头按钮（可含整栏移动变体）
- **右栏（已选）**：标题 + 计数 + 可选搜索框 + 项列表
- **项行**：勾选框 + 展示文本（+ 可选图标 / 副文本）
- **批量区**：栏顶部或底部可放「全选本栏」等操作
- **状态占位**：每栏内的加载 / 空 / 错误位

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响项行高、字号、箭头按钮大小
- 布局：两栏等宽 / 自定义权重；可左右对调（已选在左）
- 变体：基础 / 带搜索 / 带全选 / 可排序 / 树形穿梭
- 状态类：默认 / 禁用 / 只读

### 视觉状态
| 状态 | 栏 | 项行 | 箭头按钮 |
|---|---|---|---|
| default | 边框默认 | 正常 | 有可搬移项时才可用，否则禁用 |
| hover | — | 背景微亮 | 悬停加深 |
| focus-visible | — | — | 明显焦点环 |
| selected（项被勾选） | 计数不变 | 勾选框选中 + 行高亮 | 对应方向按钮变为可用 |
| disabled（单项） | — | 降透明、勾选框不可点 | 不参与可用性判定 |
| disabled（整控件） | 降透明、不可交互 | — | 禁用 |
| readonly | 外观正常、不可搬移 | — | 隐藏或禁用 |
| empty（栏内无项） | — | 空状态文案 | 该方向按钮禁用 |
| loading | — | 骨架 / spinner | 禁用 |
| error | — | 错误 + 重试入口 | 禁用 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 两栏等高；栏内列表**内部滚动**，栏高固定不随内容撑开
- 栏标题与计数左右对齐，计数随搬移实时更新
- 项文本超长截断 + tooltip
- 窄容器：两栏可上下堆叠

### 移动端
- 桌面双栏在窄屏体验差：改为**单栏 + 候选 / 已选两个切换页签**，或退化为多选弹层
- 触摸目标 ≥ 44×44，勾选与行点击区域合并
- 搬移按钮放大、间距拉开，避免误触

## 交互

### 触发与搬移
- **搬移方向**：勾选左侧项后点「→」搬到右侧；勾选右侧项后点「←」搬回左侧
- **单选移动**：勾一项点按钮即移动该项
- **整组移动**：勾「全选本栏」或多项后，点按钮一次搬移**全部已勾项**
- 搬移后：源栏勾选清空，焦点回到源栏（便于连续操作）
- 真正改变值的只有**按箭头搬移**——右栏内容即值

### 选中 / 输入行为
- 勾选只是**暂存**，勾选本身不改变值
- 搜索：在某一栏输入关键词，**只过滤该栏**，不影响另一栏
- 排序：已选栏可拖动排序（开启时），顺序即输出顺序
- 禁用项：不可勾选、不可搬移；已选栏的禁用项不可移回
- 全选：作用于**当前栏的可见（过滤后）项**——过滤与全选的交互必须先明确

### 键盘
| 按键 | 行为 |
|---|---|
| `Tab` | 依次聚焦 各栏勾选框 / 搜索框 / 箭头按钮 |
| `Space` | 勾选 / 取消当前项 |
| `↑` / `↓` | 项间移动焦点 |
| `←` / `→` | 切换两栏 或 触发对应方向搬移（按约定） |
| `Enter` | 触发当前按钮 / 移动 |
| `Home` / `End` | 跳到首 / 末项 |
| 聚焦箭头按钮时 | `Enter` / `Space` 执行该方向搬移 |

### 指针与手势
- 点击项行 → 切换勾选
- 点击箭头 → 搬移已勾项
- 拖动项跨栏（若支持）→ 直接搬移；拖动重排 → 调整已选顺序

### 焦点管理
- 搬移 / 搜索 / 过滤后**焦点不得丢到 body**，应回到源栏或搜索框
- 全选后焦点保留在「全选」控件上

### 动画与过渡
- 项在栏间移动：轻微位移 / 淡入淡出，约 100–200ms
- 计数变化即时更新，不闪烁

### 反馈
- 搬移本身即反馈（项出现在目标栏）
- 无可搬移项时箭头按钮**禁用**（而非无响应）
- 异步失败：栏内错误 + 重试，**不清空已选项**

### 边界交互
- 候选极多：虚拟滚动 + 搜索，避免一次性渲染
- 移动中数据变化：已选项若从候选数据中消失，须明确保留 / 剔除
- 快速多次搬移：以最新值为准，避免重复触发同一项

## 数据流

### 输入
- **全部数据源**：`{ 键, 展示文本, 是否禁用? }` 列表（可能带分组 / 层级）
- 初始已选集合（键集合）
- 配置：栏标题、尺寸、是否可搜索、是否可全选、是否可排序、布局权重、状态
- 数据来源：静态数组 / 远程接口

### 内部状态
- 各栏勾选集合（暂存，未落地为值）
- 各栏搜索词
- 已选栏排序
- 加载 / 错误（异步）
- 列表滚动位置

### 输出
- **值变化事件**：一次搬移 = 一次值变化，输出**新的已选集合**（完整集合，而非增量）
- 也可附带本次移动的项（供外部做动画 / 日志）
- **值形态必须明确**：是**键的数组**还是**对象数组**——决定回填、比较、默认顺序

### 受控 / 非受控
- 受控：已选集合由外部持有；点箭头**不直接改内部值**，只抛出「希望变为的新集合」，外部回传后右栏才更新
- 非受控：内部持有，给默认已选集合
- **二选一必须明确**；受控下若外部不回传，会出现「点了箭头项不动」

### 异步与竞态
- 远程数据 / 远程保存：加载 / 空 / 错误三态
- **竞态**：搬移触发的保存若并发，后发先至会覆盖；按请求标识或序号丢弃过期结果
- 搜索防抖；同一关键词可缓存

### 校验与错误
- 组件只负责「已选集合」；必选数量 / 至少一项等规则在表单层
- 错误由外部传入（标记 + 文案），组件负责呈现

### 回填与序列化
- 初值集合 → 拆成右栏；左栏 = 数据源 − 已选
- 若为键数组，按键查数据源取展示文本；查不到的键兜底显示原始键并标记「已失效」
- 比较按**键**（id）而非引用；输出顺序以已选栏排序为准

## 无障碍
- 两栏各为 `listbox`（多选），项 `option` + `aria-selected`
- 栏标题与列表用 `aria-labelledby` 关联
- 箭头按钮有可读名称（如「移入已选」「移回候选」），禁用时用 `aria-disabled`
- 计数变化用 `aria-live` 播报
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）

## 常见误用
- 选项只有几条也上穿梭框 → 过重，复选框组即可
- 高频轻量选择用它 → 每次搬移成本高，用户烦
- 候选上千却不做搜索 / 虚拟滚动 → 两栏都卡且难用
- 已选顺序有意义却不给排序
- 把「勾选」直接当值用 → 与「按箭头搬移才改值」的语义混淆
- 受控模式不回传新值 → 箭头点了没反应

## 边界与代价
- 占屏幕面积大（两栏）→ 窄屏 / 移动端必须换形态
- 候选 > 约 100 条：**必须**搜索 + 虚拟滚动
- 搬移是显式动作，不适合「随手多选」
- 值形态不明确（键 vs 对象、不按键比较）→ 回填与计数错乱
- 过滤 + 全选的语义不定义 → 用户以为全选全部，实际只选了可见项
