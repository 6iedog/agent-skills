# 树选择

以**可展开折叠的树**呈现层级，支持**跨层级多选**，并区分「全选 / 半选 / 未选」三种勾选状态。

## 角色与边界

- **是什么**：带勾选框的树，节点可展开折叠，勾选可自底向上联动父级。
- **解决什么**：数据有层级 + 需**跨层级多选**（权限 / 菜单配置、组织多选、多级分类多选）。
- **不解决什么**：
  - 层级 + 只需选一个结果 → 级联选择
  - 无层级多选 → 多选下拉 / 复选框组
  - 选项少、平铺即可 → 复选框组
- **什么时候不用**：层级深且只选一个叶子 → 级联更贴合路径语义；数据无父子关系 → 用普通多选。

## UI

### 结构解剖
- **树容器**：内嵌在页面 / 收在下拉浮层里（下拉树）
- **节点行**：缩进 + 展开 / 折叠箭头 + 勾选框 + 节点文本
- **展开箭头**：有子级时出现，控制本级子项显隐
- **勾选框**：三态——未选 / 已选 / **半选**（部分子级被选）
- **搜索框**（可搜索时）：置于顶部
- **触发器**（下拉树）：显示已选数量 / 折叠标签，右侧箭头
- **状态占位**：加载 / 空 / 错误位

### 尺寸与外观变体
- 承载：内嵌树 / 下拉树
- 尺寸：小 / 中 / 大 → 影响项行高、字号、缩进
- 联动：父子联动 / 仅勾自己（独立）
- 选择：多选（带半选）/ 单选
- 变体：可搜索 / 可异步加载 / 可虚拟滚动 / 可勾选任意层级

### 视觉状态
| 状态 | 节点行 | 勾选框 | 说明 |
|---|---|---|---|
| default | 正常 | 未选 | — |
| hover | 背景微亮 | — | — |
| focus-visible | 焦点环 | — | 键盘导航 |
| checked | 文字可加粗 | 已选（实心勾） | 该项被选 |
| 半选（部分选中） | — | 方块横线（**不是对勾**） | 部分子级被选，父级呈现 |
| expanded | 箭头翻转 | — | 子级显示 |
| disabled | 降透明、不可勾 | 不可点 | 是否参与父子联动计算须明确 |
| readonly | 外观正常、不可勾选 | 不可点 | 值照常提交 |
| loading | 该项显示 spinner | — | 异步加载子级 |
| error | 该项错误 + 重试 | — | 异步失败 |
| empty（搜索无果） | — | — | 空状态文案 |
| matched（搜索命中） | 匹配片段**高亮** | — | — |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 缩进层级清晰（每级固定缩进），长文本截断 + tooltip
- 容器限高 + 内部滚动；下拉树面板最大高度受限
- 搜索命中时自动展开路径、滚动定位到首个结果

### 移动端
- 触摸目标 ≥ 44×44，箭头与勾选框拉开间距防误触
- 下拉树改为**底部弹层**承载树
- 深层缩进在窄屏压缩，或减少每级缩进量

## 交互

### 展开与开合
- 点箭头 / 双击节点文本 → 展开 / 收起（点击行为可配置）
- 默认展开层级：可配置默认展开到第 N 层
- 下拉树：点触发器开合；Esc / 点外部关闭

### 勾选行为（核心）
- **父子联动模式**：勾父 → 其**全部子级**被勾；勾子 → 父级按子级情况显示「全选 / 半选 / 未选」（自底向上重算）
- **仅勾自己模式（独立）**：勾父不影响子，勾子不影响父；不出现半选态
- **半选态**：父级的部分（非全部）子级被勾时呈现半选，**半选不是值本身**，是派生显示
- 取消父级 → 全部子级取消；取消某子级 → 父级从「全选」降为「半选」
- 可勾选层级：任意层 / 仅叶子——仅叶子时不显示父级勾选框
- 禁用节点：不可勾选，是否参与父子联动的向上传播须明确

### 搜索
- 输入关键词 → 过滤匹配节点，**自动补全路径**并展开至命中项
- 匹配片段**高亮**；命中节点的祖先路径按需显示
- 清空搜索恢复原树与展开状态（是否保留原状态须明确）

### 键盘
| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在可见节点间移动 |
| `→` | 展开当前节点；已展开则进入第一个子节点 |
| `←` | 收起当前节点；已收起则回到父节点 |
| `Space` | 勾选 / 取消当前节点 |
| `Enter` | 展开 / 收起 或 勾选（按约定） |
| `Home` / `End` | 跳到首 / 末个可见节点 |
| 字母键 | typeahead 跳转；搜索模式下由搜索框接管 |

### 指针与手势
- 点勾选框 → 勾选 / 取消
- 点箭头 / 双击文本 → 展开 / 收起
- 悬停节点背景微亮

### 焦点管理
- 树内采用「单一可聚焦节点」（roving tabindex）
- 下拉树关闭后焦点**回到触发器**
- 搜索后焦点保留在搜索框

### 动画与过渡
- 展开 / 收起：高度过渡或淡入，约 100–200ms
- 勾选联动导致的兄弟节点状态变化应即时，不卡顿

### 反馈
- 勾选即时反映在节点与父级（半选）状态
- 下拉树触发器实时更新已选计数 / 标签
- 异步加载子级显示加载 / 失败重试

### 边界交互
- 节点多：虚拟滚动，仅渲染可见节点
- 搜索命中多：限定结果数 + 「共 N 项」，避免全量展开
- 异步加载中勾选父级：子级未加载完成时如何联动须先明确（加载后再补算）

## 数据流

### 输入
- **树形数据**：节点 `{ 值, 展示文本, 是否禁用?, 子级? }`；子级可预置或按需加载
- 初始勾选集合
- 配置：多选 / 单选、父子联动 / 独立、可勾选层级（任意层 / 仅叶子）、默认展开层级、是否可搜索、是否异步、尺寸与状态
- 数据来源：静态树 / 远程接口

### 内部状态
- 展开集合（哪些节点展开）
- 勾选集合（键 → checked）
- 半选集合（派生）
- 搜索词与匹配结果
- 加载 / 错误（异步）
- 聚焦节点（键盘）
- 滚动位置

### 输出
- **值变化事件**：输出**已选集合**（checked 的值为数组）
- 半选态是否也输出：**必须先明确**——通常半选只用于显示、不进值；若业务需要「父级代表子树」，则需附带半选集合，否则回填无法还原父级语义
- 值形态：**键的数组**或**对象数组**（决定回填与比较）
- 展开 / 搜索事件（可选）

### 受控 / 非受控
- 受控：勾选集合由外部持有，组件只抛出新集合，自身不存值
- 非受控：内部持有，给默认勾选
- **二选一必须明确**；混用会出现「勾了又跳回」或「外部改了不刷新」

### 异步与竞态
- 子级按需加载：显示加载 / 空 / 错误三态，已加载缓存
- **竞态**：多节点并发加载时按「父节点标识 + 序号」丢弃过期结果
- 父级联动依赖子级：子级未加载时勾父，须在加载完成后**补算**子级与半选态

### 校验与错误
- 组件只负责「勾选集合」；必选数量等规则在表单层
- 错误由外部传入（标记 + 文案），组件负责呈现

### 回填与序列化
- 初值集合 → 勾选对应节点，并**自底向上重算父级**的半选 / 全选状态
- 若只回填了部分叶子，父级须自动变为半选（不能只描红叶子而父级仍是未选）
- 懒加载时父级状态需在子级加载完成后重算
- 比较按键（id），不按引用

---

## 无障碍
- 树：`tree` 角色；节点 `treeitem`，带层级、展开态、勾选态（支持表达半选）
- 采用单一可聚焦节点的键盘导航，全键盘可达
- 搜索高亮用可访问方式呈现（非仅靠颜色）
- `focus-visible` 可见（禁止无替代的 `outline: none`）
- 禁用节点标 `aria-disabled`

---

## 常见误用
- 父子联动与独立勾选**混着来** → 语义混乱，「勾父带不带子」必须明确
- 无搜索 + 节点多 → 找不到目标
- 层级深却全量展开 → 一屏看不过来，性能也差
- 只需选一个却用树多选 → 应级联
- 半选态被误当作值提交 → 回填后父级状态错乱
- 异步加载中不补算子级状态 → 勾父后子级仍显示未选

## 边界与代价
- 节点 > 约数十个：**必须**可搜索（+ 虚拟滚动）
- 父子联动规则（联动 / 独立 / 半选 / 禁用节点是否可见）必须**先明确**，否则状态无法自洽
- 深层级 + 异步：展开加载、失败重试、父级补算都要处理
- 半选语义不进值 → 回填时父级的「部分选中」无法还原，只能靠叶子重算
