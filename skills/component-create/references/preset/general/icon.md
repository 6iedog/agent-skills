# 图标

用**一个图形符号**表达含义或辅助含义的最小视觉元素，可纯装饰也可承载语义。

## 角色与边界

- **是什么**：一段大小、颜色可控的矢量 / 字形符号，用来示意操作、状态、类别或方向。
- **解决什么**：在有限空间里快速传达含义，或用图形辅助文字、降低识别成本。
- **不解决什么**：
  - 不解决「需要明确无歧义的操作入口」 → 带文字的按钮（图标含义常有歧义）
  - 不解决「承载一段说明」 → 文字提示 / 就地说明
  - 不解决「可点击且独立成控制」 → 图标按钮（区别于纯展示图标）
  - 不解决「品牌 / 插画级的大图」 → 图片 / 插画组件
- **什么时候不用**：图形含义不直观且无文字辅助 → 加文字或换文案；纯装饰又会被读出 → 加装饰标记使辅助技术忽略。

## UI

### 结构解剖
- **图形本体**：矢量路径或字形，单色为主，可多色
- **容器（可选）**：图标按钮里的包裹层，提供命中区与背景
- **可访问名称载体（可选）**：为有语义的图标提供等价文字
- **旋转 / 加载形态**：连续旋转的加载图标

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 / 超大 | 与相邻文字字号成比例，常同字号或略大 |
| 颜色 | 继承当前文字色 / 指定色 / 语义色 | 默认应继承文字色以便融入文案 |
| 线型 | 线性（描边）/ 面性（填充） | 同一场景尽量统一一种，不混用 |
| 用途 | 纯装饰 / 有语义 | 决定是否需要可访问名称 |
| 状态 | 静态 / 旋转（加载）/ 可交互 | 可交互时须有命中区与焦点态 |
| 组合 | 独立 / 与文字并排 / 前置后置 | 与文字的间距与基线对齐要统一 |

- **颜色继承是默认期望**：图标应能跟随父级文字色，便于在按钮、链接、状态文案中复用而不写死颜色。
- **线宽与尺寸要成套**：同一尺寸档使用一致的线宽，混用会显得杂。

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态颜色（通常继承文字色） |
| hover（可交互时） | 颜色加深或背景微亮 |
| active（可交互时） | 颜色进一步加深或轻微缩小 |
| focus-visible（可交互时） | 明显焦点环，落在受控元素上 |
| disabled（可交互时） | 降透明、不可点 |
| spinning（加载） | 持续匀速旋转，不可暂停 |
| selected / active（表示选中） | 与未选中形成颜色 / 填充对比 |

- 纯装饰图标**无交互态**，只作为图形随父元素一起变化。

### 布局与对齐
- 图标与相邻文字的**基线或视觉中心对齐**，不能只按盒模型顶端对齐。
- 图标四周保留呼吸间距，与文字间距统一，避免贴字或过大间隙。
- 单个图标在按钮 / 标签内应居中，不因线型不同而视觉偏移。
- 多个图标并排时按统一尺寸栅格对齐。

### 移动端
- 作为可点击对象的图标（图标按钮）触摸目标 ≥ 44×44，**视觉大小可小但命中区要大**（外扩透明区）。
- 触摸端不依赖 hover 表达状态，可交互图标需按下即反馈。
- 图标在深色 / 浅色背景下都要保证对比度。

## 交互

### 核心操作
- 纯展示图标无操作；可交互图标（图标按钮）承载点击 / 聚焦 / 触发。
- 加载图标只表示「进行中」，不可点击、不被误当按钮。
- 有语义的图标可通过悬停显示文字提示补充含义（提示本身不可交互）。

### 输入与选中行为
- 图标自身无输入；作为切换控件时，其选中 / 未选中态由外部状态驱动。
- 图标作为可访问名称载体时，名称不随视觉隐藏而丢失。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 纯装饰图标 | — | 不进入键盘序列，不接收焦点 |
| 可交互图标 | `Tab` / `Shift+Tab` | 聚焦 / 移出 |
| 可交互图标 | `Enter` / `Space` | 触发对应动作 |
| 图标内不可独立聚焦 | — | 焦点落在所属控件上，而非图形本身 |

### 指针与手势
- 纯展示图标不响应指针。
- 可交互图标 hover 给反馈、按下即触发；触摸端点击触发并即时反馈。
- 悬停图标可显示文字提示，但图标本身命中区应覆盖整个可点区域。

### 焦点管理
- 纯装饰图标**不可获得焦点**。
- 可交互时焦点落在包裹控件（按钮 / 链接）上，图形不单独接收焦点。
- 焦点环属包裹控件，图标不重复绘制焦点环。

### 动画与过渡
- 加载图标匀速旋转，不自带加速 / 减速，避免分散注意。
- 图标状态切换（如展开箭头翻转、选中断变化）用短过渡，约 100–200ms。
- 旋转动画在图标隐藏时应停止，避免后台空转耗电。

### 反馈
- 图标不产生业务反馈；可交互图标的点击结果反馈由所属控件与上层负责。
- 状态类图标（成功 / 警告 / 错误）的颜色即反馈，应带等价可访问文本。

### 边界交互
- 图标尺寸随父容器缩放时保持清晰（矢量为宜，位图会糊）。
- 极窄容器中图标与文字同时存在时，明确是省略文字还是缩小图标。
- 图标含义可能因文化 / 语境不同而歧义 → 关键操作必须有文字或提示兜底。

## 数据流

### 输入
- **图标标识**：指向具体图形的名称或引用。
- 尺寸、颜色（或继承开关）、线型、是否旋转。
- 是否为装饰、可访问名称（有语义时）。

### 内部状态
- 基本无：仅加载图标维持旋转相位。
- 可交互时由所属控件持有焦点 / 按下态，图标本身不存状态。

### 输出
- 纯图标**无输出**。
- 可交互时由所属控件抛出事件，图标不单独输出业务值。

### 受控 / 非受控
- 图标是**纯展示**，无受控 / 非受控之分。
- 颜色与尺寸由外部配置驱动；是否旋转由外部传入的加载状态驱动（受控）。

### 异步与竞态
- 图标本身不做异步。
- 若图标来源为异步加载的图形集，需处理加载与失败占位，避免出现空白坑位。

### 校验与错误
- 图标不承担校验。
- 图形标识无效 / 缺失时要有兜底占位，不能渲染成空白或破图。

### 回填与序列化
- 无值回填概念；图标标识与配置可来自数据，变化时同步刷新。
- 若图标标识在运行时不稳定（改用名称而非编号），回填要按标识解析。

## 无障碍
- **纯装饰图标**：标记为装饰，使辅助技术跳过，不被读出。
- **有语义图标**：必须提供等价可访问名称（如「关闭」），且与视觉图形一致。
- 作为按钮的图标：名称描述**动作**，而非「一个图标」；例如读作「删除」而非「垃圾桶图标」。
- 图标**不能是信息的唯一载体**：颜色、形状表达的状态要有文本等价。
- 可交互图标需全键盘可达，焦点环可见。
- 图标按钮的触摸 / 点击命中区足够大，不只图形本体。

---

## 常见误用
- 纯装饰图标被屏幕阅读器读出，制造朗读噪音。
- 有语义图标无可访问名称 → 只读作「图标」或读不出。
- 命中小但视觉大 / 视觉小但命中也小 → 触摸端难点。
- 用图标单独承载关键信息（如仅用颜色表示错误）→ 色觉障碍与辅助技术不可知。
- 同一界面线性与面性图标混用、线宽不一 → 视觉杂乱。
- 把加载图标做成可点击 → 误触发。
- 图标颜色写死，不继承文字色 → 在按钮 / 状态文案里突兀。
- 图形含义歧义（如「星」既可收藏也可评分）却无文字兜底。

## 边界与代价
- 图标**不得成为唯一信息源**，否则无障碍缺失。
- 有语义图标**必须**有等价名称，否则语义丢失。
- 命中区小于触摸标准 → 移动端不可用。
- 位图图标在大尺寸下模糊 → 优先矢量。
- 图标集异步加载失败无占位 → 出现空白 / 破图。
- 线型混用与线宽不统一 → 是观感问题，也是整套图标体系不一致的信号。
