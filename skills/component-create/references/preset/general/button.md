# 按钮

点击后**立即触发一个动作**的最基本控件，可带文字、可只带图标。

## 角色与边界

- **是什么**：可聚焦、可点击、执行单一动作的控件；通常带文字标签，也可仅图标。
- **解决什么**：让用户主动发起一件事——提交、保存、删除、打开、刷新、导航到下一步。
- **不解决什么**：
  - 不解决「在多个互斥选项里选一个」 → 单选按钮组 / 分段控件
  - 不解决「开启或关闭某个状态」 → 开关 / 复选框
  - 不解决「锚点跳转且应可复制、可右键新窗口打开的链接」 → 用链接
  - 不解决「多个关联动作 + 溢出更多」 → 按钮组 + 下拉面板
  - 不承担业务校验与提交逻辑 → 那是表单层的事，按钮只负责「被按下」
- **什么时候不用**：目标本身就是一个 URL 且用户会想复制链接 → 用链接；纯展示状态（如「已启用」）→ 标签 / 徽标，不要做成假按钮。

## UI

### 结构解剖
- **容器**：圆角矩形，承载文字与图标
- **标签**：主文字，一到几个词；可省略（图标按钮）
- **前置图标 / 后置图标**：表示动作或方向，可选
- **加载指示**：进行中的 spinner，替换或并列于图标位
- **危险色态**：用于破坏性动作的着色变体
- **按钮组**：多个按钮拼合的容器，共享边框或间距
- **计数 / 徽标**：挂在按钮角上的数字或圆点（可选）

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 影响高度、内边距、字号、图标尺寸 |
| 形态 | 实心 / 描边 / 文字（幽灵）/ 链接 | 由强调程度决定，一屏内实心至多一个主按钮 |
| 宽度 | 自适应内容 / 块级占满父容器 | 块级用于表单底栏、移动端主操作 |
| 内容 | 文字 / 图标 + 文字 / 纯图标 | 纯图标**必须**补可访问名称 |
| 状态类 | 默认 / 危险 / 成功（按需） | 危险色仅用于不可逆或破坏性动作 |

- 强调层级：一屏内主操作（实心）**只应有一个**，次级用描边，再次级用文字 / 链接。
- 图标与文字间距、图标与文字的对齐基线要统一，避免不同按钮视觉高度不一。

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态底色 / 边框 / 文字色 |
| hover | 底色或边框加深，可加轻微抬升 |
| active（按下） | 底色进一步加深，可有轻微下沉感 |
| focus-visible | 明显焦点环，不可用无替代的 outline 清除 |
| disabled | 降透明度、禁用指针、不可聚焦、不触发 |
| loading | 显示 spinner，交互被锁定，尺寸不跳动 |
| danger | 使用破坏色；hover / active 同步加深 |
| toggled（可按压切换时） | 保持按下态着色，与 hover 区分 |
| block（块级） | 占满宽度，左右不留白 |

- **loading 与 disabled 要分开**：disabled 是「不可用」，loading 是「正在用，请稍候」；loading 期间应保留按钮宽度避免布局跳动。

### 布局与对齐
- 一屏内的按钮应按**主次顺序**排列；常规做法：主操作在右（表单 / 对话框底栏），移动端主操作在底部或占满整行。
- 按钮高度与同区域输入框对齐（同一表单行内不出现高低不齐）。
- 相邻按钮间距统一；按钮组内相邻边框合并，避免双线。
- 同一容器内多按钮换行时保持对齐网格，不出现半个按钮溢出。

### 移动端
- 主操作优先**块级**或靠底部固定，便于拇指触达。
- 触摸目标 ≥ 44×44；纯图标按钮尤其要放大命中区（可加透明外扩）。
- 文案简短，避免按钮里长句子换行。
- 加载态仍要能看清状态，不能被软键盘顶出可视区。

## 交互

### 触发与提交
- 主触发：鼠标点击、触摸点按、`Enter` / `Space`（聚焦时）。
- 点击即触发**一次**动作；不要用双击、长按承载主操作。
- 若动作会打开弹层或跳页，视觉上应能预期（图标 / 文案提示），不产生意外跳转。

### 防重复点击
- 提交类按钮在动作发起后进入 **loading 或 pending**，期间忽略后续点击，防止重复提交。
- 防抖是**组件行为**：不能只靠使用者自觉加状态。
- 若动作很快完成（本地即时操作）可不锁，但派发后短时间内重复触发仍需去重。

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` / `Shift+Tab` | 聚焦 / 移出（disabled 跳过） |
| `Enter` | 触发动作 |
| `Space` | 触发动作（松开时） |
| `Esc` | 不作用于按钮；若在弹层内则交由弹层关闭 |

- 纯图标按钮在键盘序列里**不可被跳过**，且需能被读出名称。
- 若按钮可按压切换，`Space` / `Enter` 切换其按下态并同步可访问状态。

### 指针与手势
- hover 仅作视觉反馈，不承载信息。
- 触摸端无 hover：按下即给出即时反馈，抬起触发；拖出按钮再松手应**取消触发**。
- 破坏性动作若绑定长按（少见），必须另有明确可点击路径。

### 焦点管理
- 点击后焦点停留在按钮（不跳走），除非动作本身把焦点移交给新内容（如打开对话框）。
- 对话框 / 弹层关闭后，焦点回到触发它的按钮。
- loading 期间若按钮被禁用，需保留其实体与焦点语义，避免焦点丢失。

### 动画与过渡
- hover / active 的颜色与位移过渡短促（约 100–200ms），不拖沓。
- loading spinner 常驻旋转，不与按钮出现 / 消失动画冲突。
- 尺寸变化（如文字变加载）要**预留宽度**，不引起布局抖动。

### 反馈
- 动作结果反馈属于上层：成功提示、错误提示、禁用原因由业务决定。
- 同步即时动作（如展开）可只用视觉变化反馈。
- 禁止「点了没任何反应」——至少要有按下态或 loading。

### 边界交互
- 表单未通过校验时，主按钮应可点击并在点击后暴露错误（或明确禁用并给出原因），不要静默无响应。
- 极长文案：截断或换行策略要明确，不撑破容器。
- 并排多按钮在窄屏下换行，主操作仍保持可达。

## 数据流

### 输入
- **标签文本**、图标、尺寸、形态、是否禁用、是否加载、是否块级、危险标记。
- 无「值」概念，只有配置与可选的点击前确认配置。

### 内部状态
- 极少：主要为自身是否处于 loading / pressed（可按压切换时）。
- 防重复点击的**派发锁**（短时去重）。

### 输出
- **点击事件**：不携带业务值，业务数据由外层闭包或动作标识携带。
- 若为按压切换按钮，输出切换后的**按下态**。
- 不输出表单值（按钮不进表单字段）。

### 受控 / 非受控
- 按钮通常**非受控**（自管按下反馈）。
- 若为可按压切换，其按下态应由外部受控（避免视觉与真实状态不一致）。
- loading 态**必须受控**：由动作的进行中状态驱动，不能按钮自管。

### 异步与竞态
- 按钮本身不发起异步；但**必须配合**异步动作：发起即锁定，完成后解锁。
- 竞态防护：连续点击/请求应只保留一次有效派发；后到的重复触发直接丢弃。
- 若同一按钮可能被不同来源重复触发，去重键需明确（按动作 id 或时间窗）。

### 校验与错误
- 按钮不做校验；校验失败表现为「按钮点击后上层展示错误」或「按钮禁用 + 原因」。
- 禁用必须给出理由（提示或就地说明），否则用户不知为何点不了。

### 回填与序列化
- 无值回填概念；标签 / 图标可来自配置或运行时数据，变化时同步刷新。
- 若按钮文案随状态变（如「保存中…」），状态变更要幂等，不出现文案与真实态错位。

## 无障碍
- 用**原生按钮语义**，而非给容器硬加点击事件后冒充按钮。
- 纯图标按钮必须提供可访问名称（等价文案），且该名称不随视觉隐藏而丢失。
- 状态要能被读出：disabled、pressed、busy（loading）应通过可访问状态表达。
- 全键盘可聚焦、可触发；`focus-visible` 必须可见。
- 加载中提示对辅助技术可感知（如「正在提交」）。
- 按钮组应有分组语义，组内按钮各自可读。

---

## 常见误用
- 一屏放多个实心主按钮 → 主次不分，用户不知该点哪个。
- 用按钮做链接（或反之） → 语义错、右键菜单与快捷键行为异常。
- 纯图标按钮不写可访问名称 → 屏幕阅读器读不出。
- 提交按钮不自带防重复 → 用户连点产生重复订单 / 重复提交。
- 用 disabled 掩盖「其实该给加载态」的场景 → 用户不知道是在进行还是坏了。
- 用文字按钮承担危险操作 → 误点代价高，应使用危险色或改二次确认。
- 破坏性动作与普通操作外观一致 → 缺少警示层级。

## 边界与代价
- 提交类按钮**必须**内建防重复点击，否则是不可接受的缺陷。
- loading 与 disabled 混为一谈 → 用户无法区分「等待」与「不可用」。
- 一屏多个实心按钮 → 认知负担与误点率上升。
- 禁用而不给理由 → 用户卡死。
- 按钮宽度随加载 / 文案变化 → 布局抖动，尤其在并排按钮中。
- 用非原生元素伪装按钮 → 键盘、屏幕阅读器、右键全部失效。
