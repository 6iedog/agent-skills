# 面包屑

从根到当前页的**层级路径链**，除末项外每级可点击，用来回答「我在哪、怎么上去」。

## 角色与边界

- **是什么**：一条横向路径，逐级展示当前页在系统中的位置；中间层级是跳转入口，末项是当前页。
- **解决什么**：层级较深的系统里，用户需要知道自己在哪一层、并快速回退到某一上级。
- **不解决什么**：
  - 不承担站在主导航（全站功能入口）→ 导航菜单
  - 不承担同级内容的互斥切换（不换层级）→ 标签页
  - 不承担页面内章节定位 → 锚点
  - 不承担「已走几步」的流程进度 → 步骤条
  - 不同于浏览器返回：返回是**历史回退**（可能跨层级来回），面包屑是**沿层级上溯**（只向上，不含横向历史）
- **什么时候不用**：结构只有一层、没有父级；页面标题本身已完整表达位置；流程是线性推进（应用步骤条）；移动端宽度极窄且层级价值低时可只保留「返回上级」。

## UI

### 结构解剖
- **容器**：横向一行，通常放在页面标题上方
- **层级项**：文字（可含图标，如首页图标）；可点击项与不可点击项样式区隔
- **分隔符**：位于相邻项之间（斜杠 / 箭头 / 点），纯装饰、不参与点击
- **当前项**：末项，代表当前页，**不可点击**，视觉上更重或更淡
- **折叠触发**：层级过多时出现的省略标记（如「…」），点击 / 悬停展开被隐藏的中间层级
- **展开浮层**：列出被折叠的中间层级，供跳转
- **可选背景条**：整条位于一条浅底 / 分隔线之上

### 尺寸与外观变体
- 尺寸：小 / 中 → 影响字号、项间距、图标大小
- 分隔符样式：斜杠式 / 箭头式 / 圆点式
- 是否含首页图标项
- 外观：无背景（融入页面）/ 带浅背景条或底部分隔线
- 末项处理：加粗强调 / 降为次要色 / 保持常态

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 可点项为链接色 / 常态色，末项为文本色 |
| hover | 可点项下划线或变色 |
| focus-visible | 可点项出现明显焦点环 |
| current | 末项：不可点、无 hover、标为当前 |
| active（按下） | 可点项按下时颜色加深 |
| collapsed | 中间层级收起为省略标记，标记本身可点 |
| disabled | 个别层级因无权限不可点 → 降透明、禁用指针 |

- **可点与不可点必须有视觉差异**：否则用户会反复点末项或误以为中间项也不可点。

### 布局与对齐
- 单行横向排列，与页面内容左对齐
- 项文字过长时逐个截断，悬停显示完整标题
- 整条宽度受限，放不下时**先折叠中间层级**，而不是让整条换行
- 折叠规则：通常保留「第一项 + 省略 + 最后 1–2 项」

### 移动端
- 宽度不够时：只显示「返回上级 + 当前页」，或折叠为单一返回入口
- 项间距适当收紧，触摸目标 ≥ 44×44（必要时给项加内边距）
- 不强制横向滚动整条路径——触摸端横向滚动命中率低

## 交互

### 触发与导航
- 点击某个中间层级项 → 跳转到该层级对应的页面
- 末项（当前页）点击**无响应**，也不应表现为可点
- 折叠标记 → 展开被隐藏的层级，供进一步跳转
- 跳转是**层级上溯**，不影响浏览器前进 / 后退历史栈的语义（仍会写入一条历史）

### 展开与折叠
- 层级超过设定的折叠阈值 → 自动折叠中间层级
- 折叠标记：悬停或点击展开浮层；浮层列出被隐藏项
- 浮层内选中一项 → 跳转并收起
- `Esc` 或点击外部 → 收起浮层，不改变当前页

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在可点击的层级项之间移动 |
| `Enter` / `Space` | 激活当前聚焦的层级项 / 折叠标记 |
| `Esc` | 关闭展开的浮层（若有） |
| `↑` / `↓` | 浮层展开后，在隐藏层级之间移动 |

- 分隔符与末项不进入 Tab 序列。

### 指针与手势
- 点击可点项跳转；悬停给出下划线 / 变色反馈
- 折叠标记悬停或点击展开浮层
- 移动端点击项即跳转，无 hover 态

### 焦点管理
- 跳转后焦点交由目标页处理（通常落到页面主标题）
- 浮层关闭后焦点**回到折叠标记**
- 不使用 `tabindex` 让末项可聚焦

### 动画与过渡
- 折叠浮层：淡入淡出 + 轻微位移，约 100–200ms
- 路径本身切换（换页）由路由承担，面包屑自身不做位移动画
- 不引起布局抖动

### 反馈
- 导航本身即反馈（页面切换）
- 浮层展开 / 收起有即时视觉反馈
- 无权限层级可给出禁用态或点击后提示

### 边界交互
- **与浏览器返回的关系**：面包屑只表达「层级向上」，浏览器返回表达「历史回退」。二者方向、范围不同，**不能互相替代**；不要因为页面上有面包屑就不提供返回能力，也不要用面包屑假装实现返回
- 层级过多：折叠中间层级，避免整条溢出
- 中间层级对应页面不存在 / 无权限：该项设为禁用或从路径中省略
- 末项标题过长：截断，不换行

## 数据流

### 输入
- **层级项列表**：`{ 标题, 路径?, 图标?, 是否可点? }` 的有序数组（首项为根，末项为当前页）
- 配置：分隔符样式、尺寸、折叠阈值、是否显示首页项
- 数据来源：由当前路由 / 页面元信息生成，或后端返回层级路径

### 内部状态
- 折叠浮层是否展开
- 浮层内高亮索引（键盘导航）
- 是否需要折叠（由阈值与层级数决定）

### 输出
- **导航事件**：被点击层级的标识 / 路径
- 折叠展开 / 收起事件（供埋点或联动）
- 组件**不持有页面的业务数据**，只抛出「去了哪一层」

### 受控 / 非受控
- 层级项由外部传入（受控）；组件不在内部推导层级
- 折叠展开默认内部自管；如外部需要联动可提为受控
- 末项是否可点由「是否为末项」与外部显式配置共同决定，**不要由外部随意改**

### 异步与竞态
- 层级路径若来自远程（如按 id 拉取祖先链），需处理加载态
- **竞态**：连续切换页面导致多次路径请求时，按最新请求标识丢弃过期结果

### 校验与错误
- 组件不做业务校验
- 路径项缺失（无 `路径`）时该项不可点，视觉上与当前项区分
- 层级无法解析时报错由使用方处理，组件回退为「只显示当前页标题」

### 回填与序列化
- **当前页高亮由是否为末项决定**，不需要额外标选
- 层级路径通常由路由状态反推；若需与 URL 对齐，应保证路径片段与路由层级一致
- 分隔符仅为装饰，不参与任何值的比较

## 无障碍
- 外层用导航区域并附可读标签（如「面包屑」）
- 层级用**有序列表**表达，保证层级语义与顺序
- 当前项标注为「当前页」语义，屏幕阅读器可读
- 分隔符标记为装饰，避免被读出为内容
- 折叠标记有明确可读名称（如「显示更多层级」）
- 全键盘可达；可点项 `focus-visible` 可见（禁止无替代的焦点移除）

---

## 常见误用
- 当作主导航使用 → 它只表达层级与上溯，不承载功能入口
- 层级很浅或页面标题已足够时仍强加面包屑 → 冗余
- 末项也做成可点 → 违背「当前位置」语义
- 层级过多却不折叠 → 整条溢出、被截断
- 用面包屑替代「返回」→ 二者语义不同，会误导用户
- 移动端照搬完整横向路径 → 挤压标题、难以点中

## 边界与代价
- 层级超过约 3–4 级：**必须**折叠中间层级，否则溢出
- 移动端：应收敛为「返回 + 当前页」，不照搬桌面形态
- 中间层级无权限或无对应页面时若不处理 → 出现死链接
- 末项与中间项缺少视觉区隔 → 用户反复点当前页
- 误把面包屑当作返回 → 用户对「上一步去哪」产生错误预期
