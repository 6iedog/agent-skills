# 标签页

在同一上下文里并列切换多组内容面板，**同一时刻只显示一个**，是同级、无顺序的互斥切换。

## 角色与边界

- **是什么**：一组标签 + 对应内容面板，切换标签即切换面板；标签间平级、无先后顺序。
- **解决什么**：把相关但不需同时可见的内容分组，共享同一页面上下文，避免整页跳转。
- **不解决什么**：
  - 不承担跨页面的功能导航 → 导航菜单
  - 不承担有先后顺序的流程 → 步骤条
  - 不表达层级路径 → 面包屑
  - 不表达数据分页 → 分页
  - 若切换本质是「换一个 URL / 换一份数据视图」且希望可分享 / 可回退，需明确其与路由的关系（见下），但组件本身不负责路由
- **什么时候不用**：内容需要顺序阅读；标签过多（> 约 7 个）导致拥挤；两组内容本应同时可见（用并列布局而非切换）。

## UI

### 结构解剖
- **标签列表**：承载所有标签，横向或纵向排列
- **标签**：图标（可选）+ 文字 + 可选关闭按钮；选中态有指示（线条 / 卡片 / 胶囊）
- **指示条 / 选中块**：随当前标签移动的视觉标记
- **面板容器**：显示当前标签对应内容
- **溢出入口**：标签过多时收纳为下拉「更多」或提供滚动按钮
- **新增标签入口**（可选）：如「+」用于动态添加
- **滚动按钮**：横向溢出时的左右滚动控件

### 尺寸与外观变体
- 位置：**顶部**（横向，最常见）/ **侧边**（左侧竖排，适合较多标签）
- 外观：**线条式**（下划线指示）/ **卡片式**（边框块）/ **胶囊式**（圆角填充）
- 是否可关闭
- 是否可新增
- 是否溢出滚动 / 收纳
- 尺寸：小 / 中 / 大

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 未选中标签，次要色 |
| hover | 文字变色 / 背景微亮 |
| focus-visible | 明显焦点环 |
| selected | 当前标签：强调色 + 指示条 / 卡片选中样式 |
| active（按下） | 按下时背景加深 |
| disabled | 标签不可点：降透明、禁用指针 |
| closable | 可关闭标签在 hover 时显形关闭按钮 |
| overflow | 超出容器的标签折叠进「更多」或需滚动查看 |

- 选中指示（下划线 / 侧边条 / 卡片态）必须清晰且随切换平滑移动。
- 关闭按钮默认隐藏、hover / 聚焦时才显形，避免视觉噪声（但键盘聚焦该标签时也应可见）。

### 布局与对齐
- 顶部：横向排列，左对齐；溢出时滚动或收纳进「更多」
- 侧边：纵向排列，面板在右
- 标签宽度：内容自适应 / 固定等宽——需二选一，切换时不应跳动
- 指示条与标签文字对齐，随切换过渡而非瞬移

### 移动端
- 顶部横向标签可**横向滚动**（触摸滑动），不做窄屏压缩
- 侧边标签在窄屏收纳为下拉选择
- 触摸目标 ≥ 44×44
- 关闭按钮在触摸端要足够大且不误触

## 交互

### 触发与切换
- 点击标签 → 切换到对应面板
- 切换后**只有当前面板可见**，其余隐藏
- 是否保留非当前面板的挂载状态（保留 DOM / 卸载）需明确，影响内部状态与性能

### 选中与关闭行为
- 选中互斥，同一时刻只有一个标签激活
- **关闭标签**：
  - 关闭当前标签 → 自动选中**相邻标签**（通常右侧，无则左侧）
  - 关闭非当前标签 → 当前标签不变
  - 可配置「至少保留一个」或允许全部关闭（清空态）
- **新增标签**（若支持）：新增后激活新标签

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 焦点进入标签列表；再 `Tab` 进入面板内容 |
| `←` / `→` | 标签间移动（水平布局） |
| `↑` / `↓` | 标签间移动（垂直 / 侧边布局） |
| `Home` / `End` | 跳到首 / 末标签 |
| `Enter` / `Space` | 激活聚焦标签（**手动激活**模式下） |
| `Delete` / `Backspace` | 关闭聚焦标签（可关闭时） |

- **自动激活 vs 手动激活**必须明确：自动激活是方向键移动即切换面板，手动激活是移动仅聚焦、`Enter` 才切换。键盘可达性上手动模式更省心。

### 指针与手势
- 点击标签切换；移动端横向滑动标签条
- 中键 / 长按可提供「在新视图打开」等（由使用方决定，非组件核心）
- 关闭按钮点击即关闭并不触发标签切换

### 焦点管理
- 关闭一个标签后，焦点移到接替选中的标签
- 手动激活模式下，方向键移动只移焦点、不改选中
- 面板切换后，焦点通常保留在标签上（不强制跳入面板）

### 动画与过渡
- 指示条 / 选中块：平滑移动（位移过渡），约 150–250ms
- 面板切换：淡入或轻微位移；避免高度剧烈跳动
- 首次激活面板的懒加载应有骨架 / 加载态，避免空白闪一下
- 尊重「减少动效」偏好

### 反馈
- 切换即时可见（面板替换即反馈）
- 面板懒加载时显示加载态
- 关闭标签给出即时消失反馈
- 若切换相当于导航，可由外层更新 URL

### 边界交互
- **超出滚动**：标签多于容器宽度 → 滚动或收纳；选中标签应自动滚入可视区
- **面板懒加载**：非当前面板默认不渲染 / 不请求，首次激活才加载；是否缓存已加载面板需明确
- 标签过多：> 约 7 个考虑换形态（下拉、侧边、树）
- 受控切换：由外部状态驱动，点击只抛「请求切换」
- 标签禁用：不可点且不进 Tab 序列

## 数据流

### 输入
- **标签列表**：`{ 键, 标题, 图标?, 是否禁用?, 是否可关闭? }` 的有序数组
- **当前激活键**
- 配置：位置、外观、尺寸、是否可关闭 / 新增、激活模式（自动 / 手动）

### 内部状态
- 激活键（非受控时）
- 指示条位置（用于动画）
- 已加载面板集合（懒加载）
- 标签条滚动位置
- 键盘聚焦的标签（手动激活模式）

### 输出
- **切换事件**：新激活的键
- **关闭事件**：被关闭的键
- **新增事件**（若支持）
- 键是回填与比较的依据，**必须稳定**（不用会变的显示文本作键）

### 受控 / 非受控
- 激活键**二选一**：受控时由外部（路由 / 页面状态）持有，组件只抛请求；非受控时给默认键
- 受控切换常见于「标签与 URL 联动」：激活键进查询参数，刷新 / 分享可恢复
- **混用会出现「点了不切换」或「外部改了不刷新」**

### 异步与竞态
- 面板内容懒加载：首次激活才请求；显示加载态
- **竞态**：快速来回切标签导致多次请求，按标签键 / 请求标识丢弃过期结果
- 已加载面板可缓存，避免来回切换重复请求

### 校验与错误
- 组件自身不做业务校验
- 面板加载失败显示错误态 + 重试，且不应影响标签切换本身
- 受控切换若被外部拒绝（如未保存拦截），由外层处理，组件呈现结果

### 回填与序列化
- 激活键写 URL 时，键需稳定且可合法出现在地址中
- 刷新后按 URL 恢复激活标签；若该键已不存在，回退到首个可用标签
- 受控场景下「初始激活键」与「URL 键」应一致，避免首次渲染闪错

## 无障碍
- 标签角色与标签面板角色关联：选中标签、面板归属关系需正确表达
- 当前标签标注「已选中」语义；面板关联到其标签
- 全键盘可达：方向键移动、`Enter` 激活（手动模式）、`Delete` 关闭
- 关闭按钮有可读名称（「关闭 XX」）
- 方向键移动与激活模式需在文档中说明，避免「方向键没反应」的困惑

---

## 常见误用
- 用标签页做跨页面导航 → 应用导航菜单
- 标签数量过多（> 约 7）不换形态 → 拥挤、难找
- 关闭当前标签后不自动选中替代标签 → 出现空面板
- 全部面板一次性 eager 加载 → 首屏变慢、请求浪费
- 激活键用会变的显示文本 → 切换 / 回填错乱
- 受控与非受控混用 → 状态不一致
- 用标签页承载有顺序的流程 → 应用步骤条

## 边界与代价
- 标签 > 约 7 个：**必须**溢出处理（滚动 / 收纳）或换形态
- 侧边标签移动端**必须**换形态（下拉），否则占满屏宽
- 面板**应懒加载**，全量 eager 会拖慢首屏
- 激活键**必须稳定且受控**（与路由 / 状态明确绑定），否则回填错乱
- 关闭当前标签**必须**有明确的接替选中规则
- 键进入 URL 时**必须**处理键失效的回退，避免刷新后无标签可选
