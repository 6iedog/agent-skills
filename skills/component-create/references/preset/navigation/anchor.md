# 锚点

长页面内的**区块导航**：点击滚动到目标区块，滚动时高亮当前所在区块。

## 角色与边界

- **是什么**：与页面内若干内容区块一一对应的导航列表，点击即滚动定位，并随滚动反向高亮当前区块。
- **解决什么**：长文档 / 长表单 / 长页面的章节间快速定位与「当前读到哪」的感知。
- **不解决什么**：
  - 不承担页面间 / 路由级导航 → 导航菜单
  - 不表达「从根到当前页」的层级路径 → 面包屑
  - 不表达流程进度 → 步骤条
  - 不做同级内容互斥切换 → 标签页
- **什么时候不用**：页面短、所有区块一屏内可见；区块极多且每个都很短（高亮会不停跳）；内容本就有清晰目录且不需定位。

---

## UI

### 结构解剖
- **锚点列表容器**：承载全部锚点项
- **锚点项**：对应一个区块的标题文字；可含层级缩进
- **当前高亮项**：正在浏览的区块对应项
- **指示线 / 滑块**：随当前区块移动的视觉标记（左侧竖条最常见）
- **嵌套层级**：子章节的缩进呈现
- **可选吸顶容器**：滚动时锚点列表固定在视口一侧

### 尺寸与外观变体
- 方向：**垂直**（侧边固定，最常见）/ **水平**（顶部横向）
- 层级：平级 / 嵌套（子项缩进）
- 指示样式：左侧竖线滑块 / 文字变色 / 背景高亮块 / 圆点
- 是否吸顶（随滚动固定）
- 尺寸：字号、项间距、缩进宽度

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 普通锚点项 |
| hover | 文字变色 / 背景微亮 |
| focus-visible | 明显焦点环 |
| active | 当前区块对应项：高亮 + 指示标记 |
| active-parent | 当前区块在子层级时，父项呈弱高亮（嵌套时） |

- 当前高亮必须**唯一且稳定**；滚动过程中不应在两项之间高频闪烁。

### 布局与对齐
- 垂直：置于内容侧边，项左对齐，嵌套子项缩进
- 水平：置于顶部，横向排列；块多时滚动
- 嵌套：父项与子项用缩进 / 字号区分层级
- 吸顶：容器进入视口后固定，避免随长内容滚走

### 移动端
- 侧边常驻锚点占宽 → 收起为**下拉选择**或**浮动按钮弹出目录**
- 触摸目标 ≥ 44×44
- 弹出层内可滚动，选中后自动关闭
- 水平顶部锚点在窄屏改为横向滚动

## 交互

### 触发与滚动
- 点击锚点项 → **平滑滚动**到目标区块
- 滚动落点需加**偏移量**，避免区块标题被固定头部 / 吸顶容器遮挡
- 平滑滚动可关闭；必须尊重「减少动效」偏好（关闭时直接跳转）

### 滚动监听高亮
- 滚动时根据区块相对视口的位置，高亮对应锚点项
- 判定基准：通常取「区块顶部越过某阈值线（如头部高度）」时激活该区块
- 多区块同时可见时，取最接近阈值线的一项
- 顶部 / 底部边界：滚动到页首高亮首项，页尾高亮末项，避免无高亮空档

### 层级行为
- 点击父项 → 滚动到父区块起始位置
- 子项高亮时父项可呈弱高亮，保持层级可读
- 嵌套仅用于层级呈现，不改变点击即滚动这一核心行为

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在锚点项之间移动焦点 |
| `Enter` / `Space` | 激活聚焦项，滚动到对应区块 |
| `↑` / `↓` | 垂直方向：在项间移动 |
| `←` / `→` | 水平方向：在项间移动 |
| `Home` / `End` | 跳到首 / 末项 |

### 指针与手势
- 点击项滚动定位
- 悬停有反馈
- 移动端在弹出目录中点击项，滚动并关闭目录

### 焦点管理
- 点击后滚动到目标区块，焦点通常移到**目标区块容器**（便于继续键盘阅读）
- 不因滚动而丢失焦点
- 更新 URL 锚点时，浏览器可能跳到目标，需与平滑滚动协调（见边界交互）

### 动画与过渡
- 平滑滚动：时长适中（约数百毫秒），不拖沓
- 高亮指示滑块：位移过渡，约 150–250ms
- 尊重「减少动效」偏好：关闭平滑滚动与滑块动画

### 反馈
- 点击后滚动本身即反馈
- 高亮随滚动更新，即「当前位置」反馈
- 目录弹出层有开合反馈

### 边界交互
- **偏移量与固定头部**：页面有固定头部 / 吸顶栏时，滚动落点必须减去其高度，否则标题被遮
- **滚动容器不是窗口**：内容在可滚动容器内时，滚动监听与定位必须作用于**该容器**，而非全局窗口；同时须考虑容器内偏移
- **URL hash 联动**：点击可更新地址哈希，刷新后能回到同一区块；首屏若带哈希应滚动到位（需处理异步内容渲染完成后再定位）
- 内容异步渲染：目标区块高度在数据到达后才确定，滚动位置需在渲染后重新校正
- 层级过深：缩进过多挤压文本，应收敛

## 数据流

### 输入
- **锚点列表**：`{ 标题, 目标标识?, 层级? }` 的有序数组
- **滚动容器**：默认窗口，或指定的可滚动元素
- **偏移量**：固定头部 / 吸顶高度
- 配置：方向、指示样式、是否吸顶、是否同步哈希、是否平滑滚动

### 内部状态
- 当前激活锚点索引
- 滚动监听注册与节流状态
- 目录弹出层开合（移动端）
- 各目标区块的测量位置（滚动 / 尺寸变化时重算）

### 输出
- **激活锚点变化事件**：当前高亮项标识（供外部联动 / 埋点）
- **导航事件**：点击跳转的项标识
- 可选：URL 哈希更新

### 受控 / 非受控
- 激活项默认由**内部滚动监听**推导（非受控）
- 也可由外部传入受控激活项（如与目录树高亮联动）；受控时组件不再自行推导
- 二选一必须明确，混用会出现「滚动了但高亮不动」或「高亮与位置不符」

### 异步与竞态
- 内容异步加载会改变各区块位置 → 加载完成后重新测量
- **竞态**：快速点击多项时，后发滚动可能与平滑滚动动画冲突 → 以最后一次点击为准，取消前一次滚动
- 目标区块尚不存在（懒渲染）时，需等到其出现再定位

### 校验与错误
- 目标标识不存在或未渲染 → 该项应降级（不可点 / 跳过），不产生死锚点
- 组件不做业务校验

### 回填与序列化
- URL 哈希即「当前锚点」的一种序列化；刷新后应还原滚动位置
- 回填时若对应区块尚未渲染，需在渲染完成后补一次定位
- 哈希值需稳定（与区块标识一致），不用会变的文案

---

## 无障碍
- 用导航区域 + 列表结构表达锚点集合
- 锚点项为**真正的链接**（指向区块标识），保证无脚本时也可跳转
- 当前项标注「当前」语义，屏幕阅读器可读
- 嵌套层级用列表嵌套表达，保留层级
- 平滑滚动尊重「减少动效」；键盘可达；`focus-visible` 可见

---

## 常见误用
- 页面很短仍做锚点 → 冗余
- 不做偏移量 → 滚动后标题被固定头部遮住
- 滚动容器不是窗口却监听全局滚动 → 高亮不更新或定位错误
- 用会变的文案作哈希 → 刷新无法还原
- 层级过深、缩进过多 → 文本被挤压
- 高亮判定无阈值 / 无边界处理 → 顶部或底部出现无高亮空档、滚动时频繁闪烁
- 内容异步渲染却在渲染前定位 → 滚到错误位置

## 边界与代价
- 页面存在固定头部 / 吸顶容器：**必须**加偏移量，否则标题被遮
- 内容位于可滚动容器：**必须**监听并定位该容器，而非全局窗口
- 与 URL 哈希联动：**必须**处理「目标尚未渲染」的补定位
- 目标标识失效：**必须**降级，避免死锚点
- 高亮判定**必须**有阈值线与首尾边界处理，否则闪烁 / 空档
- 平滑滚动**必须**尊重「减少动效」偏好
