# 分页

把大量数据切成若干页，让用户**跳转到指定页**浏览，并展示总量与当前页。

## 角色与边界

- **是什么**：一组页码导航控件，含上一页 / 下一页、页码、跳页、每页条数切换与总量文案。
- **解决什么**：数据量超出单页可承载范围，需要分块浏览且能定位到某一块。
- **不解决什么**：
  - 不负责**加载数据**，只发出「要看第几页」的信号（取数由使用方完成）
  - 不承担无限滚动 / 触底加载（那是列表自身行为）→ 列表 / 虚拟滚动
  - 不表达流程进度 → 步骤条
  - 不表达层级位置 → 面包屑
- **什么时候不用**：数据量小到可一屏呈现；内容是按时间流持续追加（更适合「加载更多」或无限滚动）；移动端信息流（同前）。

## UI

### 结构解剖
- **上一页按钮**：退一页，首页时禁用
- **页码按钮**：显示可点页码
- **省略号**：折叠被省略的页码区间，不可点
- **下一页按钮**：进一页，末页时禁用
- **跳页输入框**：输入目标页号，回车或确认后跳转
- **每页条数选择器**：切换每页显示条数（如 10 / 20 / 50）
- **总量文案**：如「共 128 条」；可含当前区间（如「第 21–40 条」）
- **简洁模式**：只保留上一页 / 下一页 + 「当前页 X / 共 Y 页」

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响按钮高度、字号、圆角
- 模式：完整页码 / 简洁模式 / 首页与末页固定显示 / 带跳页 / 带每页条数
- 外观：带边框按钮 / 无边框文本按钮 / 背景块
- 省略号策略：固定显示首尾若干页 + 当前页邻域

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态页码 / 按钮 |
| hover | 背景微亮或文案变色 |
| focus-visible | 明显焦点环 |
| current | 当前页：高亮、**不可点**、无 hover |
| active（按下） | 按钮按下加深 |
| disabled | 边界时上一页 / 下一页禁用：降透明、不可点 |
| ellipsis | 省略号：纯文本、不可点、无交互态 |
| loading | 翻页加载中：控件可禁用或显示加载态，防重复点击 |

- **当前页与不可点必须区分**：当前页是「你看的就是这页」，禁用是「这条路走不通」。

### 布局与对齐
- 常置于列表 / 表格底部，右对齐居多；也可居中
- 宽屏可完整展示；窄屏优先收起页码、保留上一页 / 下一页
- 页码数量随可用宽度动态增减，避免换行折断

### 移动端
- 收起为简洁模式：上一页 / 下一页 + 「X / Y」
- 或改为「加载更多」按钮 / 触底自动加载
- 触摸目标 ≥ 44×44
- 每页条数切换在移动端常省略

## 交互

### 触发与翻页
- 点击页码 / 上一页 / 下一页 → 请求对应页数据
- 点击当前页 → 无响应（不做「刷新当前页」的隐含语义）
- 跳页：输入页码 → 回车或确认 → 跳转
- 每页条数切换 → **重置到第 1 页**（避免页码越界）

### 选中行为
- 当前页高亮唯一
- 翻页后列表滚动到顶部（或保持位置，需二选一并一致）
- 跳页越界（小于 1 或大于总页数）→ **钳制到边界**或提示，不可提交非法页

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在按钮与输入框之间移动焦点 |
| `Enter` / `Space` | 激活聚焦的页码 / 按钮 |
| `Enter`（跳页框内） | 提交跳转 |
| `Home` / `End` | 可选：跳到首页 / 末页 |
| `PageUp` / `PageDown` | 可选：上一页 / 下一页 |

### 指针与手势
- 点击即翻页；悬停有反馈
- 移动端可支持横向滑动手势（可选），或按下上一页 / 下一页
- 禁用按钮不响应点击

### 焦点管理
- 翻页后焦点通常保持在被点控件上（若控件仍在），或移交列表容器
- 跳页提交后焦点从输入框移出，避免停留在已失效位置
- 简洁模式下禁用按钮不可聚焦

### 动画与过渡
- 翻页不做过场动画；列表数据更新由使用方处理
- 当前页高亮切换即时
- 加载态避免闪烁抖动

### 反馈
- 翻页加载中给出加载态（列表内骨架 / 控件禁用）
- 跳页非法或超出范围时给出提示
- 无数据时显示空状态，分页可整体隐藏

### 边界交互
- **边界禁用**：第 1 页禁用上一页，末页禁用下一页
- 总数变化导致当前页越界（如筛掉数据后页数减少）→ 回退到最后一有效页或重置到第 1 页，二选一并明确
- 省略号：首尾页固定 + 当前页邻域，规则要稳定不跳动
- 快速连点翻页 → 防抖 / 请求竞态处理
- 页数极多（成百上千）→ 页码必须折叠，不能全部渲染

## 数据流

### 输入
- **总数**（决定总页数）
- **每页条数**
- **当前页**
- 配置：尺寸、简洁模式、可选每页条数、是否显示总量 / 跳页、上限页数

### 内部状态
- 跳页输入框的草稿值（受控前的临时输入）
- 悬停 / 聚焦状态
- 非受控模式下的内部当前页

### 输出
- **页码变化事件**：目标页号
- **每页条数变化事件**：新条数（与页码事件**必须区分**，因为条数变化需重置页码）
- 两者可合并为一次「查询参数变化」抛出，但需让使用方能识别是哪种变化

### 受控 / 非受控
- 页码通常**受控**（由数据源 / 状态持有），组件只抛请求
- 跳页输入草稿非受控（内部临时）
- 若允许非受控，需给默认页与默认条数；**混用会出现「点了不变」**

### 异步与竞态
- 翻页请求进行中应禁用重复触发或忽略重复请求
- **竞态**：用户快速翻多页时，后发请求先返回会覆盖新页 → 按页码 / 请求标识丢弃过期结果
- 总数与数据的加载应尽量同批返回，避免页码据此算错

### 校验与错误
- 组件只负责「请求第几页」，业务校验不在此层
- 跳页越界钳制或提示，规则明确
- 总页数为 0（无数据）时不渲染页码

### 回填与序列化
- 当前页与每页条数常写入 URL（如页码 / 尺寸查询参数），刷新后恢复
- 回填时校验：页号超出实际总页数需纠正
- **页码语义**从 1 开始还是从 0 开始必须明确，否则与后端分页错位

## 无障碍
- 用导航区域 + 可读标签包裹
- 当前页标注「当前页」语义，屏幕阅读器可读
- 禁用按钮标注为不可用
- 跳页输入框需有关联标签与说明
- 全键盘可达；`focus-visible` 可见
- 省略号不应被读作可操作项

---

## 常见误用
- 数据量很小仍做分页 → 单页即可
- 切换每页条数却不重置到第 1 页 → 页码越界
- 当前页仍可点 → 触发无意义刷新
- 页数极多却全量渲染页码 → 溢出、性能差
- 快速翻页不处理竞态 → 显示到错误页的数据
- 分页与「加载更多 / 无限滚动」混用在同一列表 → 两套模式冲突
- 页码起始从 0 vs 1 未与后端对齐 → 差一页

## 边界与代价
- 总页数超过约 7–10 页：**必须**折叠页码，只留首尾 + 邻域
- 移动端：应收敛为简洁模式或改「加载更多」，照搬完整页码会挤爆
- 每页条数切换**必须**重置页码
- 当前页越界（总数变化）**必须**有明确纠正策略
- 翻页**必须**处理请求竞态，否则出现「翻到第 3 页显示第 1 页数据」
- 页码起始约定**必须**与后端一致
