# 导航菜单

一组指向页面 / 路由的**导航项**，按水平、垂直或内联排列，支持子菜单、选中态与折叠态。

## 角色与边界

- **是什么**：由「目标为页面 / 路由」的项组成的导航结构，可含多级子菜单，并高亮当前所在页。
- **解决什么**：在多个页面 / 模块之间切换，并让用户一眼看到当前处于哪个模块。
- **不解决什么**：
  - 不承载「点击即执行动作」的命令（不跳转）→ 操作菜单 / 下拉面板
  - 不承载同级内容的互斥切换（不换页面）→ 标签页 / 分段控件
  - 不表达「从根到当前页」的路径 → 面包屑
  - 不表达流程进度 → 步骤条
- **什么时候不用**：项很少且长期固定 → 直接平铺链接；同一页面内切换视图 → 标签页；内容本身是流程 → 步骤条。

## UI

### 结构解剖
- **容器**：承载所有菜单项；决定排列方向与主题
- **菜单项**：图标（可选）+ 文字；指向一个页面 / 路由
- **子菜单父项**：带展开箭头；展开后显示下一级
- **子菜单**：两级呈现方式——浮层（水平菜单常用）或内联展开（垂直 / 内联菜单常用）
- **分组标题**：把项按类别归组
- **选中指示**：下划线 / 侧边条 / 背景块，标明当前路由对应项
- **折叠触发器**：把菜单收成仅图标或汉堡入口
- **溢出入口**：水平菜单放不下时收纳多余项

### 尺寸与外观变体
- 排列方向：**水平**（顶部主导航）/ **垂直**（侧边栏）/ **内联**（垂直且子级缩进内嵌，随父级展开）
- 主题：浅色 / 深色
- 选中指示样式：下划线 / 侧边竖条 / 背景高亮块 / 文字变色
- 是否可折叠（折叠后只显图标，hover 出浮层）
- 层级深度：一级 / 二级（推荐上限）/ 更深（不推荐）
- 是否含图标、分组标题

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态项，未选中 |
| hover | 背景微亮 / 文案变色 |
| focus-visible | 明显焦点环 |
| selected | 当前路由对应项：选中指示 + 强调色 |
| open | 子菜单展开：父项高亮 + 箭头翻转 |
| active（按下） | 按下时背景加深 |
| disabled | 项不可用：降透明、不可点、不进键盘导航 |
| collapsed | 折叠态：只显图标（或收起），悬停时以浮层补全标题 |

- **选中态与展开态必须可区分**：选中是「当前所在页」，展开是「正在浏览子项」，二者常同时出现但语义不同。
- 折叠态下必须提供浮层 / 提示补全被隐藏的文字，否则不可辨识。

### 布局与对齐
- 水平：项横向排列；放不下时收纳进「更多」或横向滚动（桌面优先收纳）
- 垂直 / 内联：纵向排列，内联子级缩进一级
- 子菜单浮层：贴父项边缘展开；靠近视口边缘时翻转方向
- 水平菜单的子菜单通常在其下方；垂直菜单的子菜单常在其右侧

### 移动端
- 水平主导航 → 收纳为抽屉 / 汉堡菜单；或改用底部导航（项 ≤ 5）
- 垂直菜单常本身即移动端形态，主容器可滑出
- 内联子菜单在窄屏展开为全屏层级页
- 触摸目标 ≥ 44×44

## 交互

### 触发与开合
- **内联菜单**：点击父项 → 展开 / 收起内联子级
- **浮层菜单**：悬停或点击父项 → 弹出子菜单
- **折叠态**：悬停 / 点击折叠的项 → 弹出含标题与子项的浮层
- 关闭：再次点击父项、`Esc`、点击外部、切换到另一个父项

### 选中与展开行为
- **选中态由当前路由决定**，不由点击单独维护
- **展开态与选中态分离**：选中不等于展开（可折叠的已选分支常默认展开）
- 手风琴模式（可选）：同一级同时只展开一个子菜单
- 默认应**自动展开包含当前选中项的分支**，让用户看到自己在树中的位置
- 点击父项若同时是页面入口：可点击进入页面，也可点击展开——需二选一并保持一致（常见做法：父项点击展开，或父项点击跳转 + 箭头单独展开）

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 进入菜单 / 在项间移动焦点 |
| `↑` / `↓` | 垂直 / 内联：上下移动；水平：打开子菜单并聚焦 |
| `→` | 展开子菜单 / 进入下一级 |
| `←` | 收起子菜单 / 返回上一级 |
| `Enter` / `Space` | 跳转到项对应页面，或展开 / 收起子菜单 |
| `Esc` | 关闭当前展开的子菜单，焦点回到父项 |
| `Home` / `End` | 跳到同级首 / 末项 |

- 禁用项在键盘遍历中跳过。

### 指针与手势
- 悬停项高亮；悬停父项可延迟展开子菜单（防抖，避免划过误开）
- 指针从父项移向子菜单时不得因「离开父项」而收起
- 移动端：点击项跳转或展开，主菜单可滑动呼出

### 焦点管理
- 子菜单展开：焦点可进入子菜单并可返回父项
- 关闭子菜单：焦点**回到父项**，不丢失到 body
- 主菜单收起（抽屉 / 折叠）：焦点归还触发器

### 动画与过渡
- 子菜单展开 / 收起：淡入淡出 + 与方向一致的轻微位移，约 100–200ms
- 内联展开：高度过渡，避免布局抖动
- 折叠指示箭头翻转
- 尊重「减少动效」偏好

### 反馈
- 跳转由路由承担（页面变化即反馈）
- 展开 / 收起有即时视觉反馈
- 异步加载子项时显示加载态

### 边界交互
- **与路由联动**：选中态必须跟随当前路由；路由变化后自动重算选中项与展开链
- 子菜单靠近视口右 / 下边缘：翻转方向或改对齐边
- 层级过深（> 2 级）：难以导航，应收敛
- 权限过滤后项减少：菜单结构动态变化，不留下空分组

## 数据流

### 输入
- **菜单树**：`{ 标题, 图标?, 路径?, 子项?, 是否禁用? }` 的树形结构，支持分组
- **当前路由 / 选中项**：用于计算高亮与默认展开链
- 配置：排列方向、主题、是否折叠、是否手风琴、选中指示样式

### 内部状态
- 展开的父项集合（内联 / 手风琴场景）
- 键盘高亮索引
- 折叠 / 展开状态
- 子菜单浮层的定位结果

### 输出
- **导航事件**：被点击项的目标路径 / 标识
- 展开 / 收起事件（供埋点或联动）
- 折叠切换事件
- 组件**只抛「去哪」，不持有页面数据**

### 受控 / 非受控
- 选中项由路由派生（受控）
- 展开集合默认内部自管；需要外部联动（如记住展开状态）时提为受控
- 折叠状态通常受控（由布局持有）
- **混用会导致「点了不变」或「外部改了不刷新」**，需二选一

### 异步与竞态
- 菜单树可能来自远程（按权限 / 角色下发）；需处理加载 / 空 / 错误
- **竞态**：连续切换角色 / 上下文时，按最新请求标识丢弃过期菜单树
- 异步子项懒加载时给出加载态，避免闪空

### 校验与错误
- 组件不做业务校验
- 无权限 / 不可用项应下发为 `disabled`（而非直接删除，若保留结构更有助理解）
- 路径缺失项不可点

### 回填与序列化
- 选中态由当前路由**匹配**得到：需支持「父级匹配」（如按路径前缀），使子页面也能点亮父模块
- 默认展开链 = 当前选中项到根的祖先路径
- 匹配规则需明确（精确匹配 / 前缀匹配），否则出现「进了子页但父级没亮」

## 无障碍
- 用导航区域 + 列表结构表达菜单层级
- 当前项标注「当前页」语义，屏幕阅读器可读
- 含子菜单的项标注可展开 / 已展开状态
- 禁用项标为不可用
- **全键盘可达**：`↑↓←→` 导航、`Enter` 跳转 / 展开、`Esc` 收起并归还焦点
- 折叠态下被隐藏的标题仍需对屏幕阅读器可读

## 常见误用
- 拿菜单承担同级视图切换（不换页面）→ 应用标签页
- 拿菜单承担操作命令（点击执行而非跳转）→ 应用操作菜单
- 选中态与路由不同步 → 用户看不清自己在哪
- 层级做到三级以上 → 难导航，应收敛为二级 + 面包屑
- 折叠态只显图标却无浮层 / 提示 → 图标含义不可辨
- 父项既可跳转又可展开却不区分点击区域 → 交互含糊
- 悬停展开无防抖 → 鼠标划过时菜单乱闪

## 边界与代价
- 层级深度建议 **≤ 2 级**；更深应改用其他信息架构
- 移动端**必须**换形态（抽屉 / 底部导航），照搬水平菜单会挤爆
- **必须**与路由联动且支持父级匹配，否则选中态错乱
- 折叠态**必须**提供浮层或提示补全标题
- 悬停展开**必须**防抖 + 处理移向子菜单的过渡区
- 权限过滤导致结构变化时，需保证不出现空分组与死项
