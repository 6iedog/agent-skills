# 输入框

单行文本录入控件，一行内容、一回车提交。

## 角色与边界

- **是什么**：一个单行可编辑文本区，配合前后置标签、前缀后缀、图标与状态构成完整输入单元。
- **解决什么**：录入短文本（姓名、标题、邮箱、网址、搜索词、编号），单行足够。
- **不解决什么**：
  - 内容多行 / 需换行 → 多行文本域
  - 只允许数字 → 数字输入
  - 输入即联想 → 自动完成
  - 在文本里触发 @ 引用 → 提及
  - 只能从固定选项里选（不许自由输入）→ 单选 / 多选下拉
  - 强掩码输入（电话、日期、金额）→ 掩码输入 / 专用输入
- **什么时候不用**：答案只有几个固定选项 → 选择类控件（更防错、更省输入）；真二元语义 → 开关。

## UI

### 结构解剖
- **容器**：一行，含边框或底色
- **前置标签 / 后置标签**：贴在边框外侧的文字块（如「https://」「元」）
- **前缀 / 后缀**：边框内侧的图标或文字（如搜索图标、单位）
- **输入区**：可编辑文本 + 光标 + 占位符
- **清空按钮**：有值时出现（常 hover 才显形）
- **密码可见切换**：密码态下的眼睛图标，切换明文 / 掩码
- **计数**：设了最大长度时可显示「已输 / 上限」
- **帮助 / 错误文案**：容器下方一行

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响高度、内边距、字号
- 外观：带边框 / 无边框（工具栏内）/ 填充式 / 下划线式
- 变体轴：有无前后缀、有无前后置标签、有无清空、明文 / 密码、只读 / 禁用、错误 / 警告 / 成功

### 视觉状态（逐条）
| 状态 | 容器 | 输入区 |
|---|---|---|
| default | 边框默认、底色默认 | 占位符浅色 |
| hover | 边框加深 | — |
| focus | 边框高亮（可带柔光） | 光标可见 |
| focus-visible | 明显焦点环 | — |
| filled（有值） | 同 default | 显示文本，清空按钮出现 |
| composing（IME 组合） | 同 focus | 光标带下划线，中间串未上屏 |
| readonly | 外观接近 default | 可聚焦、可选中复制、不可改 |
| disabled | 整体降透明 | 不可聚焦、禁用指针 |
| error | 边框红 + 下方错误文案 | — |
| warning | 边框黄 + 下方提示 | — |
| success | 边框绿 + 成功标记 | — |
| full（达上限） | — | 输入被拦，计数变色 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 前后置标签与输入框**等高吸附**、无间隙
- 前缀后缀图标与文本间距固定，图标不随文字滚动
- 内容超出时**内部横向滚动**，光标始终滚入可视区
- 占位符与输入文本左对齐（数字、密码可右对齐，须统一）
- 后缀与右侧内边距对齐

### 移动端
- 触摸目标 ≥ 44×44
- 按输入类型调起合适键盘（数字 / 邮箱 / 电话 / 网址），并设置自动大写、自动纠错的取舍
- 键盘弹出遮挡输入框时需滚动让其可见

## 交互

### 触发与输入行为
- 聚焦：点击容器 / Tab / 程序聚焦
- 输入：逐字录入，首字符输入后占位符消失
- 清空：点清空按钮，或选中后按删除键
- 密码切换：点眼睛图标，**值不变、光标位置保持**
- 前后缀 / 标签点击：默认不聚焦输入，除非显式配置
- 失焦：触发失焦事件；若配置「失焦提交」则在此提交

### 输入行为
- **IME 组合态**：拼音 / 日文输入过程中，未上屏的中间串**不得当作值**；值变化与提交须在组合结束后判定
- 选择：双击选词，全选快捷键选中全部
- 粘贴：允许；超长时按最大长度策略截断；密码框一般禁止粘贴
- 输入过滤：可按规则拒绝非法字符（但一般优先用专用输入）
- 浏览器级自动补全气泡可关闭

### 键盘
| 按键 | 行为 |
|---|---|
| `Enter` | 触发提交 / 完成事件；在表单中可能提交表单 |
| `Esc` | 清空或还原为聚焦前值（可配置） |
| `Tab` | 移出焦点，在元素间跳转 |
| `Backspace` / `Delete` | 删除字符 |
| `Ctrl/Cmd + A` | 全选 |
| `←` / `→` | 移动光标；在联想场景可交给上层 |
| `Home` / `End` | 行首 / 行尾 |

### 指针与手势
- 点容器任意处（含前后缀）聚焦输入
- 拖动选择文本
- 触摸端长按选字、拖动定位光标

### 焦点管理
- 焦点环可见；禁用元素不可聚焦；只读元素可聚焦可复制
- 程序聚焦时把光标置于末尾，或全选（可配置）
- 清空后焦点留在输入区

### 动画与过渡
- 边框 / 阴影状态色过渡约 100–150ms
- 清空按钮淡入淡出
- 错误文案区域**预留高度**，出现时不引起布局跳动

### 反馈
- 错误 / 警告 / 成功以边框色 + 文案呈现
- 最大长度：达上限后输入被拦，计数变色，并明确溢出处理
- 提交成功一般不在框内提示（避免噪声）

### 边界交互
- 超长文本：内部横向滚动，不回推占位符
- 最大长度策略须明确：**输入时禁止超出** 还是 **允许超出但校验报错**
- 快速输入 + 异步校验：防抖、防竞态

## 数据流

### 输入
- 配置：值 / 默认值、占位符、尺寸、状态、最大长度、是否可清空、是否密码、前后缀与标签、是否只读 / 禁用
- 来源：外部传入（表单 / 上层状态）

### 内部状态
- 当前文本（非受控时）
- 焦点态、IME 组合态
- 是否已切换为明文（密码框）
- 是否达上限

### 输出
- **值变化事件**：新字符串（可选带触发原因：输入 / 清空 / 粘贴）
- 提交 / 回车事件
- 聚焦 / 失焦事件
- **值形态**：字符串；「空串」与「未填」是否等价须明确

### 受控 / 非受控
- 受控：值由外部持有，组件只抛新值；外部不回写则显示不变（表现为「打不进字」）
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「打字消失」或「外部改了不刷新」

### 异步与竞态
- 若做异步校验 / 联想：输入防抖，按请求标识丢弃过期结果
- 提交时若有异步校验：须明确是阻塞提交还是先提交再提示

### 校验与错误
- 组件只呈现错误；规则在表单层或内联传入
- 常见规则：必填、长度、格式、唯一性
- 校验时机：输入中 / 失焦 / 提交——**须明确**；输入中校验用防抖

### 回填与序列化
- 初值 → 直接渲染；`null` / `未定义` 显示占位符
- 序列化：输出输入区纯文本
- 前后缀与标签**不属于值**，提交时只提交输入区文本
- 密码框**不应回填明文**

---

## 无障碍
- 关联可见标签；无可见标签时用可读名称属性提供名称
- 帮助 / 错误文案与其关联；错误态标 `aria-invalid`
- 只读用只读语义（可聚焦可读）；禁用用禁用语义（不可聚焦）
- 密码切换按钮有可读名称与状态（明 / 暗）
- 全键盘可达；焦点可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 用输入框承载固定选项 → 应为选择类控件
- 拿最大长度当唯一校验（类型 / 格式仍需校验）
- 用禁用代替只读（想让人复制却不让改）
- 密码框回填明文
- IME 组合态把中间串当值提交
- 只靠占位符当标签，无可见标签

## 边界与代价
- 无标签只靠占位符 → 输入后提示消失、可访问性差
- 最大长度策略不明确 → 用户粘贴被静默截断
- 受控却外部不回写 → 出现「打不进字」的错觉
- 每次输入都同步远程校验 → 请求风暴
- 前后缀做成可点击却不聚焦输入 → 用户误以为可编辑
