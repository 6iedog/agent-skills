# 时间选择

从时 / 分 / 秒列中**选一个时刻**（或一段时刻区间），结果是钟表时刻。

## 角色与边界

- **是什么**：以时 / 分 / 秒列（或滚轮）为载体的时刻输入，可点击选择、可手输。
- **解决什么**：需要选具体时刻，并希望有列式参照与约束。
- **不解决什么**：
  - 选日期 → 日期选择
  - 同时需要日期 + 时刻 → 日期时间选择（本组件与日期选择组合）
  - 选「时长 / 间隔」（如 2 小时 30 分）→ 数字输入；本组件选的是**钟表上的点**，不是两点之间的差
  - 时区换算 → 本组件只处理「本地钟表时刻」的呈现，时区在数据层定义
- **什么时候不用**：候选时刻只有固定几个（如「上午 / 下午」）→ 单选按钮组 / 分段控件；需要高精度到秒且允许任意值 → 直接用文本输入更稳。

---

## UI

### 结构解剖
- **触发器**：一行输入框，左为已选时刻文本（或占位符），右为时钟图标；可含清空按钮
- **输入区**：可手输时刻
- **弹出面板**：时 / 分 / 秒若干列（列数取决于粒度）
- **列**：每列是一个可滚动的时刻列表，选中项居中高亮
- **分隔符**：列与列之间的 `:` 占位对齐
- **上下午列**：12 小时制下额外的一列或切换控件
- **「现在」按钮**：一键填当前时刻
- **范围模式**：起止两个时刻 + 区间示意
- **确认按钮**：范围模式或与日期组合时，面板底部的确认入口
- **状态占位**：面板内的加载 / 空位

### 尺寸与外观变体
- 选择模式：**单时刻** / **时刻区间**
- 列数：时:分 / 时:分:秒
- 制式：**12 小时制**（含上下午）/ **24 小时制**
- 步长：分的步长、秒的步长（如每 15 分钟一项）
- 是否含「现在」/「确认」
- 形态：内联 / 浮层
- 尺寸：小 / 中 / 大 → 影响触发器高度、列高、字号
- 状态类：默认 / 错误 / 警告 / 禁用

### 视觉状态（逐条）
| 状态 | 触发器 | 面板 / 列项 |
|---|---|---|
| default | 边框默认、占位符浅色 | 列项常规显示 |
| hover | 边框加深 | 悬停列项背景微亮 |
| focus-visible | 明显焦点环 | 焦点列项有独立焦点环 |
| open | 边框高亮 + 图标变化 | 面板出现 |
| selected | 显示所选时刻 | 该列项填充高亮 |
| now（当前时刻） | — | 与当前时刻相同的项有独立标记（**区别于 selected**） |
| range-start / range-end | 显示区间文本 | 两端点高亮 |
| disabled（禁用时刻） | 整体禁用则降透明 | 个别禁用时刻灰显、不可选 |
| disabled（整列禁用） | — | 整列灰显、不可滚动选中 |
| readonly | 外观同 default，但不可展开 | — |
| error | 边框红 + 下方错误文案 | — |
| loading | 触发器可显示加载 | 面板内骨架 / spinner |

- **now 与 selected 不得同色同形**：否则分不清「现在是几点」与「我选了几点」。
- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 各列等宽、定高，列内滚动并让选中项**居中**
- 分隔符与列垂直居中，保证时:分:秒视觉对齐
- 面板宽度固定，不随内容跳动
- 靠近视口底部时**向上翻转**，避免出屏

### 移动端
- 桌面列式在小屏宜改为**底部弹层 / 全屏滚动轮**
- 触摸目标 ≥ 44×44，滚动带惯性并在松手后吸附到最近项
- 12 小时制的上下午切换做成显式控件，不藏进滚动

## 交互

### 触发与开合
- 打开：点击触发器 / 聚焦后 `Enter`、`Space`、`↓`
- 关闭：`Esc`、点击外部、单时刻选完即收
- 范围 / 组合模式：需点「确认」才落值，避免半成品状态
- 面板自动避让视口边缘

### 输入或选择行为
- 点某列中的时刻即选中该列
- 滚动列 → 高亮居中项，松手后吸附到最近项
- 12 小时制：先定上下午，再定时 / 分
- 步长：列中只出现步长对齐的时刻（如 00/15/30/45）
- 范围：分别设定起止；结束早于开始时交换或禁止，须定义
- 手输解析：需定义可接受格式（如 `9:30`、`09:30:00`、`9:30 PM`）及非法处理

### 键盘
| 键 | 行为 |
|---|---|
| `Tab` | 在触发器与各列之间移动焦点 |
| `↑` / `↓` | 当前列内移动到上 / 下一项 |
| `←` / `→` | 切换到相邻列 |
| `Enter` | 选中当前项 / 确认（范围与组合模式） |
| `Esc` | 关闭且**不改变值** |
| `Home` / `End` | 跳到当前列的首 / 末项 |
| `PageUp` / `PageDown` | 在当前列内大跨度跳转 |
| 数字键 | 直接输入数值跳转（可选增强） |

- 列式面板打开时，焦点默认落在**当前时刻所在列**。

### 指针与手势
- 点击列项选中；滚轮滚动；触摸上下滑动并惯性吸附
- 移动端：点触发器 → 底部弹层

### 焦点管理
- 关闭后焦点**回到触发器**（不得丢到 body）
- 打开即聚焦当前时刻列，键盘导航从该列开始
- 范围选择中，焦点停留在刚设定的端点上

### 动画与过渡
- 面板出现 / 消失：轻微位移 + 淡入淡出，约 100–200ms
- 列滚动吸附动画平滑；选中项高亮过渡短
- 12 小时制切换上下午时不引起列跳动

### 反馈
- 选中即反馈（列项高亮）
- 范围 / 组合模式未确认时，明确区分「已选未提交」与「已提交」
- 手输非法：立即标错 + 文案，不静默丢弃

### 边界交互
- **越界循环**：24 小时制下 `23` 再向后是 `00` 是否循环，须定义且保持一致
- **步长与「现在」**：当前分钟不在步长网格内时，「现在」按钮落值须定义（取最近网格 / 取精确值）
- **禁用时刻**：可能是整列禁用（某个小时全部禁用）或个别禁用，二者视觉与交互须区分
- **与日期组合**：先填时间后填日期、或反之，顺序无关，最终合并为同一时刻

## 数据流

### 输入
- **值形态**：单个时刻 / `[起, 止]`
- **粒度**：时:分 / 时:分:秒
- **制式**：12 / 24 小时制
- **步长**：分步长、秒步长
- **可选范围**：最早 / 最晚时刻（min / max）
- **禁用时刻**：禁用列表或判定
- **时区 / 是否含时区**：对外值是否携带时区信息
- **显示格式 / 值格式**：面板显示与对外提交可不同但须明确
- **是否需确认**：范围与组合模式是否强制确认
- 其他：占位符、默认值、尺寸、是否可清空、状态（错误 / 禁用）

### 内部状态
- open（开合）
- 当前滚动位置 / 各列高亮项
- 范围选择的中间态（已定起点、未定终点）
- 12 小时制下的上下午
- 输入框草稿文本（手输未提交时）
- 加载 / 错误（异步加载可用时刻时）

### 输出
- **值变化事件**：新值（可选带旧值）
- **确认事件**：范围 / 组合模式在确认时抛出最终值
- 面板打开 / 关闭事件
- **值形态必须明确**：对外是时刻字符串、`时:分:秒` 还是时间段对象

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值，自身不存值
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「选了不变」或「外部改了不刷新」

### 异步与竞态
- 可用时刻远程加载时处理加载 / 空 / 错误三态
- **竞态**：后发请求先返回须丢弃过期结果
- 与日期组合提交时，时间先填、日期未填的中间态须可表达

### 校验与错误
- 组件负责时刻格式与可选约束；跨天、起止先后等业务校验在表单层
- 错误由外部传入（错误标记 + 文案），组件负责呈现

### 回填与序列化
- 初值 → 显示：按显示格式渲染并归一化（补零，秒可省略但要统一）
- **文本 ↔ 值双向解析一致**：手输与列选择走同一套归一化
- **时区**：若对外值不含时区，必须与日期部分约定同一基准，避免组合后错位
- 与日期组合成日期时间时，两部分的拼接与拆分规则须明确

## 无障碍
- 触发器：`textbox` / `combobox` + `aria-expanded`、`aria-haspopup`
- 列：`listbox` + `option` + `aria-selected`；或按 `spinbutton` 语义实现
- 12 / 24 制与上下午对读屏可读，不依赖颜色
- 禁用项标 `aria-disabled`；now 与 selected 状态可读
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 用时间选择表达「时长」而非「时刻」
- 步长与业务不符（既要 15 分钟粒度又要求任意分钟）→ 应放宽为文本输入
- 12 / 24 小时制在同一系统内混用
- 范围模式边选边生效 → 产生半成品值
- 忽略时区，组合成日期时间后整体错位
- now 与 selected 视觉不区分 → 状态混淆

## 边界与代价
- 步长过大又要精确值 → 改用文本输入
- 时区不定义 → 与日期组合后跨时区出错
- 起止先后校验只在提交 → 用户选到一半不知对错
- 越界循环规则不统一 → 上下滚动行为不一致
- 手输与列选择解析不一致 → 显示 / 取值不一致
