# 开关

表示一个**二元开 / 关状态**，操作后**立即生效**。

## 角色与边界

- **是什么**：一个在两态间切换的控件，点击即切换并即时生效。
- **解决什么**：「是 / 否」「启用 / 停用」这类二元设置，且改动应当马上生效。
- **不解决什么**：
  - 需要「改完再统一提交」的选择 → 复选框 / 单选按钮组（随表单一起提交）
  - 多个相互独立选项 → 复选框组
  - 三种以上状态 → 单选按钮组 / 下拉
  - 危险操作的二次确认 → 确认弹窗承担，开关本身只做开合
- **什么时候不用**：出现在「填完一屏、点提交才生效」的表单里 → 用复选框；把开关放进这种表单，用户会误以为改动已保存。
- **与复选框的区别**：
  | 维度 | 开关 | 复选框 |
  |---|---|---|
  | 生效时机 | **立即生效** | 随表单提交 |
  | 值 | 单个布尔 | 布尔（含于一组时是数组元素） |
  | 典型语义 | 某对象的属性开 / 关 | 是否包含某项 |
  | 异步 | 常承载异步切换（含 loading） | 一般不承载异步 |
  | 出现位置 | 设置项、即时操作 | 表单内 |

## UI

### 结构解剖
- **轨道 + 滑块（旋钮）**
- **状态文字**：轨内或两侧的「开 / 关」文案（可选）
- **图标**：轨内的勾 / 叉等（可选）
- **标签**：开关旁的描述文字
- **副说明文案**：标签下方的一行解释
- **加载态**：异步切换中的占位
- **状态文案**：如「已开启 / 已关闭」的外露文本（可选）

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响轨道尺寸与滑块大小
- 是否带文字 / 图标
- 开状态的方向约定：**滑块在右 = 开**（须全系统统一，不得混用）
- 是否有标签与说明文案
- 状态类：默认 / 禁用 / 加载 / 错误 / 只读

### 视觉状态（逐条）
| 状态 | 轨道 | 滑块 |
|---|---|---|
| default（关） | 中性底色 | 位于关闭侧 |
| on（开） | 强调色 | 位于开启侧 |
| hover | 轨道微亮 / 描边 | 滑块阴影加深 |
| focus-visible | 明显焦点环（落在轨道上） | — |
| active（按下） | 轨道轻微变化 | 滑块轻微放大 |
| disabled（关 / 开） | 整体降透明、禁用指针 | 不可拖动、位置保持当前态 |
| loading | 显示 spinner / 进度 | 位置保持，不抖动 |
| readonly | 外观同默认，但不可切换 | 可聚焦、可读 |
| error | 轨道变红 + 下方错误文案 | — |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 开关与标签垂直居中对齐；标签在左或右全系统保持一致
- 说明文案置于标签下方
- 开关本体可小，但**整行（开关 + 标签）应是可点区域**，扩大命中

### 移动端
- 触摸目标 ≥ 44×44；本体小但热区整体可点
- 避免紧贴屏幕边缘，防误触系统手势

## 交互

### 核心操作
- 点击 / 按 `Space` → 切换状态
- **立即生效**：切换即抛出值变化事件
- 异步：先进入 loading，成功后落值；**失败必须回滚**

### 输入与选择行为
- 整行（开关 + 标签 + 说明）可点击切换
- 加载中禁止再次点击，防重复提交
- **选用乐观更新还是等待结果**必须定义：
  - 乐观更新：点击立即翻转，失败再回滚（响应快，但需处理回滚与竞态）
  - 等待结果：点击后保持原态并显示 loading，成功才翻转（稳，但反馈慢）

### 键盘
| 键 | 行为 |
|---|---|
| `Tab` | 聚焦开关 |
| `Space` | 切换状态 |
| `Enter` | （可选）同 Space，视框架约定 |

- 开关只有两态，方向键默认不参与切换；若按滑杆语义实现可选支持方向键，但须全项目统一。

### 指针与手势
- 点击切换
- 移动端可支持滑动切换（可选增强，非默认），滑动阈值须定义

### 焦点管理
- 切换后焦点留在开关上
- 禁用不可聚焦；只读可聚焦但不可切换

### 动画与过渡
- 滑块左右移动 + 轨道变色，约 100–200ms
- 进入 / 退出 loading 时滑块位置保持，不产生抖动
- 回滚时动画方向要表达「退回」，避免被误认为又切换了一次

### 反馈
- 状态变化即反馈（颜色 + 位置）
- 异步中显示 loading；失败回滚并给出明确提示（toast / 行内文案）
- 无权限 / 不可切换时，若禁用须说明原因（tooltip 或说明文案）

### 边界交互
- **异步失败回滚**：值必须回到切换前，并提示用户
- **快速连点**：防抖 / 排队 / 加载中禁点，避免请求风暴
- 权限不足：禁用并说明原因，不能只是点不动
- 若开关依赖其他条件（如「需先启用总开关」），禁用时应表达依赖关系

## 数据流

### 输入
- **当前值**（布尔 / null）
- **标签 / 说明文案**
- 是否禁用 / 是否加载
- 尺寸
- 开 / 关状态文案
- 其他：是否带图标、错误文案

### 内部状态
- 内部当前值（非受控时）
- loading
- 乐观更新的临时值（若采用）
- 错误提示态

### 输出
- **值变化事件**：新布尔值
- 通常**无「确认」事件**（立即生效语义）
- 若异步，可能有「切换成功 / 失败」事件供外部处理

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值；**异步回滚也要通过事件把值退回**
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「点了不变」或「外部改了不刷新」

### 异步与竞态
- 切换触发远程请求：loading → 成功落值 → 失败回滚
- **竞态**：连续切换时，旧请求返回不得覆盖新状态（按请求标识丢弃过期结果）
- 失败反馈：明确提示 + 值回滚，二者都要做

### 校验与错误
- 组件本身不做业务校验；冲突（如不允许关闭）应由外部禁用并说明
- 错误由外部传入（错误标记 + 文案），组件负责呈现

### 回填与序列化
- 布尔值直接映射
- **null / 未设置 与 false 是否区分必须定义**：三态场景（未知 / 开 / 关）不能塞进纯布尔
- 序列化为布尔（或按约定保留 null）

## 无障碍
- `role="switch"` + `aria-checked`
- 关联标签用 `aria-labelledby`；说明文案用 `aria-describedby`
- loading 用 `aria-busy`；禁用用 `aria-disabled`
- 全键盘可达（`Space`）
- `focus-visible` 可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 在需要提交的表单里用开关 → 语义是立即生效，用户误以为可撤销
- 异步开关无 loading → 用户重复点击
- 失败不回滚 → 界面与真实状态不符
- 用开关做多选 / 三态
- 开 / 关方向不统一（有的左开有的右开）→ 认知负担
- 无权限时不解释原因 → 用户不知为何点不动

## 边界与代价
- 二元但需「改完再提交」→ 改用复选框
- 异步不回滚 → 状态错乱
- 无防连点 → 请求竞态、重复提交
- 需要三态却强塞布尔 → 语义丢失
- 只做禁用不做说明 → 可用性差
