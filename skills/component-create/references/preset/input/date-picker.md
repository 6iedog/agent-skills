# 日期选择

从日历中**选一个、一段或多天**日期，结果是一个日期（或日期区间 / 日期数组）。

## 角色与边界

- **是什么**：以日历面板为载体的日期输入控件，可展开日历、可手输，取值是日期而非普通文本。
- **解决什么**：需要选具体日期 / 日期区间 / 多个日期，并希望有日历作为参照与约束。
- **不解决什么**：
  - 只选时刻 → 时间选择
  - 同时需要日期 + 时刻 → 日期时间选择（由本组件与时间选择组合而成）
  - 候选项是固定集合、非日历语义（如「财年季度」）→ 单选下拉
  - 必填 / 业务规则校验 → 属于表单层，本组件只呈现错误态
- **什么时候不用**：只需在少数几个固定日期中选（如「本周一 / 本周五」）→ 单选按钮组或直接给快捷按钮；只需相对时间（近 7 天等）且不关心具体哪天 → 快捷项直接落到值即可，不必暴露日历。

---

## UI

### 结构解剖
- **触发器**：一行输入框，左为已选日期文本（或占位符），右为日历图标；可含清空按钮
- **输入区**：可手输日期字符串
- **弹出面板**：日历浮层
- **面板头**：上一月 / 下一月切换、当前年月标题（可点击逐级钻取）、「今天」按钮
- **星期表头**：周一到周日的列头
- **日期网格**：周 × 日，含本月与外溢的上 / 下月日期
- **月面板 / 年面板 / 十年面板**：点击标题后逐级钻取
- **快捷项侧栏**：今天、昨天、近 7 天、本月、最近 30 天、自定义区间等
- **双月并排**：范围模式下起止两个连续月份并排
- **时间附加区**：日期时间模式下，面板底部的时间输入
- **状态占位**：面板内的加载 / 空位

### 尺寸与外观变体
- 选择模式：**单日** / **范围** / **多选**
- 面板粒度：日 / 月 / 年 / 十年（钻取层级）
- 是否带快捷项、是否可手输
- 是否附加时间（日期时间模式）
- 形态：**内联日历**（常驻页面） / **浮层日历**（收起在触发器后）
- 尺寸：小 / 中 / 大 → 影响触发器高度、字号、单元格边长
- 状态类：默认 / 错误 / 警告 / 禁用

### 视觉状态（逐条）
| 状态 | 触发器 | 面板 / 单元格 |
|---|---|---|
| default | 边框默认、占位符浅色 | 常规日期可点 |
| hover | 边框加深 | 悬停单元格背景微亮 |
| focus-visible | 明显焦点环 | 焦点单元格有独立焦点环（与选中态区分） |
| open | 边框高亮 + 图标变化 | 面板出现 |
| selected（单日） | 显示所选日期 | 该单元格填充高亮 |
| range-start / range-end | 显示区间文本 | 两端点加粗填充，形状与其他内区间不同 |
| in-range（区间内） | — | 起止之间浅色连片高亮 |
| today | — | 今天有区别于选中态的描边或标记 |
| outside-month（外溢日） | — | 相邻月日期弱化显示；可点或不可点必须定义 |
| disabled | 整体降透明（若整体禁用） | 禁用日期灰显、不可点 |
| readonly | 外观同 default，但不可展开 | — |
| error | 边框红 + 下方错误文案 | — |
| loading | 触发器可显示加载 | 面板内骨架 / spinner |
| empty | — | 无可用日期时占位文案 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。
- **today 与 selected 不得用同一种视觉**：否则用户分不清「今天是哪天」与「我选了哪天」。

### 布局与对齐
- 日期网格为固定 7 列，单元格等宽等高
- 范围模式两月并排且连续，中间不留断月
- 面板宽度固定，窄屏下缩为单月
- 靠近视口底部时**向上翻转**，避免出屏
- 超长日期文本在触发器内截断，悬停显示完整

### 移动端
- 桌面浮层日历在小屏体验差：改为**底部弹层 / 全屏日历**
- 触摸目标 ≥ 44×44，单元格间距加大防误触
- 范围与多选在小屏优先竖排或分步选择，不做窄浮层双月

## 交互

### 触发与开合
- 打开：点击触发器 / 聚焦后 `Enter`、`Space`、`↓`
- 关闭：`Esc`、点击外部、单日选完即收；范围 / 多选通常在选完后收或需确认
- 可手输时：输入合法即回填并可直接收起
- 面板自动避让视口边缘

### 输入或选择行为
- **单日**：点日期立即选中并收起
- **范围**：第一次点为起点，第二次点为终点；第二次早于起点时交换两端（或禁止，须定义）
- **多选**：反复点选 / 取消，每个日期独立切换
- **面板钻取**：点标题 → 月面板 → 年面板 → 十年面板；选中上一级后回到日期网格
- **快捷项**：点一下即选中对应区间（可含时间，须定义）
- **手输解析**：必须定义可接受的格式与不合法输入的处理（保留原文并标错 / 拒绝 / 忽略）

### 键盘
| 键 | 行为 |
|---|---|
| `Tab` | 聚焦 / 离开触发器与面板 |
| `Enter` / `Space` | 打开；面板内确认选中当前焦点日 |
| `Esc` | 关闭且**不改变值** |
| `←` / `→` | 焦点日前后一天 |
| `↑` / `↓` | 焦点日前后一周 |
| `Home` / `End` | 跳到本周首 / 末 |
| `PageUp` / `PageDown` | 上一月 / 下一月（`Shift` 同按则切年） |
| 面板打开时 | 焦点落在当前选中日；无选中则落在今天 |

### 指针与手势
- 点单元格选中；范围模式可按住拖动连选（可选增强）
- 移动端：点触发器 → 底部弹层；点日期 → 选中
- 悬停单元格高亮

### 焦点管理
- 关闭后焦点**回到触发器**（不得丢到 body）
- 面板打开即聚焦到选中日 / 今天，键盘导航从该点开始
- 范围选择中，焦点停留在刚设定的端点上

### 动画与过渡
- 面板出现 / 消失：轻微位移 + 淡入淡出，约 100–200ms
- 面板层级切换（日 → 月 → 年）：滑动或淡入，方向与钻取方向一致
- 选区连片高亮的扩张应即时，不滞后

### 反馈
- 选中即反馈（单元格高亮）
- 手输非法：立即标错 + 文案，不静默丢弃
- 命中禁用日期：不可点 / 点后明确提示禁用原因（若外部提供）

### 边界交互
- **禁用日期落在范围内**：范围模式须定义区间内是否允许禁用日（通常允许，仅端点不可为禁用日）
- **今天与当前时间**：以用户本地「今天」为准，跨零点需刷新
- **跨年 / 跨月范围**：双月并排与滚动切换需连续
- **时区**：见数据流，显示与取值必须统一基准
- **手输与面板冲突**：先手输再开面板时，面板应定位到该日期

## 数据流

### 输入
- **值形态**：单个日期 / `[起, 止]` / `[日期…]`
- **粒度**：日 / 月 / 年
- **可选范围**：最早 / 最晚日期（min / max）
- **禁用日期**：禁用列表或禁用判定函数（含周末、节假日）
- **时区 / 基准**：以本地时区还是 UTC 解释与显示
- **显示格式 / 值格式**：面板显示的格式与对外提交的格式，两者可不同但须明确
- **快捷项配置**：内置项开关、自定义项
- 其他：占位符、默认值、尺寸、是否可清空、状态（错误 / 禁用）

### 内部状态
- open（开合）
- 当前面板层级（日 / 月 / 年 / 十年）
- 当前显示的月份
- 范围选择的中间态（已定起点、未定终点）
- 输入框草稿文本（手输未提交时）
- 键盘焦点日
- 加载 / 错误（异步加载可用日期时）

### 输出
- **值变化事件**：新值（可选带旧值）
- 面板打开 / 关闭事件（供外部联动）
- 面板层级 / 月份切换事件（异步加载该月可用日期时把目标月抛给外部）
- **值形态必须明确**：对外是日期字符串、时间戳还是日期对象——这决定回填、比较与序列化

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值，自身不存值
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「选了不变」或「外部改了不刷新」

### 异步与竞态
- 可用日期 / 禁用日期远程加载：处理加载 / 空 / 错误三态
- **竞态**：快速切月时，后发请求先返回须丢弃过期结果（按月份或请求标识）
- 可按月缓存可用日期，避免重复请求

### 校验与错误
- 组件只负责「当前值」与「可选约束的呈现」；必填、业务规则校验在表单层
- 错误由外部传入（错误标记 + 文案），组件负责呈现
- 手输非法属组件自身可即时呈现的错误

### 回填与序列化
- 初值 → 显示：按显示格式渲染；无法解析时兜底（显示原文 或 留空并标错）
- **文本 ↔ 值双向解析必须一致**：手输解析与面板选择走同一套归一化，否则出现「手输和点击结果不同」
- **时区归一化**：存与取必须同一基准，避免「存本地、显 UTC」导致差一天
- 序列化格式（如 `YYYY-MM-DD` 字符串 / 时间戳）必须与后端约定一致

---

## 无障碍
- 触发器：`textbox` / `combobox` + `aria-expanded`、`aria-haspopup`
- 面板：`grid` / `table`；单元格 `gridcell` + `aria-selected`，禁用日 `aria-disabled`
- 星期表头、当前月份标题对读屏可读
- 今天与选中态对读屏可辨（不依赖颜色，须有可读文本或状态）
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 只有少量固定日期仍上日历 → 按钮 / 单选按钮组更直接
- 手输格式不明确、解析与显示不一致 → 用户输得进去却显示错乱
- 用本地时区存储、用 UTC 显示 → 日期整体差一天
- 范围模式不禁用中间日期也未定义 → 选到无效区间
- 移动端照搬桌面双月浮层 → 触摸体验差
- today 与 selected 同款高亮 → 状态混淆

## 边界与代价
- 时区基准不明确 → 跨时区差一天
- 手输与面板两套解析 → 显示 / 取值不一致
- 禁用日期规则与范围选择不协调 → 用户无法完成选择
- 值格式与提交格式不一致 → 后端解析失败
- 异步可用日期无竞态处理 → 切月后显示错误月份的可用状态
