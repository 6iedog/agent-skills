# 自动完成

在输入框中**边输边给建议**，从候选中快速选定，并可选地允许自由输入。

## 角色与边界

- **是什么**：输入框 + 悬浮候选列表；随输入过滤（本地）或请求（远程）建议，可键盘选择。
- **解决什么**：值来自一个大集合、用户记不全（城市、用户名、商品、搜索词），边打边收窄。
- **不解决什么**：
  - 只是从固定小集合里选、不需要打字 → 单选下拉
  - 在自由文本里 @ 引用实体 → 提及
  - 需要累积多个值 → 标签输入
  - 纯粹的搜索跳转、不承载值语义 → 搜索框
  - 需要层级收窄 → 级联选择
- **什么时候不用**：候选极少（≤ 5）且固定 → 单选下拉 / 单选按钮组（一眼可见更快）。

## UI

### 结构解剖
- **输入框**：同普通输入框，可带前缀图标、清空按钮
- **候选浮层**：位于输入框下方，含候选行
- **候选行**：展示文本（+ 副文本 / 图标）
- **匹配高亮**：命中的子串加粗或着色
- **分组标题**：分组模式下每组一行标题
- **状态位**：浮层内的加载 / 空 / 错误

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响高度、行高、字号
- 模式：**自由输入**（可提交任意值）/ **必选**（只能从候选里选）
- 来源：本地过滤 / 远程请求
- 变体轴：是否分组、是否显示副文本、是否高亮匹配、是否可清空、是否只读 / 禁用

### 视觉状态（逐条）
| 状态 | 输入框 | 浮层 / 候选 |
|---|---|---|
| default | 边框默认、占位符浅色 | 未出现 |
| hover | 边框加深 | — |
| focus-visible | 明显焦点环 | — |
| open | 边框高亮 | 浮层出现 |
| active（高亮候选） | — | 该行背景加深（键盘 / 悬停） |
| selected（已选定） | 显示值 | 该行可带勾选 |
| composing（IME） | 光标带下划线 | 组合结束前不建议触发请求 |
| loading | 可带 spinner | 骨架 / spinner |
| empty | — | 空状态文案 |
| error | 边框红 + 文案 | — |
| disabled | 整体降透明、不可聚焦 | 不出现 |
| readonly | 外观正常、可复制 | 不出现 |

### 布局与对齐
- 浮层宽度默认与输入框对齐；内容长时可加宽
- 浮层最大高度受限，候选多时**列表内滚动**
- 靠近视口底部时**向上翻转**
- 候选文本截断，悬停显示完整值

### 移动端
- 浮层改为**整宽列表**（或底部弹层），避免窄浮层
- 触摸目标 ≥ 44×44
- 键盘弹出时浮层须避免被遮挡（置于输入框上方或压缩）

## 交互

### 触发与开合
- 打开：输入非空（或聚焦即开）；过滤 / 请求后出现候选
- 关闭：清空输入、`Esc`、选中一项、点击外部、无候选、`Tab` 移出
- 打开时机须明确：**聚焦即开** 还是 **输入后开**

### 输入行为
- 输入即过滤（本地）或请求（远程）；高亮匹配片段
- 默认高亮第一项；输入变化后重置高亮
- **自由输入模式**：失焦或回车时若未选候选，按当前输入串提交值
- **必选模式**：值只能来自候选；手打的不匹配串不落地（或标「无匹配」）
- 选中候选后：填入并关闭浮层；可配置是否在值后追加空格

### 键盘
| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在候选间移动高亮 |
| `Enter` | 选高亮候选；无候选时提交输入串（自由模式） |
| `Esc` | 关闭浮层（保留输入）；再按可清空（可配置） |
| `Tab` | 选高亮候选 或 移出焦点——须明确 |
| `Home` / `End` | 跳到候选首 / 末 |
| `Backspace` | 删字符；输入清空后关闭浮层 |

### 指针与手势
- 点候选：选中并关闭
- 悬停候选高亮
- 触摸端滚动候选列表

### 焦点管理
- 焦点始终在输入框；浮层不抢焦点
- 关闭后焦点回到输入框；选中后焦点保持输入框

### 动画与过渡
- 浮层淡入 + 轻微位移，约 100–200ms
- 候选列表刷新时避免整体闪烁

### 反馈
- 远程：加载中显示骨架 / spinner；失败显示错误 + 重试入口
- 无匹配：空状态文案（不要静默无反馈）
- 选中：值即反馈，不额外提示

### 边界交互
- 快速输入：防抖；**丢弃过期结果**（竞态）
- 候选分页：滚动到底部加载更多（远程）
- 已输入值从候选中消失时：保留已输入值，不强行清空

## 数据流

### 输入
- 候选数据（本地）或搜索函数（远程）
- 配置：匹配规则（前缀 / 包含 / 模糊）、最少触发字符数、防抖时长、是否自由输入、是否分组、尺寸状态

### 内部状态
- 输入串
- 浮层开合、高亮索引
- **当前候选集**（远程时）
- 加载 / 错误状态
- 请求标识（用于竞态）

### 输出
- **值变化事件**：字符串（自由）或候选值 / 候选对象（必选）
- 输入事件（远程搜索时把输入串抛给外部）
- 选中事件（带被选候选）
- **值形态必须明确**：是字符串、id 还是整个候选对象——决定回填与比较

### 受控 / 非受控
- 输入值可受控，选中项也可受控；须明确**哪个**受控
- 非受控：给默认输入 / 默认选中项
- **二选一必须明确**；混用会出现「选了不变」或「外部改了不刷新」

### 异步与竞态
- 防抖 + 最少字符数门槛（如 ≥ 2）
- **竞态**：后发请求先返回时，按请求标识或时间戳丢弃过期候选（否则「输 A 显示 B 的结果」）
- 相同关键词可缓存，不重复请求

### 校验与错误
- 必选模式：值必须属于候选集，否则报错
- 自由模式：可叠加格式校验
- 组件只呈现错误；规则由外部给

### 回填与序列化
- 初值 → 显示为输入串；若值是对象，按值查候选取展示文本
- 序列化：自由模式输出输入串；必选模式输出候选值 / id
- 回填时须校验初值是否仍在候选集内，否则标记「已失效」

## 无障碍
- 输入框用 `combobox` 语义，带 `aria-expanded`、`aria-autocomplete`、`aria-controls`
- 浮层用 `listbox`，候选用 `option` + `aria-selected`；高亮项用 `aria-activedescendant` 关联
- 加载 / 空状态用 `aria-live` 播报
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 必选场景却允许自由输入 → 脏值
- 远程搜索无防抖、无竞态处理 → 结果显示错乱
- 输入 1 个字符就发请求 → 请求风暴
- 无候选时静默无反馈 → 用户以为卡住
- 移动端照搬窄浮层 → 遮挡、不可用
- 只支持前缀匹配却不支持包含匹配 → 用户找不到

## 边界与代价
- 候选集极大且远程 → 必须分页 + 防抖 + 竞态处理
- 模糊匹配过宽 → 候选噪声大，反而更难选
- 必选与自由混用不说明 → 最终值与候选不一致
- 不做竞态处理 → 出现「搜 A 显示 B」
- 移动端窄浮层 → 触摸与可见性问题
