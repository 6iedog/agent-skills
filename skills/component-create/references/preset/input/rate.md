# 评分

用一排图标（通常是星）**打分**，表达评价等级。

## 角色与边界

- **是什么**：一排等权图标，点击第 N 个表示「N 分」；可交互也可只读展示。
- **解决什么**：快速表达偏好 / 满意度 / 等级（如 1–5、1–10 分）。
- **不解决什么**：
  - 精确数值评价（如 8.7 分）→ 数字输入 / 滑块
  - 多维度评价 → 多组评分或交给表单
  - 二元「喜欢 / 不喜欢」→ 点赞按钮 / 开关
  - 选项自带文字语义的等级（「差 / 中 / 好」）→ 单选按钮组
- **什么时候不用**：等级本身需要用户理解文字含义（不是一眼可懂的星数）→ 单选按钮组 / 分段控件。
- **与「滑块」的区别**：评分是**离散、等分、带符号含义**的等级，重点是图标与提示；滑块是连续 / 相对位置，重点是区间。需要「精确连续值」用滑块，需要「几颗星」的等级表达用评分。

## UI

### 结构解剖
- **图标行**：一排等距图标（星 / 心 / 任意可替换图标）
- **单个图标**：可含半星（左半 / 右半分别命中）
- **高亮层**：已选部分与悬停预览部分的填充
- **当前值数字**：显示分数（可选）
- **提示文案**：随分值变化的短评（如「一般」「非常好」）
- **说明文案**：解释 1 分的含义（如「很不满意」）
- **清空入口**：再次点击当前值，或独立清空按钮
- **只读展示形态**：纯展示、无交互

### 尺寸与外观变体
- 可交互 / **只读**
- 允许半星 / 仅整星
- 是否可清除
- 图标总数：3 / 5 / 10…
- 图标可替换（星 / 心 / 自定义字符或图形）
- 是否显示提示文案 / 数值
- 尺寸：小 / 中 / 大 → 影响图标大小与间距

### 视觉状态（逐条）
| 状态 | 图标 | 整行 |
|---|---|---|
| default（未评） | 全部未填充 | 提示文案显示中性态或默认 |
| hover（预览） | 高亮到悬停的那一颗 | 提示文案随预览值变化 |
| focus-visible | 焦点环落在当前值位置 | — |
| active（按下） | 图标轻微缩放 / 加深 | — |
| selected（已评） | 高亮到已选值 | 提示文案对应已选值 |
| half（半星） | 单颗图标半填充 | — |
| readonly | 按值静态高亮，无交互 | 无悬停预览 |
| disabled | 整体降透明、禁用指针 | 不可交互 |
| error | 图标描边变红 | 下方错误文案 |

- **hover 预览与 selected 必须分离**：鼠标移开后必须回到已选值，不得把预览值落成实际值。

### 布局与对齐
- 图标等距排列，间距一致；图标与数值 / 文案垂直对齐
- 提示文案位置固定（右侧或下方），随分值变化时不引起布局跳动（预留宽度或固定位置）
- 半星图标的左右命中区需在视觉上公平划分

### 移动端
- 加大图标命中区；触摸目标 ≥ 44×44（图标间距加大防误触）
- 半星在小屏容易误触，若非必要不启用
- 只读与可交互必须在视觉上区分清楚（避免用户去点不可点的星）

## 交互

### 核心操作
- 点击第 N 颗图标 → 值 = N
- 再次点击当前值 → 清空（若允许）
- 悬停 → **预览高亮**到该值（不落值）
- 半星：点击图标的左半 / 右半分别表示 N-0.5 / N

### 输入与选择行为
- 悬停预览与已选值分离：移开后回到已选值
- 半星判定区域（左半 / 右半）必须明确，命中区不能过小
- 清空逻辑二选一：点已选值清空 / 独立清空按钮，须明确定义
- **键盘能否选半星**：通常键盘只到整数，若半星重要须说明键盘替代路径

### 键盘
| 键 | 行为 |
|---|---|
| `Tab` | 聚焦整组（**单一 Tab 停靠点**） |
| `←` / `↓` | 减小一分 |
| `→` / `↑` | 增大一分 |
| `Home` / `End` | 跳到最小 / 最大 |
| `Delete` / `Backspace` | 清空（若允许） |
| 数字键 | 直接跳到第 N 分（可选增强） |

### 指针与手势
- 悬停预览、点击落值
- 半星按左 / 右半区点击
- 只读态无任何指针反馈

### 焦点管理
- 整组为单一 Tab 停靠点；焦点环落在当前值位置
- 只读不可聚焦；禁用不可聚焦
- 落值后焦点保持在组上，便于继续用方向键调整

### 动画与过渡
- 图标点亮：填充 / 缩放过渡短，约 100ms
- 悬停预览即时，不滞后
- 提示文案切换可淡入，避免跳变

### 反馈
- 落值后图标填充；可同时显示数值与文案
- 触顶 / 触底时方向键无效，应静默钳制（不报错）

### 边界交互
- 值超过总数 / 为负：钳制到 `[0, 总数]`
- **未评（null）与 0 分必须区分**：未评 = 尚未打分，0 分（若允许）= 打分为零
- 半星模式下键盘选值只到整数，须说明
- 只读 + 悬停：只读态不应有预览行为

## 数据流

### 输入
- **图标总数**
- 是否允许半星
- 是否可清除
- 图标 / 尺寸 / 是否只读
- **默认值**
- **提示文案映射**：每个分值对应的文案
- 其他：是否显示数值、状态（错误 / 禁用）

### 内部状态
- 当前值
- **悬停值（预览）**——与当前值分离的临时状态
- 只读标记
- 焦点位置

### 输出
- **值变化事件**：新值（可为 null 表示清空）
- 悬停变化事件（可选，供外部同步展示文案）
- 清空事件（可选，便于区分是「调到 0」还是「清除」）
- **值形态必须明确**：数字、支持小数（半星）或 null

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值；**悬停预览仍由组件内部维护**
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「点了不变」或「外部改了不刷新」

### 异步与竞态
- 值提交到远程（如提交评分）：提交中可置 loading 或禁用，防重复提交
- **失败回滚**：提交失败须把值恢复到提交前，并提示
- **竞态**：快速改分时，旧请求返回不得覆盖新值

### 校验与错误
- 「必评」校验在表单层；组件呈现错误态
- 错误由外部传入（错误标记 + 文案），组件负责呈现

### 回填与序列化
- 值 → 点亮的图标数（半星 → 半填充）
- **未评（null）与 0 分区分**：回填与序列化时都要保留这一差异
- 序列化为数字（含小数）或 null
- 图标可替换时，仍须提供可访问名称（如「4 分，共 5 分」）

## 无障碍
- 两种可行语义，须选定其一并写清：
  - **单选组**：`radiogroup` + 每颗星 `radio` + `aria-checked`
  - **滑杆**：整组 `slider` + `aria-valuemin` / `aria-valuemax` / `aria-valuenow` / `aria-valuetext`
- 只读：用可读文本表达（如「评分 4，共 5」），不依赖图标
- 提示文案通过 `aria-describedby` 关联
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）
- 禁用标 `aria-disabled`

---

## 常见误用
- 用评分承担精确 / 多位小数的评价
- 悬停预览与已选值不分离 → 鼠标移开后值变了
- 半星命中区太小 → 移动端误触
- 只读态仍可点 → 造成误导
- 未评与 0 分不区分 → 无法判定「用户是否打过分」
- 图标被替换却无可访问名称 → 读屏读不出

## 边界与代价
- 需要精确 / 多维度评价 → 换组件
- 半星使键盘与读屏复杂，非必要不启用
- 「可清除」与「必评」冲突须在表单层协调
- 异步提交不回滚 → 界面与真实评分不符
- 图标可替换时不做无障碍命名 → 不可访问
