# 提及

在文本输入中通过触发符（如 `@`）唤起候选，**按光标位置插入一个引用块**，可多次出现。

## 角色与边界

- **是什么**：宿主是文本输入（多为多行文本域），在光标处输入触发符后弹出候选，选中后插入一段「提及块」（人、标签、页面、命令），该块作为一个整体存在。
- **解决什么**：在自由文本里**结构化引用**实体（提及某人 / 某话题 / 某文档），既可读，又能在提交时解析出实体标识。
- **不解决什么**：
  - 值本身就是一组标签 → 标签输入
  - 只联想补全整条文本 → 自动完成
  - 富文本 / 图文混排 → 富文本编辑器
  - 引用块需要复杂内联 UI（卡片、可展开）→ 富文本编辑器的嵌入式节点
- **什么时候不用**：实体只作纯文本展示、无需解析 → 普通输入；引用是主体而非点缀 → 标签输入。

---

## UI

### 结构解剖
- **宿主输入区**：多行文本域（也可单行）
- **提及块**：插入后的内联标记，形如「@张三」，可高亮或带底色，通常作为**不可拆分的整体**
- **触发符**：`@` / `#` / `/` 等，紧贴光标
- **候选浮层**：锚定在光标附近（或输入框下方），含候选行
- **候选行**：展示名（+ 头像 / 图标 / 副文本）
- **匹配高亮**：命中子串加粗或着色
- **状态位**：浮层内的加载 / 空 / 错误

### 尺寸与外观变体
- 尺寸：小 / 中 / 大
- 触发符类型：提及人 / 话题 / 命令 等，可多套并存
- 候选来源：本地 / 远程
- 变体轴：是否分组、是否带头像、是否允许重复提及同一实体、是否只读 / 禁用

### 视觉状态（逐条）
| 状态 | 输入区 | 浮层 / 提及块 |
|---|---|---|
| default | 边框默认、占位符浅色 | 未出现 |
| hover | 边框加深 | 悬停候选背景微亮 |
| focus-visible | 明显焦点环 | — |
| open | 边框高亮 | 浮层出现 |
| active（高亮候选） | — | 该行背景加深 |
| composing（IME） | 光标带下划线 | **组合态不触发 / 不提交** |
| loading | — | 骨架 / spinner |
| empty | — | 空状态文案 |
| disabled | 整体降透明、不可聚焦 | 不出现 |
| readonly | 外观正常、值可复制 | 提及块整块可复制 |

### 布局与对齐
- 浮层锚定：优先贴近**光标**；多行若不支持光标定位，则锚定输入框
- 浮层**悬浮**，不挤占输入布局（避免文本跳动）
- 候选行固定高度、文本截断
- 提及块与普通文本基线对齐

### 移动端
- 候选浮层改为**整宽列表**或底部弹层；光标处定位在移动端通常不可靠，退化处理
- 触摸目标 ≥ 44×44
- 提及块点击热区放大

## 交互

### 触发与插入（核心操作）
- 输入触发符（如 `@`）→ 记录锚点位置 → 打开浮层 → 过滤 / 请求候选
- 选择候选 → 在锚点处**替换「触发符 + 已输入查询串」为提及块** → 光标移到块后 → 关闭浮层
- 取消（`Esc` / 退格到触发符前 / 点击外部）→ 移除触发符与查询串，恢复普通文本
- 同一段文本里可**多次提及**，块之间可穿插自由文字

### 输入行为
- 触发符后的字符作为查询词，实时过滤 / 请求
- 触发条件须明确：触发符紧跟**行首、空格或标点**才算，避免邮箱、网址里的 `@` 误触
- 提及块插入后：删除键**整体删除整块**，不进入块内部编辑
- **IME 组合态**：触发符与查询词的中文组合过程中不得误触发 / 误提交
- 粘贴含 `@` 的文本：是否解析为提及块须明确（一般**不解析**，保持纯文本）

### 键盘
| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 在候选间移动高亮 |
| `Enter` | 选高亮候选，插入提及块 |
| `Tab` | 选高亮候选插入（常与 `Enter` 同义） |
| `Esc` | 关闭浮层、撤销本次触发 |
| `Backspace` | 查询为空时删除触发符并关闭；块后用删除键删整块 |
| `←` / `→` | 移动光标；若块为整体则按整体跨越 |
| `Home` / `End` | 行首 / 行尾 |

### 指针与手势
- 点候选插入
- 悬停候选高亮
- 点提及块：可显示详情弹层或跳转（可选）
- 触摸端滚动候选列表

### 焦点管理
- 焦点始终在宿主输入区；浮层不抢焦点
- 插入后光标紧跟块后
- 撤销触发后光标回到触发符原位置

### 动画与过渡
- 浮层淡入，约 100–150ms
- 提及块插入时可轻微高亮一下再恢复（可选）

### 反馈
- 远程候选：加载 / 空 / 错误
- 无匹配：空状态文案
- 插入成功：提及块即反馈

### 边界交互
- 超长候选：截断 + tooltip
- 引用不存在的实体：保留为纯文本 或 标红——须明确
- 快速连续触发：防抖 + 竞态
- 光标后仍有文本时插入：**不得覆盖后续文本**

## 数据流

### 输入
- 候选数据 / 搜索函数
- 配置：触发符集合、触发条件（前一字符）、匹配规则、最少查询长度、是否分组、是否允许重复、尺寸状态

### 内部状态
- 浮层开合
- **锚点位置**（触发符起止）
- 查询串、高亮索引、候选集、加载 / 错误
- **提及块列表**（含位置与实体标识）

### 输出
- **值**：通常同时给出「原始文本（含 `@名`）」与「提及列表（实体标识 + 位置）」
- 值变化事件；选中事件
- **形态必须明确**：提交时给纯文本 还是 结构化（文本 + 实体引用）——推荐两者都给

### 受控 / 非受控
- 宿主文本可受控；提及块若为整体，受控下需按结构化模型回写
- 非受控：给默认文本
- **二选一必须明确**

### 异步与竞态
- 远程候选：防抖 + 按请求标识丢弃过期结果
- 不同触发符并发（先 `@` 后 `#`）要能区分请求

### 校验与错误
- 引用的实体失效 / 无权限：标红或降级为纯文本——须明确
- 是否要求至少一个提及：属表单层规则

### 回填与序列化
- 初值：结构化模型 → 渲染文本 + 提及块；纯文本 → 全部当普通文本（**不反解**）
- 从纯文本反解 `@名` 到实体**不稳健**（重名、含空格、重名不同人），优先用结构化初值
- 序列化：输出文本 + 实体标识列表（位置可省略）

---

## 无障碍
- 输入区保持文本输入语义；提及块须有可读文本（如「提及 张三」）
- 浮层用 `listbox` + `option` + `aria-selected`
- 触发与插入对键盘可用
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 触发条件过松（任意 `@` 都触发）→ 邮箱 / 网址误触
- 用正则从纯文本反解提及 → 重名、含空格名字解析错乱
- 提及块可进入内部编辑 → 状态难维护
- 不支持光标处定位 → 多行文本里浮层飘错位置
- IME 组合态误触发
- 值只给纯文本、不给实体标识 → 后端无法可靠解析

## 边界与代价
- 多段提及 + 自由文本混排 → 位置模型复杂，须结构化存储
- 远程候选无竞态处理 → 候选错乱
- 靠文本反解实体 → 不可靠，务必存结构化引用
- 触发符与业务文本冲突（如代码里的 `@`）→ 需可配置触发条件或转义
- 移动端浮层定位困难 → 退化为整宽列表
