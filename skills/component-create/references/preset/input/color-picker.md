# 颜色选择

选取一个颜色值，可用预设色板、取色器或数值输入，可选透明度。

## 角色与边界

- **是什么**：产出一个颜色值的控件，形态为「色块触发器 + 浮层」（含色板、取色器、数值输入），或内联色板。
- **解决什么**：让用户选 / 调一个颜色（主题色、标签色、图表色、画笔色）。
- **不解决什么**：
  - 选颜色的「名称」（如「红色」）而非色值 → 单选下拉
  - 编辑渐变 / 多点色标 → 渐变编辑器
  - 管理整套配色方案 / 调色板 → 专门的调色板工具
  - 颜色仅用于展示、不可改 → 只读色块
- **什么时候不用**：可选色就是几个固定色 → 内联色块单选（一眼可见，无需浮层）；颜色只是展示 → 只读色块。

---

## UI

### 结构解剖
- **触发器**：一个色块 + 可选色值文本 + 展开箭头
- **浮层**，可含以下子区：
  - **预设色板**：若干色块网格
  - **取色器**：饱和度 / 明度二维区 + 色相条（+ 透明度条）
  - **数值输入**：十六进制 / RGB / HSL 输入框
  - **透明度控制**：滑块 + 数值
  - **操作区**：清除按钮、确认 / 取消按钮（可配置）
- **空值态**：显示「无颜色」（棋盘格背景 或 空符号）

### 尺寸与外观变体
- 尺寸：小 / 中 / 大
- 形态：触发器 + 浮层 / 内联面板 / 内联色块组
- 内容深度：仅色板 / 色板 + 取色器 / 色板 + 取色器 + 数值输入
- 变体轴：是否含透明度、是否含清除、是否即时生效、预置色板（主题色 / 品牌色 / 自定义）

### 视觉状态（逐条）
| 状态 | 触发器 | 浮层 / 色板 |
|---|---|---|
| default | 显示当前色块 | 未出现 |
| hover | 色块边缘描边 | 色板项背景微亮 |
| focus-visible | 明显焦点环 | — |
| open | 边框高亮 | 浮层出现 |
| selected（当前色） | 色块 = 当前色 | 对应色板项高亮 / 描边 |
| keyboard-active | — | 色板项键盘高亮 |
| dragging | 色块实时跟随 | 取色器滑块处于拖动中 |
| transparent（含透明） | 棋盘格打底 | 透明度条可见 |
| empty（无颜色） | 显示空符号 / 棋盘格 | — |
| readonly | 外观正常、值可复制 | 不展开 |
| disabled | 整体降透明、不可聚焦 | 不展开 |
| error | — | 数值输入边框红 + 提示 |

### 布局与对齐
- 浮层尺寸固定（取色器需稳定尺寸），子区上下 或 左右排列
- 色块网格行列固定、间距一致
- 数值输入与色块对齐
- 靠近视口底部时**向上翻转**

### 移动端
- 浮层改**整宽 / 底部弹层**；取色器区域放大
- 触摸目标 ≥ 44×44；色块网格热区足够
- 拖动取色器与页面滚动冲突须处理（阻止滚动）

## 交互

### 触发与开合（核心操作）
- 打开：点触发器；关闭：`Esc`、点击外部、确认（若为确认式）
- **即时生效 vs 确认式须明确**：即时改动感强但易误触；确认式更稳但多一步
- 拖动取色器：实时更新预览色

### 输入行为
- 色板点击：选中该色
- 取色器拖动：连续改变色相 / 饱和 / 明度 / 透明度
- 数值输入：输入十六进制 / RGB / HSL，实时校验并同步色块
- **色值互转**：`hex ↔ rgb ↔ hsl` 须一致往返；透明度用 alpha，**单位（0–1 或 0–100%）须明确**
- 清除：清成**空值**，而非黑色
- 越界 / 非法字符被拒

### 键盘
| 按键 | 行为 |
|---|---|
| `Tab` | 在色板与各子区之间移动焦点 |
| `←` / `→` / `↑` / `↓` | 色板网格内移动高亮；取色器聚焦时微调色值 |
| `Shift + 方向键` | 大幅调整（可选） |
| `Enter` / `Space` | 选中当前高亮色 |
| `Esc` | 关闭，并按策略生效或回退 |
| `PageUp` / `PageDown` | 调整透明度（可选） |

### 指针与手势
- 点色块选中
- 拖动取色器（二维区 + 色相条 + 透明度条）
- 触摸端尺寸放大，防止误触与滚动干扰

### 焦点管理
- 关闭后焦点回到触发器
- 浮层内各子区可依次 Tab 到达
- 拖动取色器时仍可用键盘微调

### 动画与过渡
- 浮层淡入，约 100–200ms
- 色块聚焦 / 选中态过渡约 100ms
- 取色器拖动**无过渡**（要跟手）

### 反馈
- 当前色实时预览（触发器色块同步）
- 非法输入：边框红 + 提示
- 透明度：用棋盘格背景表示透明

### 边界交互
- 颜色格式不统一（大小写、`#` 可选、3 / 6 / 8 位十六进制）→ 统一规范化
- alpha 为 0 但 RGB 有值：视为「透明」还是「带 alpha」——**须明确**
- 超宽色板：换行 或 内部滚动
- 即时生效下连续拖动：是否防抖落库须明确

## 数据流

### 输入
- 配置：默认值、预置色板、尺寸、是否含透明度、是否含清除、是否即时生效
- 值来源：外部（受控）或内部

### 内部状态
- 浮层开合
- **正在编辑的色值**（确认式下可能区别于已提交值）
- 取色器内部的分量表示（色相 / 饱和 / 明度）与 alpha
- 数值输入中的原始串（可能非法）

### 输出
- **值变化事件**：颜色值——**形态必须明确**（十六进制字符串 / rgb 对象 / 是否含 alpha）
- 确认式下还需「确认 / 取消」事件
- 空值输出 `null`

### 受控 / 非受控
- 受控：外部持有色值，组件只抛新值；即时生效模式下每次拖动都抛，外部须自行防抖落库
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「选了不变」或「外部改了不刷新」

### 异步与竞态
- 一般无异步；若色板来自远程需处理加载 / 空 / 错误
- 即时生效 + 远程保存：防抖 + 竞态处理

### 校验与错误
- 校验色值格式合法性与分量范围（如 0–255、0–360）
- 组件只呈现错误；规则由外部给

### 回填与序列化
- 初值：任意格式 → 规范化到内部统一表示 → 渲染色块
- 序列化：统一输出格式（推荐带 alpha 的十六进制，如 `#RRGGBBAA`，或明确的对象）
- **往返一致**：解析 → 显示 → 提交三者格式须能无损往返

---

## 无障碍
- 触发器有可读名称与当前值（如「颜色选择，当前 #FF0000」）
- 浮层用适当角色；色板项有可读名称（色名或色值）
- 数值输入有关联标签；错误态标 `aria-invalid`
- 全键盘可达；取色器可键盘微调

---

## 常见误用
- 色值格式不统一 → 提交 / 回填来回转换丢精度
- 透明度单位（0–1 vs 0–100%）不明确
- 即时生效却无防抖 → 拖动时疯狂请求
- 把清除当黑色处理
- 只给色板、不给数值输入 → 用户想输品牌色值无从下手
- 只用颜色、不配文字或图标标识 → 色觉障碍用户难用

## 边界与代价
- `hex ↔ rgb ↔ hsl` 往返不无损 → 选一次颜色值就漂移
- 即时生效 + 无防抖 → 请求风暴且难撤销
- alpha 为 0 与「无颜色」混淆 → 语义歧义
- 大色板无换行 / 滚动 → 撑破浮层
- 纯色彩传达信息 → 无障碍与色觉障碍不友好
