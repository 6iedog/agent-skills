# 滑块

在一段数值区间上**拖动取值**，支持单值与双值范围。

## 角色与边界

- **是什么**：一条轨道加上可拖动的把手，用位置表示数值，可单值也可双值（范围）。
- **解决什么**：在已知上下限内做**相对、粗略**的取值，用户更关心「大概位置」而非精确数字。
- **不解决什么**：
  - 需要精确输入 → 数字输入（滑块可与之联动，但精确性由输入框保证）
  - 从固定少数选项中选 → 单选按钮组 / 分段控件
  - 没有明确上下限的取值 → 数字输入
  - 选日期 / 时间区间 → 日期 / 时间选择
- **什么时候不用**：范围极大且需精确到个位（如 0–10000）→ 数字输入，或「输入框 + 滑块」组合；取值本身没有「连续区间」语义（如「小 / 中 / 大」）→ 分段控件。

## UI

### 结构解剖
- **轨道**：承载取值的背景条
- **已选区间条**：单值时为起点到把手；双值时为两把手之间
- **把手**：可拖动的圆点 / 胶囊，单个或两个
- **刻度标记（tick）**：轨道上的分点
- **刻度文案**：各刻度对应的数值说明
- **当前值气泡**：拖动 / 悬停时显示的数值提示
- **输入框**：与滑块双向联动的数值输入（可选）
- **端点文案**：最小值 / 最大值标注
- **禁用遮罩**：整体禁用时的视觉层

### 尺寸与外观变体
- 值形态：**单值** / **双值范围**
- 方向：**水平** / **垂直**
- 是否显示刻度、刻度文案
- 是否显示当前值气泡
- 是否带输入框联动
- 是否分段（离散步长 vs 连续）
- 尺寸：小 / 中 / 大 → 影响轨道粗细、把手大小
- 状态类：默认 / 错误 / 禁用 / 只读

### 视觉状态（逐条）
| 状态 | 轨道 / 区间条 | 把手 |
|---|---|---|
| default | 轨道浅色，已选区间填充 | 常规圆点 |
| hover | 区间条微亮 | 把手放大 / 描边加深 |
| focus-visible | — | 明显焦点环（键盘聚焦时） |
| active / dragging | 区间条跟随 | 把手放大并高亮，气泡显示 |
| disabled | 整体降透明、禁用指针 | 不可拖动、不可聚焦 |
| readonly | 外观同 default，但不可拖动 | 可聚焦、可读 |
| error | 轨道变红 + 下方错误文案 | 描边变红 |
| at-min / at-max | — | 把手贴到端点时的边界视觉（可选） |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 把手位置 = `(值 - 最小) / (最大 - 最小)` 映射到轨道长度
- 双值把手**不得相交**；可设最小间隔，接近时间距钳制
- 垂直方向取值自下而上递增
- 刻度文案与刻度标记对齐；文案过长时交错或省略
- 带输入框时，输入框与滑块成对排列（水平常在滑块右侧，垂直在下方）

### 移动端
- 加大把手的**命中区**（本体可小，热区 ≥ 44×44）
- 拖动时显示气泡，避免手指遮挡
- 拖动需锁定方向，避免与页面滚动冲突（横向滑块拦截横向手势）

## 交互

### 核心操作
- 拖动把手 → 改值
- 点击轨道 → 单值直接跳到该位置；双值跳到较近的把手
- 与输入框联动：改输入框 → 把手移动；拖把手 → 输入框实时更新

### 输入与选择行为
- **单值**：一个数值
- **双值**：两个数值，恒有 `起 ≤ 止`；一端越过另一端时**钳制**或**交换**，二者须选一并保持一致
- **步长**：值吸附到步长网格（连续场景可设极小步长或关闭吸附）
- **刻度吸附**：可选，吸附到最近的刻度
- **输入框联动**：双向同步；输入越界 / 非数字时须定义钳制或拒绝

### 键盘
| 键 | 行为 |
|---|---|
| `Tab` | 聚焦把手（双值的两个把手**各自**是 Tab 停靠点） |
| `←` / `↓` | 按步长减小 |
| `→` / `↑` | 按步长增大 |
| `PageUp` / `PageDown` | 按大步长增减 |
| `Home` / `End` | 跳到最小 / 最大 |

- 单值与双值的 Tab 行为差异必须在文档中写清：双值有两个可聚焦把手。

### 指针与手势
- 按下把手拖动、松手结束
- 点击轨道跳值
- 触摸拖动需防页面滚动；拖动中即时反馈

### 焦点管理
- 焦点落在被操作的把手上；双值分别可聚焦
- 拖动过程中焦点保持在把手，松手后不丢焦点
- 整体禁用不可聚焦；只读可聚焦但不可改值

### 动画与过渡
- 把手 / 区间条的**非拖动**状态过渡短（约 100ms）
- **拖动中必须即时跟手**，不得有缓动滞后
- 气泡出现 / 消失淡入淡出

### 反馈
- 拖动时实时显示当前值（气泡 / 输入框）
- 触碰端点被钳制时给出视觉提示（而非静默卡住）
- 错误由外部传入，显示在滑块下方

### 边界交互
- **双值最小间隔**：两把手太近时禁止继续靠近
- **步长与范围不整除**：最大值需保证可达（端点不吸附丢失）
- **输入框填入越界值**：钳制到 min / max，并同步滑块
- **禁用**：通常整体禁用；若需禁用单侧，须专门设计，不支持则说明

## 数据流

### 输入
- **min / max**：上下限
- **step**：步长
- **值形态**：单值 / 双值
- **刻度**：`{ 值, 文案 }` 列表（可选）
- **方向**：水平 / 垂直
- **单位 / 格式化**：显示与气泡的格式化函数
- **默认值**
- 其他：尺寸、是否带输入框、是否显示气泡、状态（错误 / 禁用）

### 内部状态
- 当前值（或值对）
- 是否拖动中
- 气泡显隐
- 输入框草稿文本（输入未提交时）

### 输出
- **值变化事件**：需明确触发时机——**拖动中连续触发** 还是 **松手后触发一次**（或两者分开：`change` / `commit`）
- 输入框联动产生的事件
- **值形态必须明确**：单值 / 数组 `[起, 止]`

### 受控 / 非受控
- 受控：值由外部持有，组件只在事件里抛出新值
- 非受控：内部持有，给默认值
- **二选一必须明确**；受控 + 拖动中高频回抛时，外部若未及时回灌会造成把手回弹

### 异步与竞态
- 值提交到远程时处理加载 / 失败；失败须回滚或提示
- 拖动中高频触发不得每次都发请求——需节流或只在松手时提交

### 校验与错误
- 上下限、步长由组件钳制；业务校验（如「必须 ≥ 某值」）在表单层
- 错误由外部传入（错误标记 + 文案），组件负责呈现

### 回填与序列化
- 值 → 把手位置；越界初值须钳制到 min / max
- **双值顺序**：回填时保证 `起 ≤ 止`
- **浮点精度**：步长为小数（如 0.1）时须按精度取整，避免出现 `0.30000000004`
- 序列化为数字 / 数字数组

---

## 无障碍
- 把手：`slider` + `aria-valuemin`、`aria-valuemax`、`aria-valuenow`、`aria-valuetext`
- 双值：两个独立 `slider`；垂直方向用 `aria-orientation`
- 刻度文案不应被逐条读屏淹没（作为装饰或通过 `valuetext` 表达）
- 全键盘可达；`focus-visible` 可见（禁止无替代的 `outline: none`）
- 禁用标 `aria-disabled`；只读用 `aria-readonly`

---

## 常见误用
- 需要精确数值时只给滑块 → 应同时提供输入框
- 范围过大（如 0–10000）仍用滑块
- 步长 / 显示精度不一致 → 界面出现 `33.333`
- 双值未定义最小间隔 → 两把手重叠，无法操作
- 垂直滑块在移动端与页面滚动冲突
- 拖动中每次都发请求 → 性能与请求风暴

## 边界与代价
- 精确取值场景必须配输入框
- 双值语义（起止顺序、最小间隔）不定义 → 逻辑混乱
- 拖动中高频触发不节流 → 卡顿 / 请求风暴
- 浮点步长不处理 → 数值出现长尾误差
- 不区分「拖动中」与「松手后」事件 → 外部难以决定何时提交
