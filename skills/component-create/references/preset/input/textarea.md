# 多行文本域

可换行的多行纯文本录入，高度可固定、可自动增长。

## 角色与边界

- **是什么**：一个可换行的多行文本编辑区，支持自动高度与字数统计。
- **解决什么**：较长、可能多段的**纯文本**录入（描述、备注、地址、签名、反馈）。
- **不解决什么**：
  - 内容单行 → 输入框（更省空间）
  - 需要样式 / 图文混排 → 富文本编辑器
  - 需要在文本里 @ 引用 → 提及（其宿主常是本组件）
  - 结构化字段（日期、数字、选项）→ 对应专用控件
  - 长文本作为「一组值」累积 → 标签输入
- **什么时候不用**：内容就是一行（标题、名称）→ 输入框；内容高度结构化 → 拆成表单字段。

---

## UI

### 结构解剖
- **容器**：多行区域，含边框或底色
- **文本区**：可换行的可编辑内容 + 光标 + 占位符
- **缩放把手**：右下角可拖拽改变尺寸（可禁用）
- **计数**：设上限时显示「已输 / 上限」，常带剩余
- **帮助 / 错误文案**：容器下方一行

### 尺寸与外观变体
- 尺寸：小 / 中 / 大 → 影响字号、内边距、默认行数
- 高度模式：固定行数 / 自动增长（随内容）/ 自适应（在下限与上限之间）
- 外观：带边框 / 无边框 / 填充式 / 下划线式
- 变体轴：是否可手动缩放、是否显示计数、是否只读 / 禁用、错误 / 警告 / 成功

### 视觉状态（逐条）
| 状态 | 容器 | 文本区 |
|---|---|---|
| default | 边框默认 | 占位符浅色 |
| hover | 边框加深 | — |
| focus | 边框高亮 | 光标可见 |
| focus-visible | 明显焦点环 | — |
| composing（IME） | 同 focus | 光标带下划线，中间串未上屏 |
| auto-grow | 高度随内容增加 | — |
| resizing | — | 拖拽把手改变尺寸中 |
| readonly | 外观接近 default | 可聚焦、可复制、不可改 |
| disabled | 整体降透明 | 不可聚焦、禁用指针 |
| error | 边框红 + 下方文案 | — |
| warning | 边框黄 + 下方提示 | — |
| overflow（超限高） | 出现滚动条 | 内部滚动 |
| full（达上限） | — | 输入被拦，计数变色 |

- **disabled 与 readonly 必须分开**：disabled 不可聚焦、不进表单值；readonly 可聚焦、可复制、值照常提交。

### 布局与对齐
- 文本左对齐、**顶部对齐**
- 自动增长：随内容增高；到达最大高度后改为**内部滚动**
- 手动缩放须设定可缩放方向（仅垂直 / 自由）与上下限
- 长单词 / 长链接需允许断行，避免水平溢出

### 移动端
- 触摸目标 ≥ 44×44；键盘弹出时滚动保持光标可见
- 触摸端建议**禁用或忽略缩放手把**（拖动与页面滚动冲突）
- 自动增长在移动端更实用

## 交互

### 触发与输入行为
- 聚焦 → 输入 → `Enter` 插入换行（表单内**默认不提交**）
- 提交快捷键：常见 `Ctrl/Cmd + Enter`（须明确开启与否）
- 清空：可选清空按钮
- 缩放：拖右下角把手改变尺寸（受上下限夹取）

### 输入行为
- **IME 组合态**：未上屏的中间串不得当作值
- `Enter` 换行 vs `Tab`：默认 `Tab` 移出焦点；若要插入制表符须显式开启
- 粘贴：多行正常；超上限按策略截断或拒绝
- 自动增长时每次输入触发高度重算，须避免逐字抖动

### 键盘
| 按键 | 行为 |
|---|---|
| `Enter` | 插入换行（默认不提交表单） |
| `Ctrl/Cmd + Enter` | 提交（若配置开启） |
| `Tab` | 默认移出焦点；开启后插入缩进 |
| `Esc` | 还原 / 清空（可配置） |
| `Ctrl/Cmd + A` | 全选 |
| `Backspace` / `Delete` | 删除字符 |

### 指针与手势
- 拖右下角把手缩放
- 拖动选择、双击选词
- 触摸端长按选字、拖动定位光标

### 焦点管理
- 焦点环可见；程序聚焦时光标置于末尾
- 自动增长与缩放**不抢焦点**

### 动画与过渡
- 自动增长的高度变化平滑（建议按行高步进，避免逐字抖动）
- 状态色过渡约 100–150ms
- 缩放拖动时实时跟随，无过渡

### 反馈
- 计数：接近上限变色；达上限输入被拦并标红
- 错误 / 警告文案在下方呈现
- 内容超高时显示滚动条

### 边界交互
- 超长内容：达最大高度后内部滚动，滚动定位到光标
- 上限策略须明确：**禁止超出** 还是 **允许但报错**
- 粘贴巨量文本可能卡顿，须限长或分批处理

## 数据流

### 输入
- 配置：值 / 默认值、占位符、行数 / 高度模式、最小与最大高度、最大长度、是否可缩放、是否计数、状态
- 来源：外部传入

### 内部状态
- 当前文本（非受控时）
- 焦点态、IME 组合态
- 滚动位置
- 当前高度（自动增长时）

### 输出
- **值变化事件**：新字符串
- 提交事件（`Ctrl/Cmd + Enter`）、聚焦 / 失焦事件
- **值形态**：字符串（含换行符）；换行符统一为 LF 还是 CRLF 须明确

### 受控 / 非受控
- 受控：值由外部持有，组件只抛新值；外部不回写则显示不变
- 非受控：内部持有，给默认值
- **二选一必须明确**；混用会出现「打字消失」或「外部改了不刷新」

### 异步与竞态
- 自动增长的高度重算须在布局后执行，避免与受控回写形成循环
- 若做自动保存：输入防抖 + 按请求标识丢弃过期结果

### 校验与错误
- 组件只呈现错误；规则由表单层或内联传入
- 长度校验必须与计数显示**一致**
- 校验时机：输入中 / 失焦 / 提交——须明确

### 回填与序列化
- 初值 → 直接渲染；`null` / `未定义` 显示占位符
- 序列化：原样字符串（含换行），可选去除首尾空白
- 换行符在展示与提交之间须保持一致

---

## 无障碍
- 关联可见标签；无可见标签时提供可读名称
- 帮助 / 错误文案与其关联；错误态标 `aria-invalid`
- 只读 / 禁用语义分开
- 计数变化若播报须用 `aria-live`，且**仅在临界值播报**，避免逐字打扰
- 全键盘可达；焦点可见（禁止无替代的 `outline: none`）

---

## 常见误用
- 单行内容也上文本域 → 浪费空间
- 自动增长不设最大高度 → 长文本撑满页面
- `Enter` 被设为提交却仍要求多行输入 → 语义冲突
- 计数上限与校验上限不一致
- 触摸端保留缩放手把 → 与页面滚动冲突
- 只用占位符当标签 → 可访问性差

## 边界与代价
- 自动增长无上限 → 长文本撑爆布局
- 手动缩放不设上下限 → 缩到看不见或撑破容器
- 巨量粘贴无限制 → 输入卡顿甚至卡死
- 换行符不统一 → 提交与展示不一致
- 无可见标签只靠占位符 → 输入后提示消失、可访问性差
