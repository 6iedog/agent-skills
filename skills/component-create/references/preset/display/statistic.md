# 统计数值

突出展示**一个数值**及其前后缀、精度，表达指标当前值或倒计时。

## 角色与边界

- **是什么**：一个强调显示的数字，可带前缀 / 后缀 / 单位 / 精度 / 分组，或作为倒计时。
- **解决什么**：在一个区域里把某个关键指标醒目地呈现出来。
- **不解决什么**：
  - 不解决「随时间变化趋势」 → 迷你图 / 折线图
  - 不解决「占比进度」 → 进度条
  - 不解决「一屏多指标大屏」 → 数据看板（可组合本组件）
  - 不解决「仪表盘刻度」 → 仪表盘图
- **什么时候不用**：指标需要趋势 / 对比 → 图表；只是普通文本里的数字 → 直接文本。

---

## UI

### 结构解剖
- **前缀**：单位 / 货币符号 / 图标
- **数值**：主体数字，支持精度、千分位、小数
- **后缀**：单位 / 百分比符号 / 说明
- **标题**：可选，说明该数值含义
- **说明区**：可选，补充变化幅度 / 时间
- **倒计时**：数值区域持续递减显示

### 尺寸与外观变体
| 轴 | 取值 | 影响 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 数值字号 |
| 数值格式 | 整数 / 定点小数 / 千分位 / 百分比 / 货币 | 展示 |
| 前缀后缀 | 无 / 文本 / 图标 / 单位 | 表达 |
| 标题 | 无 / 有 | 含义 |
| 精度 | 0–N 位小数 | 精确度 |
| 计时 | 普通数值 / 倒计时 | 行为 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 数值正立显示 |
| loading | 数值位置显示占位块 / 微光 |
| error | 取数失败显示占位或错误标记 |
| countup（可选） | 数值从 0 或旧值滚动到目标值 |
| counting（倒计时进行中） | 数值持续递减 |
| finished（倒计时结束） | 到 0 后停止，可选触发回调 |
| disabled | 灰化（少见） |

### 布局与对齐
- 标题在上或下，数值居中或左对齐需统一
- 前缀 / 数值 / 后缀同一基线对齐
- 数值过长时避免换行折断；可缩字号或截断
- 一组统计中，多个数值的基线 / 高度对齐

### 移动端
- 字号随容器缩放，避免溢出
- 一组统计在窄屏纵排或两列
- 触摸无需特殊处理（多为展示）
- 倒计时数字等宽，避免宽度跳动

---

## 交互

### 触发与核心操作（数值刷新 / 倒计时）
- 数值随数据更新而刷新
- 倒计时：设置目标时间后自动递减，到 0 停止
- 可选：数值变化时以滚动动画过渡

### 数值更新行为
- 更新时保留位数一致，避免宽度跳动
- 倒计时格式（时 / 分 / 秒 或 天 / 时 / 分 / 秒）需明确

### 键盘
| 键位 | 行为 |
|---|---|
| — | 纯展示，一般无键盘交互 |
| `Tab` | 若含链接 / 操作则可达 |

### 指针与手势
- 一般为纯展示；含说明链接时可点

### 焦点管理
- 无自动焦点；含交互元素时纳入焦点顺序

### 动画与过渡
- 数值滚动（countup）约 300–800ms，遵循「减少动态」偏好时降级为直接显示
- 倒计时逐秒或逐帧更新，数字等宽避免抖动
- 刷新时避免整块跳动

### 反馈
- 加载态明确
- 倒计时结束可选回调 / 提示

### 边界交互
- 数值超长 / 超大 / 无穷 → 需截断或缩写（如 1.2 万 / 1.2K），规则明确
- 负值、零值显示统一
- 倒计时目标时间早于当前 → 直接显示 0
- 精度与千分位同时设置时不能冲突

---

## 数据流

### 输入
- **数值**（倒计时时为**目标时间**）
- 精度、千分位开关、前缀 / 后缀
- 标题、说明文字
- 尺寸、加载态

### 内部状态
- 倒计时剩余时间（内部定时）
- 数值滚动动画的当前中间值
- 加载状态

### 输出
- **倒计时结束事件**
- 数值滚动结束事件（可选）
- 一般无值变化输出

### 受控 / 非受控
- 展示值受控（外部传入）
- 倒计时可由外部给目标时间、内部自走，或完全受控（外部驱动更新）

### 异步与竞态
- 数值异步取数：先加载占位后填值
- 快速刷新数值时，动画应从当前中间值过渡而非重头开始
- 倒计时重复启动需清理旧定时器

### 校验与错误
- 数值非数字 / 缺失 → 占位或错误态，不能显示 NaN
- 取数失败可重试

### 回填与序列化
- 展示值由外部提供，无序列化职责
- 倒计时目标时间应可从状态回填

---

## 无障碍
- 数值提供可读文本（读屏读出的应是格式化后的值，而非动画中间态）
- 倒计时可用 `aria-live` 礼貌播报关键节点，避免逐秒打断
- 说明 / 标题与数值建立关联，使含义可读
- 加载态对读屏标注
- 含交互元素时键盘可达、`focus-visible` 可见

## 常见误用
- 用统计数值表达趋势却不给任何对比 → 无法判断好坏
- 倒计时逐秒打断读屏 → 应控制播报频率
- 精度不一致导致同一组数值宽度抖动
- 超大数不缩写 → 撑破容器
- 数值与标题无关联，读屏只读出数字不知含义

## 边界与代价
- 数值格式（精度 / 千分位 / 缩写）**必须**统一，否则一组指标参差
- 倒计时：**必须**管理定时器生命周期（清理 / 重启），否则泄漏或重影
- 动画（滚动 / 倒计时）**必须**遵循「减少动态」偏好降级
- 数值缺失显示 NaN：**必须**拦截
- 超长数值无缩写：容器溢出
