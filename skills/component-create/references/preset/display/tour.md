# 漫游式引导

用**分步高亮**引导用户认识界面的浮层，逐步聚焦关键元素并给出说明。

## 角色与边界

- **是什么**：一串按顺序推进的引导步骤，每步高亮目标元素、显示说明面板，含上一步 / 下一步 / 跳过。
- **解决什么**：帮助新用户理解复杂界面或新功能，按顺序介绍关键控件。
- **不解决什么**：
  - 不解决「单点说明」 → 文字提示
  - 不解决「一次性提示条」 → 警告 / 通知
  - 不解决「流程填写」 → 步骤条 / 表单
  - 不解决「帮助文档」 → 帮助中心
- **什么时候不用**：步骤过多（> 约 5–7）或界面常变 → 用帮助文档 / 短视频；只是提示一处 → 文字提示。

---

## UI

### 结构解剖
- **遮罩层**：覆盖全屏、降低背景关注度
- **挖空区**：在遮罩上镂空露出目标元素
- **高亮框**（可选）：围绕目标元素的描边
- **说明面板**：标题 + 正文 + 步骤计数 + 控件
- **控件**：上一步 / 下一步 / 完成 / 跳过
- **进度指示**：第几步 / 共几步（点或计数）

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 遮罩 | 纯色遮罩 / 透明可点 / 半透明可点 | 决定遮罩能否穿透点击 |
| 挖空 | 矩形 / 圆形 / 跟随元素形状 | |
| 面板位置 | 目标四向自动避让 / 固定 | 空间不足时翻转 |
| 高亮框 | 有描边 / 无 | |
| 步骤计数 | 点 / 文字 / 无 | |
| 交互 | 必须逐步 / 可跳过 / 可任意跳 | |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 当前步高亮 + 面板显示 |
| transitioning | 步骤切换过渡中 |
| first-step | 无上一步 |
| last-step | 下一步变为完成 |
| skipped | 引导结束 |
| target-missing | 目标元素不存在时的降级 |
| focus-visible | 面板内控件焦点环 |

### 布局与对齐
- 挖空区与目标元素位置、尺寸一致；元素移动 / 滚动时需跟随。
- 面板自动避让视口边缘，优先放在目标旁且有空间的一侧。
- 步骤计数与控件对齐，控件靠右或均分。

### 移动端
- 面板在小屏改为自适应宽度，必要时贴底。
- 挖空区目标元素在视口外时先滚动到可见再高亮。
- 触摸目标 ≥ 44×44。

## 交互

### 触发与核心操作
- 打开：由外部触发（首次进入 / 点击「引导」按钮）。
- 上一步 / 下一步：顺序推进。
- 跳过：结束引导。
- 完成：最后一步结束。

### 选中或输入行为
- 无输入；当前步由索引标识。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 引导浮层 | `Esc` | 跳过 / 关闭 |
| 引导浮层 | `←` / `→` | 上一步 / 下一步 |
| 引导浮层 | `Tab` | 在面板控件间移动 |
| 引导浮层 | `Enter` / `Space` | 触发聚焦控件 |

### 指针与手势
- 点「下一步」推进；遮罩是否穿透点击由配置决定（通常不穿透，避免误操作）。
- 触摸端滑动切换（可选）。

### 焦点管理
- 打开引导后焦点移入面板。
- 引导是**模态式**：焦点困在面板内，不落到被遮罩的界面。
- 结束后焦点回到触发点或页面初始焦点。

### 动画与过渡
- 步骤切换时高亮区与面板做位移 + 淡入，约 200–300ms。
- 遮罩淡入淡出；不引起页面布局变化。

### 反馈
- 步骤计数即时更新即反馈。
- 目标元素不存在时降级（略过该步或中心显示），不能卡死。

### 边界交互
- 目标元素在滚动容器内：先滚动到可见再定位。
- 目标元素动态变化（尺寸改变）：重新测量位置。
- 中途目标被移除：跳过或结束。
- 窗口 resize：重算挖空与面板位置。

## 数据流

### 输入
- **步骤列表**：`{ 目标选择符 / 元素引用, 标题, 正文, 面板位置偏好 }`
- 当前步（受控时）
- 文案：跳过 / 上一步 / 下一步 / 完成
- 是否可跳过、遮罩点击是否穿透

### 内部状态
- 当前步（非受控时）
- 各步目标元素的位置与尺寸（测量结果）
- 过渡相位

### 输出
- 步骤变化事件（当前步索引）
- 跳过 / 完成事件（供外部持久化「已看过」）
- 目标定位失败事件

### 受控 / 非受控
- 当前步可受控（外部驱动）或非受控（内部维护），须明确。
- 是否打开通常受控，由外部决定何时展示。

### 异步与竞态
- 目标元素可能异步渲染：需等待其出现再定位，否则挖空落空。
- 滚动 / resize 触发的重测量要防抖，避免抖动。

### 校验与错误
- 步骤目标选择符无效 → 降级处理，不报错崩溃。
- 步骤列表为空 → 不打开引导。

### 回填与序列化
- 「已看过」状态按引导标识持久化，避免重复打扰。
- 步骤顺序与文案来自数据；更新步骤集后已看标识需兼容。

---

## 无障碍
- 引导是模态层：焦点困于面板，`Esc` 可关闭，关闭后归位。
- 每步说明可被屏幕阅读器读取，并与高亮目标关联说明。
- 控件按按钮语义，全键盘可达，焦点环可见。
- 提供跳过且易发现，不能强制走完。
- 尊重「减少动态效果」偏好，关闭过渡动画。

---

## 常见误用
- 步骤过多、每步都要走完且难以跳过 → 用户烦躁。
- 遮罩可穿透点击 → 误操作底层界面。
- 目标元素在视口外不滚动 → 高亮落空。
- 目标异步未渲染就定位 → 挖空错位。
- 每次进入都重复弹 → 无「已看过」记录。
- 焦点未困在面板 → 键盘用户跑到被遮罩界面。
- resize / 滚动不重算 → 高亮错位。

## 边界与代价
- 步骤过多 → 应改用文档 / 视频。
- 无跳过 / 无「已看过」记录 → 重复打扰。
- 焦点不困 → 模态失效。
- 目标定位不重算 → 错位。
- 不尊重减少动态 → 不友好。
