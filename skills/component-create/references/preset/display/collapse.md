# 折叠面板

把多组内容**折叠收进可点标题**，同一空间内按需展开，省纵向空间。

## 角色与边界

- **是什么**：一组可展开 / 收起的标题面板，标题常显、内容按需显形。
- **解决什么**：多组内容共享有限空间，用户按需查看其中一组或几组。
- **不解决什么**：
  - 不解决「互斥切换视图 / 步骤」 → 标签页 / 分段控件
  - 不解决「层级导航」 → 树 / 菜单
  - 不解决「弹层承载内容」 → 抽屉 / 模态
  - 不解决「大量数据分块」 → 分页
- **什么时候不用**：分组互斥、一次只看一个 → 标签页；本身就是页面级导航 → 菜单；内容需纵向长阅读 → 直接展开或用目录锚点。

## UI

### 结构解剖
- **面板组容器**
- **单个面板**：标题头 + 可折叠内容区
- **标题头**：展开图标 + 标题 + 可选副标题 / 说明 / 右上操作
- **展开图标**：位于标题前或后（需统一）
- **内容区**：任意内容，可懒加载
- **禁用面板**：标题降透明、不可展开

### 尺寸与外观变体
| 轴 | 取值 | 影响 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 标题高度、字号、内边距 |
| 外观 | 有边框 / 无边框 / 浅色背景标题 | 视觉 |
| 图标位置 | 标题左 / 标题右 | 阅读顺序 |
| 模式 | 手风琴（仅一项展开）/ 多开 | 交互 |
| 默认展开 | 全部收起 / 展开第一项 / 指定项 | 初值 |
| 折叠动画 | 有 / 无 | 性能与观感 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| collapsed | 仅标题可见，图标指向收起方向 |
| expanded | 内容区显形，图标翻转 |
| hover | 标题头背景微亮 |
| focus-visible | 标题头显焦点环 |
| active（按下） | 标题头按下加深 |
| disabled | 标题降透明、不可展开、不可聚焦或明确标注禁用 |
| loading（懒加载中） | 内容区显示加载态 |

### 布局与对齐
- 标题头高度一致；图标与标题基线对齐
- 内容区内缩进与标题对齐，形成层级
- 多面板之间视觉分隔一致
- 长标题截断 + 悬停显示完整

### 移动端
- 图标与标题位置适配拇指，整行标题可点（触摸目标 ≥ 44 高）
- 内容区缩进减小以留出阅读宽度
- 手风琴模式在窄屏更省空间
- 触摸目标整行可点，不能只图标可点

## 交互

### 触发与开合（核心操作）
- 点击标题头 → 切换展开 / 收起
- 手风琴模式：展开一项时自动收起其他项
- 多开模式：各项独立开合
- 默认展开项按配置初始化

### 展开项选择行为
- 受控展开项集由外部持有；点击只抛「请求展开 / 收起哪一项」
- 禁用项点击无响应
- 展开状态变化需即时反映

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在标题头之间移动焦点 |
| `Enter` / `Space` | 展开 / 收起聚焦面板 |
| `↑` / `↓` | 可选：标题头间移动焦点 |
| `Home` / `End` | 可选：跳首 / 末面板 |

### 指针与手势
- 点击标题头
- 悬停标题头有反馈
- 禁用项不响应

### 焦点管理
- 展开 / 收起后焦点停留在标题头
- 懒加载完成后焦点不跳走
- 禁用标题头不可聚焦或明确标注禁用

### 动画与过渡
- 展开 / 收起高度过渡约 150–300ms
- 图标旋转
- 遵循「减少动态」偏好时降级为即时切换
- 懒加载时避免展开瞬间空白抖动，先占位

### 反馈
- 展开 / 收起即时，无需额外提示
- 懒加载中给出加载态
- 禁用项视觉明确

### 边界交互
- 手风琴 vs 多开：语义必须明确并一致
- 懒加载内容失败：可重试，不静默空白
- 深层嵌套折叠：限制层级，避免层层缩进难用
- 受控展开项：外部传入不存在的项需容错

## 数据流

### 输入
- **面板定义**：`{ 标识, 标题, 内容, 是否禁用?, 图标位置? }`
- 模式：手风琴 / 多开
- 默认展开项
- 是否懒加载

### 内部状态
- 当前展开项集（非受控时）
- 各项懒加载状态与内容缓存
- 悬停 / 聚焦

### 输出
- **展开 / 收起事件**：变化的面板标识 + 新状态
- 内容懒加载请求（首次展开时触发）

### 受控 / 非受控
- 展开项可受控（外部持有当前展开集）或非受控（给默认项）
- **二选一必须明确**
- 手风琴模式下受控集应始终至多一项

### 异步与竞态
- 懒加载：首次展开触发请求，缓存已加载内容避免重复请求
- 快速连续展开多个面板：各请求独立，不互相覆盖
- 请求失败需可重试

### 校验与错误
- 组件不做业务校验
- 懒加载失败渲染错误态而非空白
- 受控展开项越界时容错

### 回填与序列化
- 展开项可写入 URL / 状态（如哪几项展开），刷新后恢复
- 回填时过滤不存在的面板标识

---

## 无障碍
- 标题头用可聚焦的按钮语义，标注展开 / 收起状态与关联内容
- 内容区与标题头建立关联，读屏可跳到对应内容
- 禁用项标注为不可用
- 图标为装饰性时对读屏隐藏
- 全键盘可达；`focus-visible` 可见
- 展开状态变化可被读屏感知

## 常见误用
- 互斥分组却用手风琴替代标签页 → 语义模糊
- 只为省空间折叠却把关键信息藏起来 → 用户找不到
- 手风琴与多开混用在同一组 → 行为不可预期
- 图标位置逐面板变化 → 阅读错乱
- 懒加载无缓存 → 每次展开都重新请求

## 边界与代价
- 层级过深（≥ 3 层折叠）：**必须**收敛，否则缩进吞掉阅读宽度
- 懒加载：**必须**有加载 / 错误 / 缓存三态，否则展开体验断裂
- 手风琴模式：受控集**必须**至多一项，否则状态矛盾
- 只让图标可点：与触摸大点击区要求不符，**必须**整行可点
- 折叠动画进行中快速连点：需防抖，避免高度计算错乱
