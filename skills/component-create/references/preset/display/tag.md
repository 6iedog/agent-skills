# 标签

用**小块文字**对内容做分类、属性标注或状态标识的紧凑元素。

## 角色与边界

- **是什么**：一段带底色 / 边框的短文字块，可只读展示，也可作为「可关闭 / 可勾选 / 可点击」的内联控件。
- **解决什么**：在一行内并列展示多个分类、属性、状态或筛选条件。
- **不解决什么**：
  - 不解决「可自造新值的多值输入」 → 标签输入
  - 不解决「选项多、需收起的多选」 → 多选下拉
  - 不解决「极简状态点」 → 徽标
  - 不解决「整块可点的独立操作」 → 按钮
  - 不解决「一段说明文字」 → 文字提示 / 就地说明
- **什么时候不用**：只是给文字做强调 → 用文本样式；标签数量可能几十个 → 用列表或折叠成「+N」。

---

## UI

### 结构解剖
- **标签本体**：文字 + 内边距 + 圆角背景
- **前缀**（可选）：色点 / 图标
- **关闭按钮**（可关闭时）：右端小图标
- **勾选标记**（可勾选时）：选中态的对勾或选中背景
- **溢出收纳项**：固定宽度时的「+N」占位

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 影响高度、内边距、字号 |
| 颜色 | 默认 / 语义色（成功、警告、错误、信息） / 自定义 | 语义色承载状态 |
| 边框 | 有边框 / 无边框（柔和底色） | 无边框更轻，弱化存在感 |
| 交互性 | 只读展示 / 可关闭 / 可勾选 / 可点击 | 决定是否有交互态 |
| 圆角 | 直角 / 小圆角 / 胶囊 | 同一界面应统一 |
| 内容 | 纯文字 / 前缀色点+文字 / 图标+文字 | |

- **只读标签与可交互标签必须区分**：只读无 hover / 焦点态，可交互才有。

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态底色 + 文字色 |
| hover（可交互 / 可关闭） | 底色加深或关闭图标显形 |
| active | 进一步加深 |
| focus-visible | 明显焦点环 |
| checked（可勾选） | 反色底或加对勾，与未选形成对比 |
| disabled | 降透明、不可点 |
| closable | 关闭图标常 hover 才出现，触摸端常驻 |
| readonly | 外观同 default，无任何交互态 |

### 布局与对齐
- 标签间水平间距统一；换行时行间距统一。
- 标签高度一致，文字垂直居中。
- 标签组末尾可挂「+N」收纳，点击展开。
- 同一组内标签不混用多种圆角 / 尺寸。

### 移动端
- 关闭按钮在触摸端应常驻可见，不依赖 hover。
- 可关闭标签的关闭命中区 ≥ 44×44（可外扩透明区），避免误触文字。
- 标签组横向溢出时换行，不产生横向滚动条。

## 交互

### 触发与核心操作
- 可关闭：点关闭图标移除该标签。
- 可勾选：点标签切换选中 / 未选。
- 可点击：点标签触发筛选 / 跳转等动作。
- 只读：无操作。

### 选中或输入行为
- 勾选型：点整块或点勾选标记即切换。
- 关闭型：点关闭移除；关闭后是否可撤销由上层决定（常配撤销提示）。
- 同一时刻只能有一种交互语义，不叠加。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 可交互标签 | `Tab` / `Shift+Tab` | 聚焦 / 移出 |
| 可勾选标签 | `Enter` / `Space` | 切换选中 |
| 可关闭标签 | `Delete` / `Backspace` | 移除（聚焦在标签时） |
| 组内导航 | 方向键 | 可选：单行组内移动（roving tabindex） |

### 指针与手势
- 悬停显示可交互线索（底色变化 / 关闭图标显形）。
- 触摸端点按即触发，关闭图标常驻。

### 焦点管理
- 关闭后焦点应移到**同组相邻标签**或容器下一个可聚焦元素，不得丢到 body。
- 组内标签各自可聚焦，或采用单一可聚焦点 + 方向键（须一致）。

### 动画与过渡
- 新增 / 移除用短过渡（约 100–200ms）淡入淡出或高度收起。
- 勾选态切换短暂过渡，不抖动布局。

### 反馈
- 勾选 / 关闭即时在视觉上体现，即反馈。
- 关闭可撤销时给撤销入口；不可撤销且重要时先确认。

### 边界交互
- 超长文字：单行省略（末尾省略号），悬停显示完整。
- 标签过宽：限制最大宽度，防止单个标签撑满一行。
- 大量标签：折叠成「+N」，点击展开。
- 快速连续关闭：避免动画叠错位。

## 数据流

### 输入
- **标签数据**：`{ 文本, 值?, 语义色?, 是否可关闭?, 是否选中? }`
- 配置：尺寸、圆角、是否无边框、是否可勾选、最大展示数量（溢出收纳）
- 只读 / 可交互模式

### 内部状态
- 若可关闭：关闭动画的过渡相位。
- 若溢出收纳：展开 / 收起。
- 可勾选时选中态**通常受控**（外部持有），组件不自行存储。

### 输出
- 关闭事件：被关闭标签的值
- 勾选 / 取消事件：新选中集合
- 点击事件（可点击型）：标签值
- 溢出「+N」展开事件（若有）

### 受控 / 非受控
- 可勾选标签的选中集合一般**受控**，由外部维护。
- 关闭后的列表归外部维护，组件只抛事件。

### 异步与竞态
- 关闭若触发远端删除，需处理失败回滚，避免标签已消失但数据未删。
- 快速连续勾选 / 关闭要按标识去重，防止重复请求。

### 校验与错误
- 标签不承担校验；超长 / 非法内容由上游裁剪。
- 语义色非法要有兜底（回落到默认色）。

### 回填与序列化
- 选中集合按值（id）比较，不按引用。
- 只读标签由数据映射生成，更新时整体刷新。
- 序列化时值形态须明确（字符串 / 对象）。

## 无障碍
- 可关闭：关闭图标有可访问名称（如「移除 标签名」），不读作「按钮」。
- 可勾选：用勾选 / 切换语义，含选中态，名称含当前是否选中。
- 可点击：按按钮语义，名称描述动作。
- 只读标签是纯文本，不被读作可操作。
- 全键盘可达；焦点环可见。

---

## 常见误用
- 只读标签做成看似可点 → 用户误点无反应。
- 关闭按钮命中区过小 → 误触标签文字。
- 关闭不可撤销且无提示 → 数据焦虑。
- 标签颜色含义不统一 → 语义混乱。
- 超长标签不做省略 → 撑破布局。
- 标签组用横向滚动替代换行 → 触摸端难发现。
- 把可交互标签与只读标签混排且样式无区分。

## 边界与代价
- 大量标签不收纳 → 视觉与布局失控。
- 关闭无撤销 / 无确认且为重要数据 → 误删风险。
- 单一标签不限宽 → 撑满行。
- 颜色是唯一状态载体 → 无障碍缺失。
- 触摸端关闭图标依赖 hover → 不可用。
