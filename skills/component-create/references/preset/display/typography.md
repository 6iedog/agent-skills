# 排版（文本）

在界面中呈现**文字内容**的基础元素，覆盖标题层级、省略、链接、可复制 / 可编辑。

## 角色与边界

- **是什么**：一段文本的展示载体，按语义层级区分标题与正文，可单行 / 多行省略、可复制、可编辑、可含链接。
- **解决什么**：在任意位置以一致的字号、字重、行高与颜色呈现文字，并处理溢出与交互。
- **不解决什么**：
  - 不解决「输入」 → 输入框 / 多行文本框（文本是展示，输入框是表单控件）
  - 不解决「带结构的富文本编辑」 → 富文本编辑器
  - 不解决「长文档排版」 → 文档 / 阅读视图
  - 不解决「强调徽标」 → 徽标 / 标签
- **什么时候不用**：只是结构容器的间距问题 → 布局组件；纯装饰性大标题图 → 图片。

---

## UI

### 结构解剖
- **文本容器**：承载一行 / 多行文字的盒子
- **层级样式**：标题（多级）/ 正文 / 次要文字 / 辅助说明
- **截断层**：单行 / 多行的溢出省略
- **可复制 / 可编辑装饰**：悬浮出现的复制 / 编辑入口
- **链接片段**：文本内嵌入的可点链接
- **工具提示**：被截断时悬停显示完整内容（可选）

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 层级 | 一级标题 / 二级 / … / 正文 / 次要 / 辅助 | 字号字重成体系 |
| 截断 | 不截断 / 单行省略 / 多行省略（限行数） | |
| 可复制 | 否 / 悬停复制按钮 / 点击即复制 | |
| 可编辑 | 否 / 就地编辑 | |
| 链接 | 无 / 内嵌链接 | 链接须可辨 |
| 对齐 | 左 / 中 / 右 / 两端 | |
| 语义标签 | 标题 / 段落 / 强调 / 次要 / 引用 | 影响可访问性与默认样式 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 按层级的字号 / 字重 / 颜色 |
| hover（可复制 / 可编辑） | 显示复制 / 编辑入口 |
| editing | 变为可编辑区域，含边框或底纹 |
| focus-visible | 编辑态或链接的焦点环 |
| truncated | 末尾省略号，可选悬停显示完整 |
| disabled | 降透明 |
| loading | 骨架替代（数据未到时） |
| empty | 空值时的占位符（如「—」） |
| link | 链接色 + 下划线或悬停下划线 |

### 布局与对齐
- 行高与字号成比例（正文行高约字号的 1.5 倍），多行可读。
- 标题与正文之间的间距统一，避免过大或过挤。
- 截断容器需要**明确宽度约束**，否则省略不生效。
- 文本与图标并排时按基线 / 视觉中心对齐。

### 移动端
- 字号不可过小（正文不宜小于约 14），行高与触摸阅读舒适。
- 可复制 / 可编辑入口在触摸端常驻或长按触发，不依赖 hover。
- 无空格长文本（长链接）需强制换行或截断，防撑破布局。

## 交互

### 触发与核心操作
- 复制：点复制入口 / 长按选择复制。
- 编辑：点编辑入口进入就地编辑，提交或取消。
- 链接：点击跳转。

### 选中或输入行为
- 纯展示文本可选词复制。
- 可编辑态：点击进入编辑，回车提交（单行）/ 失焦提交（可配置）。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 纯展示文本 | — | 不进入键盘序列（除非在可聚焦容器内） |
| 可复制 | `Tab` | 聚焦复制入口 |
| 可复制 | `Enter` / `Space` | 触发复制 |
| 链接 | `Tab` | 聚焦链接 |
| 链接 | `Enter` | 跳转 |
| 可编辑 | `Enter` | 提交（单行） |
| 可编辑 | `Esc` | 取消编辑，恢复原值 |

### 指针与手势
- 悬停显示复制 / 编辑入口。
- 双击可进入编辑（可配置）。
- 触摸端长按进入选择 / 编辑。

### 焦点管理
- 进入编辑后焦点落在编辑区并全选或定位光标。
- 提交 / 取消后焦点回到文本容器或下一元素。
- 链接焦点可见。

### 动画与过渡
- 复制成功做短反馈（如按钮态变化或轻提示）。
- 编辑态与展示态切换轻微过渡，不抖动布局。

### 反馈
- 复制成功给出明确反馈（按钮变「已复制」或轻提示），失败也要提示。
- 编辑校验失败给错误提示并保留输入。

### 边界交互
- 超长文本：按配置单行 / 多行省略；被截断时提供查看完整的途径。
- 空值：显示占位（如「—」或「无」），不留空白坑。
- 文本含链接：链接不可被截断吃掉，需保证可点。
- 快速连续复制：去重，避免重复提示。

## 数据流

### 输入
- **文本内容**（字符串，可含链接节点）
- 层级 / 语义标签
- 截断方式与行数
- 是否可复制 / 可编辑、编辑校验规则
- 空值占位文案

### 内部状态
- 是否处于编辑态、编辑中的草稿值
- 是否被截断（测量结果）
- 复制反馈的临时态

### 输出
- 复制事件（复制内容）
- 编辑提交事件：新值
- 编辑取消事件
- 链接点击事件（或直接跳转）

### 受控 / 非受控
- 内容受控（外部给出）。
- 编辑态的值：提交由外部落库，组件内部仅在编辑期间持有草稿。

### 异步与竞态
- 内容异步加载时先用骨架占位。
- 编辑提交若异步保存，需处理保存中 / 失败；失败回滚草稿并提示。
- 快速多次提交按最新值，丢弃过期保存结果。

### 校验与错误
- 可编辑时校验规则由外部传入（如非空、最大长度）。
- 校验失败呈现错误，不提交。
- 只读文本不承担校验。

### 回填与序列化
- 内容直接来自数据字段；回填即绑定。
- 若含链接，链接与文本需分别序列化或以结构化格式存储。

---

## 无障碍
- 使用**语义标签**：标题用标题语义、正文用段落、引用用引用语义，不可全靠样式模拟。
- 链接有可辨文本，避免「点这里」；外部链接可提示新窗口。
- 可编辑文本按输入语义，名称与说明齐备，全键盘可达。
- 被截断的文本若有完整内容，辅助技术应能读到完整文本而非截断部分。
- 颜色不作为唯一区分（如仅靠颜色区分链接）。

---

## 常见误用
- 用样式模拟标题而不用标题语义 → 屏幕阅读器无法按标题跳转。
- 省略不生效（容器无宽度约束）→ 文本溢出撑破布局。
- 截断后无法查看完整内容 → 信息不可及。
- 链接文本模糊（「点这里」「更多」）→ 难辨。
- 触摸端复制 / 编辑依赖 hover → 不可发现。
- 空值留白无占位 → 误以为加载失败。
- 字号过小 / 行高过挤 → 可读性差。
- 仅用颜色区分链接 / 状态 → 无障碍缺失。

## 边界与代价
- 语义标签缺失 → 无障碍与可读结构受损。
- 无宽度约束的省略 → 布局失控。
- 截断无完整内容途径 → 信息丢失。
- 触摸端依赖 hover → 不可用。
- 可编辑无校验与失败处理 → 数据错误。
- 字号 / 行高不成体系 → 阅读疲劳。
