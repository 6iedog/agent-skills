# 表格

把结构化的多行多列数据**按行展示**，支持排序、筛选、固定列与行选择，供用户浏览、比对与批量操作。

## 角色与边界

- **是什么**：一个行列对齐的数据网格，每行是一条记录，每列是一个字段。
- **解决什么**：需要横向比对多条记录的同名字段，并可能对它们排序 / 筛选 / 批量操作。
- **不解决什么**：
  - 不解决「每条记录形状不一、图文混排」 → 列表 / 卡片
  - 不解决「只看某条记录的完整详情」 → 描述列表 / 详情面板
  - 不解决「单纯分块」 → 分页
  - 不解决「树形层级数据」 → 树表格（本文件只描述平铺表格）
  - 不承担数据请求本身，只发出排序 / 筛选 / 翻页 / 选中的信号
- **什么时候不用**：列少且每行信息量小 → 列表；记录极少而字段多 → 描述列表；移动端以浏览为主 → 卡片列表。

## UI

### 结构解剖
- **表头行**：每列标题 + 可选的排序器 / 筛选入口 / 列宽拖拽柄
- **列定义**：每列决定取值字段、标题、宽度、对齐、渲染方式、是否可排序 / 筛选 / 固定
- **数据行**：每条记录一行，单元格按列定义渲染
- **选择列**：行首复选框（单选语义时用单选）
- **展开列**：行前展开箭头，展开后在行下方插入详情区
- **单元格**：文本 / 数值 / 标签 / 操作按钮 / 自定义内容
- **行操作列**：常固定在右侧，放行级操作
- **汇总行**：可选，展示合计 / 平均
- **分页条**：表格底部（见分页组件）
- **空 / 加载 / 错误占位**：占据表格主体区域
- **横向滚动容器**：列总宽超出时包裹表格

### 尺寸与外观变体
| 轴 | 取值 | 影响 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 行高、内边距、字号 |
| 边框 | 带外框 / 全网格 / 仅行分隔线 / 无 | 视觉密度 |
| 斑马纹 | 有 / 无 | 长行可读性 |
| 密度 | 紧凑 / 默认 / 宽松 | 单屏可见行数 |
| 表头 | 固定 / 随内容滚动 | 长表导航 |
| 选中方式 | 无 / 单选 / 多选 | 是否出现选择列 |
| 展开 | 不支持 / 支持 | 是否出现展开列 |
| 分页 | 前端分页 / 服务端分页 / 不限 | 数据流形态 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常规行 |
| hover | 行背景微亮，提示可交互 |
| selected | 行背景高亮 + 选择框勾选 |
| focus-visible | 行内可聚焦元素显焦点环 |
| sorting | 表头显示方向（升 / 降 / 未排） |
| filtered | 表头筛选图标高亮，表示该列有生效筛选 |
| expanded | 展开箭头翻转，行下方出现详情区 |
| disabled（行） | 该行降透明、不可选、不可点 |
| loading | 主体区骨架 / 遮罩，防交互 |
| empty | 主体区空状态（区分无数据 / 无匹配） |
| error | 主体区错误态 + 重试 |
| dragging（列宽） | 拖拽分隔线高亮 |

- **选中态与 hover 态必须可区分**：选中是「已被选」，hover 是「正指向」。

### 布局与对齐
- 列宽：固定宽 / 自适应 / 内容撑开；数值与日期常右对齐或等宽对齐
- 固定列：横向滚动时左 / 右固定列不随滚动，需处理其边缘阴影
- 固定表头：纵向滚动时表头吸顶
- 横向滚动：包裹容器承载滚动条；固定列须与其滚动体对齐
- 单元格内容默认单行截断 + 悬停显示完整；需要换行时明确设定
- 行高一致或随内容增高，二选一并保持一致

### 移动端
- 宽表格在小屏体验差：改为卡片列表，或只保留关键列 + 展开看其余
- 若保留表格：冻结首列、允许横向滚动、隐藏次要列
- 触摸目标 ≥ 44×44；行点击与行内操作要区分，避免误触
- 表头排序 / 筛选在移动端常收起为入口

## 交互

### 触发与核心操作（排序 / 筛选 / 翻页）
- 排序：点击表头排序器 → 升序 → 再点降序 → 再点取消（三态可配置）
- 多列排序：可选，按住修饰键再点下一列；需显示排序优先级
- 筛选：点表头筛选入口 → 弹出条件面板 → 应用后请求新数据
- 翻页：见分页组件；每页条数变化重置到第 1 页
- 列宽拖拽：拖拽表头分隔线调整；双击分隔线可自适应宽度
- 列显隐：可选，通过设置入口勾选要显示的列

### 选中与行操作行为
- 选择列：勾选行 → 该行进入选中集
- 全选：勾选表头 → 选中当前页全部可选行；跨页选中需明确语义（当前页 / 全量）
- 全选三态：未选 / 部分选 / 全选
- 点行：是否触发「打开详情」需与选择解耦，避免误触
- 展开行：点展开箭头 → 展开该行详情；可选只允许同时展开一项
- 行操作：行内按钮触发；危险操作需二次确认

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在行内控件、表头排序 / 筛选入口间移动 |
| `Space` | 切换聚焦的复选框选择状态 |
| `Enter` | 激活聚焦的行操作 / 排序 / 筛选入口 |
| `↑` / `↓` | 可选：行间移动焦点（网格导航时） |
| `Home` / `End` | 可选：跳到首 / 末行 |
| `Esc` | 关闭已打开的筛选面板 |

### 指针与手势
- 悬停高亮行；点击选择框选中
- 横向滚动；移动端横滑查看被遮列
- 拖拽分隔线调列宽，指针显明确手型

### 焦点管理
- 展开 / 收起后焦点停留在触发的展开按钮上
- 筛选面板关闭后焦点回到筛选入口
- 行内操作弹层关闭后焦点回到该操作按钮
- 排序后不抢焦点

### 动画与过渡
- 排序 / 筛选 / 翻页的数据刷新以加载态过渡，避免旧数据与新数据硬切造成闪动
- 展开行：高度展开约 150–300ms，避免大幅布局跳动
- 固定列阴影在滚动时淡入

### 反馈
- 排序：表头方向箭头即反馈
- 筛选：生效的筛选入口高亮，可选显示条件标签
- 选择：选中行高亮 + 计数（如「已选 N 项」）
- 操作：行内操作执行后给出结果反馈（成功 / 失败）
- 空 / 加载 / 错误三态明确

### 边界交互
- 无数据 vs 筛选无结果：文案必须区分
- 数据刷新后选中集失效：被删行的选中要清理
- 跨页选择：明确是仅当前页还是全量，并提示
- 列过多：必须横向滚动 + 固定关键列，不能挤压变形
- 固定列与横向滚动条：滚动条不能盖住固定列底部内容
- 服务端排序 / 筛选：前后端排序字段与方向必须对齐
- 快速切换排序 / 筛选：需处理请求竞态

## 数据流

### 输入
- **列定义**：`{ 取值字段, 标题, 宽度, 对齐, 渲染方式, 可排序?, 可筛选?, 是否固定? }` 的列表
- **数据源**：当前页数据数组（服务端分页时由外部提供）
- **分页配置**：当前页、每页条数、总数
- **排序状态**：排序字段 + 方向（可多列）
- **筛选状态**：各列生效条件
- **选中状态**：已选行标识集
- **展开状态**：已展开行标识集
- 其他：加载 / 错误 / 禁用态、是否可选、行标识字段

### 内部状态
- 列宽（拖拽后）
- 当前展开行集合（非受控时）
- 当前排序 / 筛选 / 选中 / 分页（非受控时）
- 横纵滚动位置
- 筛选面板开合

### 输出
- **排序变化事件**：字段 + 方向
- **筛选变化事件**：列 + 条件
- **分页变化事件**：页号 / 每页条数
- **选择变化事件**：选中行标识集（+ 当前页 / 全量语义）
- 行点击 / 展开切换 / 行操作事件
- 列宽变化事件（如需持久化）
- 这些事件**必须能区分**，不能合并成一个含义模糊的「变化」

### 受控 / 非受控
- 服务端数据流下，排序 / 筛选 / 分页 / 选中**均应受控**：组件只抛信号，外部取数后回灌
- 前端数据流下可非受控（组件内部完成排序筛选分页）
- **二选一必须明确**；混用会出现「点了排序不动」或「外部改了不刷新」
- 受控选中时，行标识字段必须稳定（不能用数组下标）

### 异步与竞态
- 服务端排序 / 筛选 / 翻页：请求进行中禁用重复触发或忽略重复请求
- **竞态**：快速改条件时，后发请求先返回会覆盖新结果 → 按请求标识 / 参数快照丢弃过期结果
- 加载态与数据分帧：保持表头与列结构稳定，避免加载时表格高度塌缩
- 展开行内异步内容：单独管理加载 / 错误态

### 校验与错误
- 组件不承担业务校验
- 排序字段 / 方向必须与后端约定一致
- 筛选条件非法时提示或回退
- 请求失败渲染错误态而非空状态

### 回填与序列化
- 排序 / 筛选 / 分页 / 选中常写入 URL 或状态，刷新后恢复
- 回填时校验：页号越界需纠正，失效的筛选字段 / 值需清理
- 选中集跨会话恢复需以稳定行标识为准
- 行标识字段必须全局唯一且稳定

## 无障碍
- 语义化表格结构：表格 + 表头单元格 + 数据单元格，表头与列关联
- 排序按钮标注当前排序方向与状态
- 复选框有可读标签（至少标明是哪一行）
- 展开按钮标注展开 / 收起状态
- 空 / 加载 / 错误状态可被读屏播报
- 行内操作按钮有明确名称
- 全键盘可达；`focus-visible` 可见
- 横向滚动区域可键盘滚动

## 常见误用
- 列多且宽却硬塞进移动端 → 应改卡片列表或精简列
- 记录少、字段多仍用表格 → 描述列表更清晰
- 服务端数据却只做前端排序 → 只排当前页，结果错
- 选中用数组下标作标识 → 数据变化后选中错乱
- 展开行与行点击冲突 → 误触展开 / 误触详情
- 固定列与横向滚动条互相遮挡
- 排序 / 筛选清空选中却不告知
- 空状态与筛选无结果共用文案

## 边界与代价
- 列总宽超出容器：**必须**横向滚动 + 固定关键列（如标识列、操作列），否则关键信息不可达
- 数据超过一屏：**必须**固定表头，否则滚动后不知列含义
- 记录上千：**必须**分页（或虚拟滚动），不能一次渲染全部
- 服务端数据流：排序 / 筛选 / 分页**必须**受控并处理竞态，否则出现「回到第 1 页却显示旧结果」
- 行标识不唯一 / 不稳定：选中与展开全部错乱
- 移动端照搬桌面宽表：信息被压扁或截断，必须换形态
