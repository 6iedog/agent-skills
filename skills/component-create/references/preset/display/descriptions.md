# 描述列表

把一条记录的**多个字段**按「标签 + 值」成对陈列，常用于详情展示。

## 角色与边界

- **是什么**：键值对集合，逐对展示一条记录的字段名与字段值。
- **解决什么**：展示单条记录的多字段详情，字段数固定但不宜用表格。
- **不解决什么**：
  - 不解决「多条记录按字段比对」 → 表格
  - 不解决「可编辑字段」 → 表单
  - 不解决「纵向罗列同类记录」 → 列表
  - 不解决「层级键值（可折叠）」 → 折叠面板 + 描述列表
- **什么时候不用**：需要横向比对多条记录 → 表格；需要编辑 → 表单；字段极少（1–2 个）→ 直接文本。

---

## UI

### 结构解剖
- **列表容器**
- **条目**：一组「标签 + 值」
- **标签**：字段名，常弱化显示
- **值**：字段内容，可含自定义渲染（标签 / 链接 / 状态）
- **分隔**：可选，条目之间或整体边框
- **跨列项**：值独占整行（如长文本、图片）

### 尺寸与外观变体
| 轴 | 取值 | 影响 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 行高、字号、内边距 |
| 布局 | 水平（标签左值右）/ 垂直（标签上值下） | 阅读节奏 |
| 边框 | 有边框 / 无边框 | 视觉分组 |
| 列数 | 1 / 2 / 3 / 响应式 | 一屏字段数 |
| 标签对齐 | 左对齐 / 右对齐 | 视觉 |
| 值渲染 | 文本 / 标签 / 链接 / 自定义 | 表达力 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态条目 |
| hover | 可点击值时（链接 / 操作）背景或文案变化 |
| focus-visible | 值内可聚焦元素显焦点环 |
| empty（值缺失） | 显示占位符（如「-」）或留空，需统一 |
| loading | 骨架占位 |
| error | 加载失败态 + 重试 |

- **值缺失必须有统一占位策略**，不能有的留空、有的显示破折号。

### 布局与对齐
- 多列排列时字段按列铺满，末行不足自动补齐
- 水平布局：标签与值的对齐列宽固定，避免逐行跳动
- 垂直布局：标签在上、值在下，条目之间有明显间距
- 带边框时：单元格分隔线对齐成网格
- 跨列项：标签占正常列宽，值横跨剩余所有列
- 长值换行；长标签截断 + 悬停完整

### 移动端
- 列数收缩为 1（垂直布局更适配窄屏）
- 标签上、值下，避免标签左值右被压扁
- 触摸目标 ≥ 44×44（值含操作时）
- 长文本正常换行，不横向滚动

## 交互

### 触发与核心操作（值交互）
- 本组件以展示为主，交互集中在值内：
  - 值为链接 → 可点击跳转
  - 值为操作入口（编辑 / 复制）→ 点击执行
  - 值为状态标签 → 常为纯展示
- 跨列项可为图片 / 富文本

### 输入与编辑行为
- 只读展示，不做行内编辑
- 若提供「复制值」入口，点击后给出复制反馈

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在值内链接 / 操作间移动焦点 |
| `Enter` / `Space` | 触发聚焦的链接 / 操作 |
| — | 纯文本值不参与焦点 |

### 指针与手势
- 点击值内链接 / 操作
- 长文本无拖拽需求

### 焦点管理
- 值内操作弹层关闭后焦点回到该操作
- 无自动抢焦点

### 动画与过渡
- 以静态展示为主，一般无过渡
- 骨架到内容轻淡入
- 值更新（如详情异步刷新）不引起整块跳动

### 反馈
- 复制 / 编辑等操作给出反馈
- 加载 / 错误态明确

### 边界交互
- 字段缺失：统一占位，或整条不渲染（需明确策略）
- 字段动态增减：列布局随之重排，避免错位
- 值极长：换行或限制行数 + 展开
- 空值 + 有边框时单元格不可塌缩

## 数据流

### 输入
- **条目定义**：`{ 标签, 值或取值字段, 跨列?, 值渲染方式? }` 的列表
- **数据对象**（一条记录）
- 列数 / 布局 / 边框 / 尺寸
- 空值占位符

### 内部状态
- 极少：主要是布局计算与展开态（长值折叠时）

### 输出
- 值内操作事件（如复制、跳转、编辑入口）
- 一般无值变化输出（只读）

### 受控 / 非受控
- **完全受控**：展示内容由外部传入
- 组件不持有业务数据

### 异步与竞态
- 详情异步加载：先骨架后内容
- 加载失败可重试
- 字段随筛选 / 切换记录变化时，注意旧数据残留

### 校验与错误
- 组件不做业务校验
- 缺字段与加载失败必须区分

### 回填与序列化
- 字段值来自记录对象；值渲染需处理 null / 空串 的统一降级
- 无序列化职责

---

## 无障碍
- 用描述列表语义（列表 / 词条 + 释义）承载键值对，使读屏能播报「标签：值」
- 值内链接 / 操作有可读名称
- 空值占位符对读屏可读（或明确标注无值）
- 全键盘可达；`focus-visible` 可见

## 常见误用
- 多条记录用描述列表罗列 → 表格
- 需要编辑却用描述列表 → 表单 / 行内编辑
- 键与值对齐逐行跳动 → 应固定对齐列
- 空值显示不统一 → 视觉与语义混乱
- 长文本挤占导致列布局崩坏

## 边界与代价
- 字段多且需比对：**必须**改用表格
- 窄屏照搬多列：应收敛为单列垂直布局
- 空值无统一占位：语义不清，读屏读出空白
- 水平布局标签列未固定宽：值参差不齐
- 值内嵌复杂交互：需保证键盘可达，不能只靠点击
