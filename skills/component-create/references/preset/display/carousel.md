# 走马灯

在有限空间内**轮播多屏内容**的容器，可自动播放并手动切换。

## 角色与边界

- **是什么**：一个把多份内容按帧排列、逐帧显示的区域，支持自动播放、指示器与切换控件。
- **解决什么**：空间有限但要展示多屏内容（横幅、卡片、图文），或做轻量自动轮播。
- **不解决什么**：
  - 不解决「用户主动逐张浏览大图」 → 图集 / 图片预览
  - 不解决「并列展示」 → 栅格 / 列表
  - 不解决「分页数据」 → 分页组件
  - 不解决「步骤流程」 → 步骤条
- **什么时候不用**：内容少到能一屏放下 → 直接展示；用户必须逐条阅读 → 列表；有核心操作按钮 → 避免用轮播把按钮转走。

---

## UI

### 结构解剖
- **视口**：裁切可见区域的容器
- **轨道**：承载各帧并水平 / 垂直位移的层
- **帧**：单屏内容，可为任意（图 / 卡 / 图文）
- **指示器**：点 / 数字 / 进度条，标示当前帧
- **切换箭头**：上一屏 / 下一屏
- **播放控制**（可选）：暂停 / 播放
- **帧内叠加**：标题、按钮等任意内容

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 过渡 | 滑动 / 淡入淡出 | 滑动强调位移，淡入强调切换 |
| 方向 | 水平 / 垂直 | |
| 指示器 | 圆点 / 数字计数 / 进度条 / 无 | |
| 箭头 | 常驻 / hover 显形 / 无 | |
| 自动播放 | 开 / 关 / 悬停暂停 | |
| 循环 | 循环 / 不循环 | 决定边界行为 |
| 帧数 | 单帧 / 多帧 | 单帧时退化为静态展示 |
| 多帧同显 | 单帧 / 多帧并排（如并排卡片） | |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 显示当前帧 |
| autoplaying | 按间隔自动前进 |
| paused（悬停 / 失焦 / 手动） | 停止自动前进 |
| hover（箭头） | 箭头显形 / 加深 |
| focus-visible | 控件焦点环 |
| dragging（触摸拖动中） | 轨道跟随手指位移 |
| boundary（不循环时到端点） | 越界箭头禁用 |
| empty | 无帧 → 空状态或不渲染 |

### 布局与对齐
- 视口尺寸由外部给定；各帧尺寸一致，避免高低不齐。
- 指示器通常居底部居中，箭头居中于两侧。
- 帧内内容独立布局，不依赖轮播。

### 移动端
- 触摸滑动切换为主，箭头可隐藏。
- 关闭自动播放或延长间隔，避免与滑动冲突。
- 指示器命中区足够大，或设为不可点（仅示意）。

## 交互

### 触发与核心操作
- 切换：点箭头 / 点指示器 / 滑动 / 键盘。
- 自动播放：按间隔前进；用户交互或悬停应暂停。
- 播放控制：手动暂停 / 恢复。

### 选中或输入行为
- 当前帧由索引标识，切换即改索引。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 轮播容器 | `Tab` | 聚焦（通常落在切换控件） |
| 当前帧 | `←` / `→` | 上一帧 / 下一帧 |
| 当前帧 | `↑` / `↓` | 垂直轮播时同理 |
| 播放控制 | `Enter` / `Space` | 暂停 / 播放 |

### 指针与手势
- 桌面：点箭头 / 指示器切换，hover 暂停自动播放。
- 触摸：拖动滑动切换，松手按阈值决定切换或回弹。

### 焦点管理
- 轮播**不应在自动播放时抢焦点**。
- 焦点进入轮播区域应暂停自动播放；离开可恢复。
- 焦点在轮播内移动时不改变当前帧（避免焦点被转走）。

### 动画与过渡
- 滑动 / 淡入时长约 300–500ms，缓动自然。
- 自动播放间隔通常数秒（≥ 5s），不能过快。
- 触摸拖动跟手，松手有回弹或吸附。

### 反馈
- 指示器高亮当前帧即反馈。
- 切换边界（不循环）明确禁用而非静默无响应。

### 边界交互
- 循环边界：从末帧无缝回到首帧。
- 不循环边界：到端点禁用箭头。
- 单帧：隐藏指示器与箭头。
- 拖动未达阈值：回弹到当前帧。
- 自动播放期间用户拖动：暂停并重置计时。

## 数据流

### 输入
- **帧列表**：内容数组（可为任意节点 / 数据）
- 当前索引（受控时）
- 自动播放开关、间隔、是否循环、过渡方式、指示器样式
- 方向

### 内部状态
- 当前索引（非受控时）
- 是否暂停、计时器状态
- 拖动偏移与方向

### 输出
- 帧变化事件：新索引（供外部联动 / 埋点）
- 上 / 下一帧事件
- 暂停 / 播放事件

### 受控 / 非受控
- 当前索引可受控（外部持有）或非受控（内部维护），**必须二选一**。
- 受控时自动播放前进也须通过事件请求外部改索引。

### 异步与竞态
- 帧内容若异步加载，未显示的帧可懒加载。
- 自动播放计时与用户交互竞争：交互应即时暂停并重置计时，避免「刚滑走又自动跳」。

### 校验与错误
- 帧数据为空 → 不渲染或空状态。
- 单帧 → 退化为静态，不显示无效控件。

### 回填与序列化
- 初值索引须落在有效范围，越界时钳制到最近有效帧。
- 帧数据更新后索引若失效需重定位。

---

## 无障碍
- 轮播是**会移动的内容**：必须提供暂停机制，且自动播放不应在无用户操作时无限运行。
- 每帧应有可访问名称；屏幕阅读器中指示器标示当前第几帧。
- 切换控件按按钮语义，全键盘可达，名称含方向（「下一张」）。
- 尊重「减少动态效果」偏好：此偏好下应关闭自动播放与滑动动画。
- 帧内交互元素不能因轮播而变得不可达。

---

## 常见误用
- 自动播放间隔过短 → 用户读不完，且违反无障碍。
- 自动播放不可暂停 → 无障碍缺失。
- 把关键操作按钮放进轮播 → 按钮被转走，用户点不到。
- 指示器命中区过小又要求可点。
- 不循环却显示可循环暗示。
- 移动端照搬桌面箭头 + 自动播放，与滑动冲突。
- 帧高不一致 → 页面跳动。

## 边界与代价
- 自动播放不提供暂停 → 无障碍不合规。
- 帧数过多且不懒加载 → 首屏负担。
- 拖动与自动播放不互斥 → 交互打架。
- 无「减少动态」适配 → 对前庭敏感用户不友好。
- 单帧仍显示控件 → 无效交互。
