# 列表

把多条记录**纵向罗列**，每条占一行（或一格），可含主次信息与行内操作，供浏览与逐条进入。

## 角色与边界

- **是什么**：垂直堆叠的条目集合，每条可独立识别、可携带主次信息与操作。
- **解决什么**：记录条数不定、每条形状不一，或以浏览 / 逐条进入为主。
- **不解决什么**：
  - 不解决「需要横向按字段比对多条记录」 → 表格
  - 不解决「每条信息宫格化、以图片为主」 → 卡片 / 卡片栅格
  - 不解决「单纯分块」 → 分页
  - 不承担数据请求，只发翻页 / 加载更多 / 项操作信号
- **什么时候不用**：字段固定且需比对 → 表格；条目极少且结构一致 → 描述列表；条目以图文卡为主 → 卡片栅格。

## UI

### 结构解剖
- **列表容器**：包裹全部条目
- **条目**：每条一个单元，含主内容 + 可选前缀（头像 / 图标）+ 可选尾部（操作 / 元信息）
- **主内容**：标题 + 可选描述 / 副标题 / 多行文本
- **元信息**：时间 / 标签 / 状态标记
- **项内操作**：悬停或常显的按钮 / 溢出菜单
- **分隔线**：条目之间的分隔
- **加载更多 / 分页区**：列表底部
- **空 / 加载占位**：列表主体

### 尺寸与外观变体
| 轴 | 取值 | 影响 |
|---|---|---|
| 尺寸 | 小 / 中 / 大（或紧凑 / 默认 / 宽松） | 条目高、内边距、字号 |
| 布局 | 单列 / 多列栅格 | 一屏容量与阅读节奏 |
| 分隔 | 有分隔线 / 无 / 卡片式分隔 | 视觉分组 |
| 条目内容 | 仅标题 / 标题+描述 / 含头像或图标 / 含缩略图 | 复杂度 |
| 交互 | 纯展示 / 整条可点 / 仅尾部操作 | 行为 |
| 加载 | 分页 / 加载更多 / 无限滚动 | 数据流 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态条目 |
| hover | 条目背景微亮（可点或含操作时） |
| focus-visible | 条目内可聚焦元素显焦点环 |
| selected | 条目高亮（可选中场景） |
| active（按下） | 整条可点时按下加深 |
| disabled | 降透明、不可点 |
| loading | 骨架条目 / 占位 |
| loading-more | 底部追加加载态 |
| empty | 主体空状态 |
| error | 主体错误态 + 重试 |

### 布局与对齐
- 条目内分前缀 / 主内容 / 尾部三段，主内容占满剩余宽度
- 标题单行截断 + 悬停显示完整；描述可限制行数
- 尾部操作右对齐；多操作时用溢出菜单收纳
- 多列栅格：等宽列，条目高度可不等（瀑布）或对齐（等高）
- 分隔线不重复出现在首尾

### 移动端
- 单列为主；条目内操作优先常显或收进溢出菜单
- 触摸目标 ≥ 44×44；整条点击与尾部操作要留足间隔
- 多列栅格收缩为单列或两列
- 无限滚动 / 触底加载更常用

## 交互

### 触发与核心操作（进入 / 加载）
- 整条可点：点击条目进入详情 / 执行主操作
- 项内操作：点击按钮执行，**不冒泡**触发整条点击
- 分页 / 加载更多 / 触底加载：见分页与加载策略
- 溢出菜单承载次要操作

### 选择与项操作行为
- 若支持选中：点选择区或整条切换选中（二者语义需区分）
- 批量模式：进入后出现选择框与批量操作条
- 项操作执行后需即时反馈，成功可移除或更新该项

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在条目内主操作、项内操作间移动 |
| `Enter` / `Space` | 激活整条（进入）或聚焦的操作 |
| `↑` / `↓` | 可选：条目间移动焦点 |
| `Esc` | 关闭条目溢出菜单 |

### 指针与手势
- 悬停条目显形项内操作
- 移动端横滑露出操作（若有）需可发现，不能是唯一入口
- 触底触发加载更多

### 焦点管理
- 加载更多后焦点保持在触发按钮
- 项操作弹层关闭后焦点回到该操作按钮
- 条目被移除后焦点移到相邻条目或列表容器

### 动画与过渡
- 追加加载：新条目轻淡入，避免整列表跳动
- 项删除：收起或淡出约 150–200ms
- 加载占位到内容切换避免跳闪

### 反馈
- 加载中 / 加载更多态明确
- 项操作结果反馈
- 空 / 错误态明确并可重试

### 边界交互
- 空 vs 无匹配需区分
- 触底到底：显示「没有更多了」
- 加载更多失败：可重试，不静默
- 无限滚动 + 分页混用冲突 → 二选一
- 条目内异步内容（缩略图 / 状态）单独处理加载 / 失败

## 数据流

### 输入
- **数据数组**（当前批 / 当前页）
- **渲染接口**：如何把一条记录映射成条目内容
- 分页 / 加载配置
- 是否可选中、可点击、禁用判定
- **项操作定义**：`{ 文案, 图标?, 回调 }`

### 内部状态
- 加载 / 加载更多状态
- 选中集
- 条目溢出菜单开合
- 滚动位置

### 输出
- **条目点击事件**（携带该条标识）
- **项操作事件**（条目标识 + 操作标识）
- 选择变化事件
- 加载更多 / 翻页请求
- 条目标识需稳定

### 受控 / 非受控
- 数据、选中、加载状态均受控（外部取数、外部持有选中）
- 分页 / 加载更多通常受控（组件抛请求，外部回灌）
- 内部仅持有 UI 临时态（菜单开合、滚动位置）

### 异步与竞态
- 加载更多与筛选 / 刷新并发时，按请求标识丢弃过期结果
- 触底防抖，避免同一页重复请求
- 追加加载要防止重复条目

### 校验与错误
- 组件不做业务校验
- 请求失败渲染错误态并可重试
- 无匹配与无数据分开

### 回填与序列化
- 滚动位置 / 已加载页数如需恢复，记入状态
- 选中集按稳定标识序列化
- 筛选条件可从 URL 回填

## 无障碍
- 用列表语义（列表 + 列表项）承载条目
- 整条可点时用链接或按钮语义，避免给容器绑点击而键盘不可达
- 项内操作有可读名称
- 加载更多 / 空 / 错误状态可被读屏播报
- 全键盘可达；`focus-visible` 可见
- 无限滚动区域提供可达的「加载更多」兜底入口

## 常见误用
- 需要按字段比对却用列表 → 表格
- 整条绑点击但内部又有可点元素 → 冒泡冲突、键盘不可达
- 项内操作仅悬停显形 → 触摸端不可用
- 无限滚动没有到底提示 → 用户不知是否还有
- 条目高度剧烈差异导致阅读错位

## 边界与代价
- 条目过多：**必须**分页或加载更多，不能一次渲染全部
- 项内操作依赖 hover：**必须**为触摸端提供常显或菜单入口
- 无限滚动与分页**必须**二选一，混用冲突
- 缺少「没有更多了」与加载失败重试 → 用户困在列表末尾
- 整条可点 + 内嵌操作：**必须**处理冒泡并保证键盘可达
- 多列栅格不等高：需明确等高还是瀑布，否则对齐错乱
