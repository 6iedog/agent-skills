# 树（展示型）

以**缩进层级**展示具有父子关系的条目，支持展开收起与选中，但**不带勾选**。

## 角色与边界

- **是什么**：以父子缩进结构呈现数据的展示 / 导航控件，节点可展开、可选中、可异步加载。
- **解决什么**：展示层级数据（目录、组织、分类），让用户逐层查看与定位。
- **不解决什么**：
  - 不解决「多选 / 勾选层级」 → 树选择（勾选与父勾选联动是它的职责）
  - 不解决「下拉收起的层级选择」 → 树选择
  - 不解决「逐级收窄的单值选择」 → 级联选择
  - 不解决「平铺列表」 → 列表
- **什么时候不用**：层级浅（≤ 2 层）→ 用分组列表；只是选一个层级值 → 树选择。

> 与树选择分工：**本组件是展示 / 导航型**，节点做「选中当前项」（单值高亮），不做勾选集合；一旦需要「勾选多项、父勾选联动子」，应改用树选择。

## UI

### 结构解剖
- **节点行**：展开箭头 + 图标（可选）+ 文本 + 尾部操作（可选）
- **展开箭头**：有子节点时出现，指示展开态
- **缩进层级**：子节点相对父节点缩进
- **层级连线**（可选）：辅助显示父子关系
- **选中高亮**：当前选中节点
- **加载位**：异步子节点的加载指示
- **尾部插槽**：徽标 / 状态点 / 操作按钮

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 缩进 | 紧凑 / 标准 | 影响嵌套视觉 |
| 连线 | 有 / 无 | 有连线更易辨层级 |
| 箭头位置 | 前置 / 行末 | |
| 展开方式 | 就地展开 / 悬浮子层 | |
| 选中 | 单选高亮 / 无选中（纯导航） | |
| 拖拽 | 不可拖 / 可拖排序 / 可拖换父 | 可选能力 |
| 尺寸 | 小 / 中 / 大 | |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态节点 |
| hover | 行背景微亮 |
| focus-visible | 行焦点环 |
| selected | 选中行强调底，与未选形成对比 |
| expanded / collapsed | 箭头翻转，子层显隐 |
| loading（异步子节点） | 展开处显示加载指示 |
| disabled | 降透明、不可交互 |
| dragover（可拖时） | 显示插入位置 / 目标高亮 |
| empty | 无子节点（无箭头）或整体空状态 |

### 布局与对齐
- 同一层级左对齐一致；缩进量固定，不因文本长短变化。
- 长文本单行省略，悬停显示完整。
- 尾部操作靠右固定，不随文本伸缩。

### 移动端
- 触摸目标行高 ≥ 44。
- 深层级横向空间有限：限制缩进总量或做横向滚动 / 减少缩进。
- 拖拽在触摸端体验差，宜改为「移动」菜单操作。

## 交互

### 触发与核心操作
- 展开 / 收起：点箭头或点行（模式可选）。
- 选中：点行高亮该节点（单值）。
- 异步加载：展开未加载节点时触发拉取子节点。

### 选中或输入行为
- 点行即选中（若定义了选中行为）；再次点不取消（除非允许取消）。
- 展开不等于选中，两者行为分开。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 树 | `Tab` | 进入 / 离开树 |
| 节点 | `↑` / `↓` | 上下移动可见节点 |
| 节点 | `→` | 展开，或移到第一个子节点 |
| 节点 | `←` | 收起，或移到父节点 |
| 节点 | `Enter` / `Space` | 选中当前节点 |
| 节点 | `Home` / `End` | 首个 / 末个可见节点 |
| 字母键 | typeahead | 跳到以该字母开头的节点 |

### 指针与手势
- 点箭头展开收起；点行选中。
- 可拖拽时：按下拖动，悬停到目标显示插入位置，松手落位。
- 触摸端拖拽替换为长按菜单。

### 焦点管理
- 采用 roving tabindex：整棵树一个可聚焦节点，方向键在可见节点间移动。
- 子树收起时焦点若在其中，应移到父节点。
- 异步加载完成后焦点保持在触发节点。

### 动画与过渡
- 展开 / 收起用高度过渡（约 150–250ms），避免瞬跳。
- 加载中的展开位显示 spinner。

### 反馈
- 展开 / 选中即时视觉反馈。
- 异步加载失败给错误提示与重试入口，节点保持可重试。

### 边界交互
- 深层级：限制最大缩进或提供横向滚动。
- 大量节点：虚拟化渲染，只渲染可见行。
- 异步失败：标记节点为「加载失败」，再次展开可重试。
- 拖拽非法目标（如拖进自身子树）：阻止并提示。

## 数据流

### 输入
- **节点数据**：`{ 标识, 文本, 子节点?, 是否叶子?, 是否禁用? }`
- 展开方式（就地 / 悬浮）、连线、缩进
- 默认展开的节点 / 是否懒加载
- 选中值（若可选择）
- 是否可拖拽

### 内部状态
- 展开 / 收起集合
- 当前选中节点（受控时由外部持有）
- 焦点所在节点
- 各节点异步加载状态与已加载子节点缓存

### 输出
- 选中节点变化事件
- 展开 / 收起事件
- 异步加载请求事件（把节点标识抛给外部）
- 拖拽落位事件（新父节点、新顺序）

### 受控 / 非受控
- 选中值可受控或非受控，须明确。
- 展开集合除受控外，通常由内部维护。

### 异步与竞态
- 懒加载：展开时请求子节点，处理加载 / 空 / 错误。
- 快速连续展开不同节点：按节点标识分发与去重，结果不串。
- 已加载节点缓存，重复展开不重复请求。

### 校验与错误
- 节点数据非法（循环引用、缺标识）需兜底，防止无限递归。
- 加载失败给可重试节点态。

### 回填与序列化
- 选中值按标识回填，需沿路径自动展开到该节点并滚动可见。
- 异步回填：目标节点未加载时需逐级加载直至定位。
- 展开集合若需持久化，按节点标识序列化。

---

## 无障碍
- 用树语义：树容器为树角色，节点为树项，含层级与展开状态属性。
- 节点名称可读；展开 / 收起、选中、禁用状态有属性等价。
- 全键盘可达（方向键导航 + 展开 + 选中），焦点环可见。
- 异步加载状态对屏幕阅读器可播报。

---

## 常见误用
- 需要勾选多项却用展示树 → 应指向树选择。
- 点箭头与点行都触发选中，导致展开时误选。
- 每个节点都进 Tab 序列 → 键盘冗长。
- 无虚拟化渲染深大层级 → 卡顿。
- 异步加载失败无重试 → 节点死掉。
- 移动端仅支持拖拽 → 无法操作。
- 缩进随文本长短变化 → 层级错乱。

## 边界与代价
- 大层级不虚拟化 → 性能崩溃。
- 循环引用 / 深递归无兜底 → 栈溢出。
- 拖拽不校验非法目标 → 数据错乱。
- 异步不按标识分发 → 结果串台。
- 键盘导航不走 roving tabindex → 可达性差。
