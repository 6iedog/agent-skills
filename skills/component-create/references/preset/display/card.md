# 卡片

把**一块相对独立的信息与操作**收进一个有边界的容器里，常与同类卡片并排成栅格。

## 角色与边界

- **是什么**：带边框 / 阴影的容器，内含标题区、内容区、可选封面与操作区。
- **解决什么**：把一条内容或一个功能单元视觉上「打包」，便于并排浏览与单独操作。
- **不解决什么**：
  - 不解决「纵向罗列同类记录」 → 列表
  - 不解决「按字段横向比对」 → 表格
  - 不解决「键值对详情陈列」 → 描述列表
  - 不解决「阻塞式确认」 → 模态 / 确认弹窗
- **什么时候不用**：内容形状统一、以比对为主 → 表格；条目为纯文本流 → 列表；只是分块留白 → 布局间距 / 分隔。
- **卡片是容器而非内容类型**：要不要用卡片，取决于「单元是否独立、是否需要并排」。

## UI

### 结构解剖
- **容器**：提供边界（边框 / 阴影 / 背景），可整体可点
- **封面区**：可选，图片 / 媒体，常置顶部
- **标题区**：标题 + 可选副标题 / 头像 / 标签
- **操作区**：右上角或底部，图标按钮或文字按钮 / 溢出菜单
- **内容区**：主体文本 / 数据 / 自定义内容
- **底部区**：可选，元信息 / 次要操作 / 分隔
- **骨架态**：各部分对应的占位块

### 尺寸与外观变体
| 轴 | 取值 | 影响 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 内边距、字号、封面高 |
| 边框 | 有边框 / 仅阴影 / 边框+阴影 / 无边界（靠背景区分） | 视觉重量 |
| 封面 | 无 / 顶部 / 左侧 | 布局 |
| 结构 | 仅标题 / 标题+内容 / 标题+内容+底部 / 含操作区 | 复杂度 |
| 交互 | 静态 / 可悬停 / 整卡可点 / 可选中 | 行为 |
| 栅格 | 固定宽 / 等分列 / 自适应列数 | 排列 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常规边界 / 阴影 |
| hover | 阴影加深或上浮，提示可交互 |
| focus-visible | 整卡可点时显焦点环 |
| active（按下） | 整卡可点时轻微下沉 |
| selected | 选中描边 / 标记（可选中场景） |
| disabled | 降透明、不可交互 |
| loading | 骨架占位（各区块灰块） |
| dragging | 可拖拽排序时抬起 |

### 布局与对齐
- 段间距一致（标题 / 内容 / 底部之间）
- 标题与右上操作同一行，操作右对齐，标题过长截断
- 封面与其下内容对齐；封面可按固定比例裁切
- 栅格中卡片等高；内容多寡不同时底部对齐或留白补齐
- 卡片内操作区与整卡点击区要分层，避免互相吞点击

### 移动端
- 栅格收缩为单列或两列
- 封面比例放大，作为主要视觉
- 项内操作优先常显或收进菜单
- 触摸目标 ≥ 44×44；整卡可点时避免内嵌小操作误触

## 交互

### 触发与核心操作（悬停 / 点击）
- 悬停：提升阴影 / 位移，暗示可点
- 整卡可点：点击进入详情 / 执行主操作
- 内嵌操作：停止冒泡，只执行自身
- 可选中卡片：点击选择区或整卡切换选中（语义需区分）

### 选择与操作行为
- 内嵌操作按钮 / 溢出菜单
- 批量模式：可选中卡片出现选择标记与批量条
- 拖拽排序（可选）：长按 / 抓取柄拖动

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在卡内操作与整卡（若可聚焦）间移动 |
| `Enter` / `Space` | 激活整卡或聚焦操作 |
| `Esc` | 关闭溢出菜单 |

### 指针与手势
- 悬停提升；点击整卡或操作
- 可拖拽排序时指针变抓取

### 焦点管理
- 菜单关闭后焦点回操作按钮
- 卡片被移除后焦点移到相邻卡片
- 整卡可点须可聚焦，不能只靠点击

### 动画与过渡
- 悬停阴影 / 位移约 150–200ms
- 骨架到内容轻淡入，避免跳闪
- 栅格增删卡片避免大幅重排跳动（可用占位）

### 反馈
- 内嵌操作结果反馈
- 加载骨架明确
- 选中态明确

### 边界交互
- 整卡可点 + 内部可点：必须阻止冒泡且键盘可达
- 封面图加载失败：降级占位
- 内容超长：截断 / 限制行数并保持等高
- 可拖拽与整卡点击冲突：需拖拽柄或长按区分

## 数据流

### 输入
- 卡片内容各段（封面、标题、副标题、内容、底部）
- **操作定义**：`{ 文案, 图标?, 回调 }`
- 是否可点 / 可选中 / 禁用
- 骨架开关与骨架形状

### 内部状态
- 溢出菜单开合
- 悬停 / 聚焦状态
- 骨架 / 内容切换

### 输出
- **整卡点击事件**（携带卡片标识）
- **操作事件**（卡片标识 + 操作标识）
- 选择变化事件
- 拖拽排序结果

### 受控 / 非受控
- 内容由外部传入（受控）
- 选中 / 排序结果受控（组件抛事件，外部持有）
- 组件仅持有 UI 临时态

### 异步与竞态
- 卡片数据异步加载：先骨架后内容
- 封面图单独加载 / 失败降级
- 批量操作并发时注意状态一致

### 校验与错误
- 组件不做业务校验
- 内容缺失（无封面 / 无描述）需有合理降级而非塌缩

### 回填与序列化
- 卡片标识在选中 / 排序中必须稳定
- 选中集 / 排序结果可按稳定标识序列化

---

## 无障碍
- 整卡可点时用链接或按钮语义承载，保证键盘可达
- 内嵌操作有可读名称；不可只靠图标
- 封面图有替代文本（承载信息时）
- 选中态可被读屏识别
- 骨架态对读屏隐藏或标注加载中
- 全键盘可达；`focus-visible` 可见

## 常见误用
- 内容本可纵向罗列却排成卡片栅格 → 列表更省空间
- 整卡可点但内部塞可点按钮却没处理冒泡 → 误触发
- 卡片高度不齐且无对齐策略 → 栅格凌乱
- 把卡片当「万能容器」包裹一切 → 视觉噪音
- 骨架形状与实际内容结构不符 → 加载完成时跳变

## 边界与代价
- 整卡可点 + 内嵌操作：**必须**阻止冒泡并保证键盘可达
- 卡片过多：栅格需分页 / 加载更多，不能全量渲染
- 封面大图依赖网络：**必须**有本地降级占位
- 无等高策略：内容多寡导致栅格参差
- 悬停才显形操作：触摸端不可用
