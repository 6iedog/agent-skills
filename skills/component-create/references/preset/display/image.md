# 图片

承载**位图内容**的展示元素，支持预览、占位与加载兜底。

## 角色与边界

- **是什么**：一张（或一组）按容器约束展示的位图，可加载、可失败、可带占位，并可放大预览。
- **解决什么**：在页面中嵌入照片、截图、插图等内容，并处理加载与查看大图。
- **不解决什么**：
  - 不解决「图标 / 矢量符号」 → 图标组件
  - 不解决「上传流程」 → 上传组件
  - 不解决「多图自动轮播切换」 → 走马灯（图集是逐张浏览，走马灯是自动切换）
  - 不解决「品牌插画系统」 → 通常另建资源规范
- **什么时候不用**：纯装饰且用样式能实现 → 不必用图片；需要交互式图表 → 图表组件。

## UI

### 结构解剖
- **图像本体**：位图
- **容器 / 外框**：限定尺寸、圆角、裁剪
- **占位层**：加载中显示骨架或低清占位
- **失败兜底层**：加载失败显示图标 / 文案
- **预览触发器**：点击图像区域进入放大
- **预览浮层**：放大视图，含工具条（缩放、旋转、切换、关闭）
- **图集导航**：多图时的上一张 / 下一张与计数

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 适配方式 | 填满裁剪 / 完整包含 / 拉伸填充 / 按原尺寸 | 决定是否变形 |
| 尺寸 | 固定框 / 自适应宽高 / 按比例 | |
| 圆角 | 直角 / 小圆角 / 全圆 | |
| 预览 | 不可预览 / 可点击放大 / 图集浏览 | |
| 加载 | 立即加载 / 懒加载 | |
| 状态 | 正常 / 占位 / 失败 / 空 | |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 图像正常显示 |
| loading | 骨架 / 低清占位，避免空白 |
| loaded | 淡入显示高清 |
| error | 失败图标 + 可选文案 / 重试 |
| empty | 无图时的空占位 |
| hover（可预览） | 叠加「可放大」的遮罩 / 图标 |
| focus-visible | 焦点环，键盘可进入预览 |
| previewing | 处于放大预览态 |

### 布局与对齐
- 固定框 + 任意比例：按适配方式裁剪，保持视觉一致且不变形。
- 长宽比容器：用占位锁定比例，避免加载完成时布局跳动。
- 图片与文案并排：按容器规则对齐，图片不抢行高。

### 移动端
- 预览改为全屏手势浏览（双指缩放、滑动切换）。
- 点击命中区覆盖整个可见图像。
- 懒加载配合视口出现再加载，节省流量。

## 交互

### 触发与核心操作
- 点击图像 → 进入预览 / 放大。
- 预览内：缩放、旋转、切换、关闭、下载（可选）。

### 选中或输入行为
- 无输入；是否可点由配置决定。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 可预览图像 | `Tab` | 聚焦 |
| 可预览图像 | `Enter` / `Space` | 打开预览 |
| 预览浮层 | `Esc` | 关闭预览 |
| 预览浮层 | `←` / `→` | 上一张 / 下一张（图集） |
| 预览浮层 | `+` / `-` | 放大 / 缩小 |
| 预览浮层 | `0` | 复位缩放 |

### 指针与手势
- 点击打开预览；双指缩放、拖动平移、滑动切换。
- 滚轮缩放（桌面预览）。

### 焦点管理
- 打开预览后焦点移入预览浮层（常为首个控件或图像）。
- 关闭后焦点回到**触发图像**。

### 动画与过渡
- 图像从占位到加载完成淡入（约 150–250ms）。
- 预览开合做淡入 + 轻微放大，不抖动页面布局。

### 反馈
- 加载失败给失败态与重试入口。
- 预览切换有即时视觉响应，切换超时给加载指示。

### 边界交互
- 超大图：做缩略图 + 原图两级，避免一次性加载巨图。
- 超长 / 超宽图：预览内按比例适配，允许平移查看。
- 图集边界：到头不做循环（或明确是否循环），禁用越界箭头。
- 大量图片：必须懒加载 + 虚拟化，防止一次性请求。

## 数据流

### 输入
- **图像地址**（含可选低清占位地址 / 多倍图集）
- 尺寸、适配方式、圆角
- 是否可预览、是否懒加载、占位与失败兜底资源
- 图集列表与当前索引

### 内部状态
- 加载状态：loading / loaded / error
- 预览是否打开、当前索引、缩放比例、旋转角
- 懒加载：是否已进入视口

### 输出
- 点击（打开预览）事件
- 预览内切换 / 缩放事件（若外部需感知）
- 加载失败事件（供外部埋点 / 重试）

### 受控 / 非受控
- 图像地址受控。
- 预览开关与当前索引可受控（外部驱动）也可非受控（内部维护），须二选一明确。

### 异步与竞态
- 懒加载：进入视口才开始请求。
- 图集切换：快速切换时丢弃过期图片，避免「换了索引还显示旧图」。
- 预览高清图加载中先显示低清占位。

### 校验与错误
- 地址失效 → 失败兜底 + 可选重试。
- 格式不支持 → 失败兜底。
- 组件不承担内容审核。

### 回填与序列化
- 地址来自数据字段；图集按索引与列表回填。
- 若地址为临时链接（带时效），过期后需刷新，回填要按资源标识重新取址。

## 无障碍
- 有信息量的图片必须有等价替代文本；纯装饰图片标记为装饰。
- 可点击预览的图像按按钮 / 链接语义，全键盘可达，焦点可见，名称描述「查看大图」。
- 预览浮层是模态层：焦点困于其中，`Esc` 可关闭，关闭后焦点归位。
- 加载失败要有可读的失败说明，而非静默空白。

---

## 常见误用
- 用拉伸适配不同比例 → 变形。
- 无占位、无尺寸锁定 → 加载完成时页面跳动。
- 不懒加载长列表图片 → 首屏请求爆炸。
- 预览不循环却给出可循环暗示，或越界不禁用。
- 无替代文本 → 信息对辅助技术不可达。
- 直接加载原图做缩略展示 → 流量与性能浪费。
- 失败无兜底 → 破图。

## 边界与代价
- 无兜底 / 无占位 → 破图与布局抖动。
- 大图无缩略两级 → 性能问题。
- 图集切换不防竞态 → 显示错图。
- 预览非模态、焦点不归位 → 键盘用户迷路。
- 替代文本缺失 → 无障碍缺失。
