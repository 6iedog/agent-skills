# 时间轴

把一串事件按**时间顺序**沿一条轴线排布，每个节点是一个时间点或状态。

## 角色与边界

- **是什么**：轴线 + 节点序列，展示事件流 / 状态流转的过程。
- **解决什么**：需要体现事件发生的先后顺序、当前进度与各节点状态。
- **不解决什么**：
  - 不解决「线性步骤流程与当前步」 → 步骤条
  - 不解决「真实时间进度条」 → 进度条
  - 不解决「分支流程 / 审批图」 → 流程图
  - 不解决「层级结构」 → 树
- **什么时候不用**：只是并列的无序项 → 列表；严格流程步骤且强调「第几步」→ 步骤条；展示时间分布规律 → 图表。

## UI

### 结构解剖
- **轴线**：贯穿节点的连接线
- **节点**：圆点 / 图标 / 自定义标记，可带状态色
- **时间戳**：节点对应的时间
- **内容区**：标题 + 描述 / 自定义内容
- **连接线**：节点之间的线段
- **加载更多区**：时间轴底部（追加更早 / 更新的内容）

### 尺寸与外观变体
| 轴 | 取值 | 影响 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | 节点直径、字号、间距 |
| 位置 | 仅左 / 仅右 / 左右交替 | 布局 |
| 节点渲染 | 圆点 / 图标 / 数字 / 自定义 | 表达 |
| 状态 | 节点带不同状态色 | 语义 |
| 方向 | 正序 / 反向 | 时间方向 |
| 轴线样式 | 实线 / 虚线 / 无 | 视觉 |

### 视觉状态（逐条）
| 状态（节点） | 表现 |
|---|---|
| default | 常规节点 |
| success | 成功色（如完成 / 通过） |
| processing | 进行中（可带动态效果） |
| warning | 警告色 |
| error | 错误色 |
| pending / gray | 未开始 / 中性 |
| custom | 自定义节点（图标 / 图片） |

- **节点状态色必须有语义约定并全程一致**，且不能仅靠颜色传达。

### 布局与对齐
- 节点与轴线垂直对齐；内容与节点保持固定间距
- 左右交替时：节点居中轴线上，内容左右分布
- 时间戳位置统一（节点旁 / 内容内）
- 长内容换行，不撑破轴线布局
- 轴线在首尾的延伸需统一（留白或封口）

### 移动端
- 左右交替模式在窄屏体验差 → 收敛为仅左（节点 + 内容同行）
- 时间戳移到节点旁或内容首行
- 触摸目标 ≥ 44×44（节点可点 / 加载更多时）
- 内容占满剩余宽度

## 交互

### 触发与核心操作（展开 / 加载更多）
- 加载更多：底部按钮或触底追加更早 / 更新的节点（方向由数据排序决定）
- 节点可点击（如进入详情）时需明确可点态
- 可选：节点内容展开 / 收起

### 节点选择与操作行为
- 若节点承载操作（详情 / 操作菜单），点击节点或内容触发
- 追加加载后新节点按时间顺序插入正确位置

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 在可点节点 / 内容 / 加载更多间移动焦点 |
| `Enter` / `Space` | 激活聚焦的节点或操作 |
| — | 纯展示节点不参与焦点 |

### 指针与手势
- 点击可点节点
- 触底加载更多

### 焦点管理
- 加载更多后焦点保持在触发按钮
- 节点详情弹层关闭后焦点回到节点

### 动画与过渡
- 追加加载：新节点轻淡入
- 进行中节点可选脉动效果，遵循「减少动态」偏好时降级为静态
- 避免加载导致轴线错位跳动

### 反馈
- 加载 / 加载更多态明确
- 加载失败可重试
- 「没有更多」需提示

### 边界交互
- 时间相同 / 乱序：需有稳定的排序与展示策略
- 反向展示（最新在上）：轴线方向与加载方向要一致，避免两端都追加
- 追加到底：显示「没有更多」
- 节点超多：必须分页 / 加载更多
- 自定义节点内容过高：需限制尺寸并保持轴线对齐

## 数据流

### 输入
- **节点数组**：`{ 时间, 标题, 描述, 状态, 自定义节点? }`
- 显示模式：位置、正反序、尺寸
- 加载更多配置（是否可加载 / 方向）

### 内部状态
- 加载更多状态
- 节点展开 / 收起（若有）
- 已加载范围

### 输出
- **节点点击事件**（节点标识）
- 加载更多请求
- 节点操作事件

### 受控 / 非受控
- 节点数据受控（外部提供 / 分页提供）
- 加载更多通常受控（组件抛请求，外部回灌）

### 异步与竞态
- 加载更多与刷新并发：按请求标识丢弃过期结果
- 触底防抖，避免重复请求同批数据
- 追加时去重，避免重复节点

### 校验与错误
- 组件不做业务校验
- 加载失败渲染错误态 + 重试
- 时间格式非法需容错

### 回填与序列化
- 已加载范围 / 展开态如需恢复，记入状态
- 节点标识需稳定，以便操作与去重

## 无障碍
- 用列表语义承载节点序列，读屏可按顺序播报
- 节点状态不能仅靠颜色，需文字或图标替代
- 时间戳对读屏可读
- 可点节点用链接 / 按钮语义，键盘可达
- 加载更多 / 无更多状态可被读屏播报
- `focus-visible` 可见

## 常见误用
- 用时间轴表达「第几步」的流程 → 步骤条
- 节点状态只用颜色区分、无文字 → 色盲不可读
- 左右交替模式直接搬到移动端 → 内容被压窄
- 反向展示却仍从底部追加 → 顺序混乱
- 节点数量巨大却不分页

## 边界与代价
- 节点状态**必须**颜色 + 文字 / 图标双通道，不能仅靠颜色
- 左右交替：窄屏**必须**收敛为单侧
- 反向 / 加载方向**必须**与数据排序一致，否则出现「越加载越乱」
- 节点过多：**必须**分页 / 加载更多，不能全量渲染
- 自定义节点尺寸不受限：会破坏轴线对齐
