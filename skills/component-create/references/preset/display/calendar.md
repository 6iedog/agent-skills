# 日历（月历）

以**网格展示日期**的展示型日历，承载事件标记与日期选择。

## 角色与边界

- **是什么**：按月 / 年排布的日期网格，展示日期、事件标记，并可选日期。
- **解决什么**：一眼看清一段时间的安排（哪些天有事件、哪天被选中）。
- **不解决什么**：
  - 不解决「输入一个日期」 → 日期选择器（本组件强调看全貌，选择器强调取值回填）
  - 不解决「日程详情编辑」 → 事件面板 / 抽屉
  - 不解决「多日历聚合视图（周 / 日时间轴）」 → 日程视图组件
- **什么时候不用**：只让用户挑一个日期且无需看整月 → 日期选择器；纯展示某一天 → 日期文本。

> 与日期选择器分工：**本组件是展示月历**，强调「看全貌 + 标事件」；日期选择器强调「选一个值并回填到输入框」。两者可互为触发——选择器点开弹出的面板本身可由日历承担。

## UI

### 结构解剖
- **头部**：年月标题 + 上 / 下期切换 + 视图切换（月 / 年）
- **星期表头**：一周七列
- **日期网格**：每格一个日期，含可选标记 / 事件点
- **相邻月日期**：上 / 下月溢出日期，通常弱化
- **事件标记**：色点 / 条 / 数字计数
- **今日高亮**：标记「今天」
- **视图切换**：月视图 / 年视图（月份网格）

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 视图 | 月视图 / 年视图 | 年视图点月份进入月视图 |
| 卡片式 | 有边框卡片 / 无边框嵌入 | |
| 选择 | 只读展示 / 可选日期 / 可选择区间 | |
| 标记 | 色点 / 竖条 / 计数 / 自定义内容 | |
| 周起始日 | 周一 / 周日 | 需与地区习惯一致 |
| 尺寸 | 紧凑 / 标准 / 大 | |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 常态日期 |
| today | 今日强调（描边 / 加粗） |
| selected | 选中日期的强调底 |
| in-range（区间选择） | 区间内日期淡底 |
| hover | 日期格背景微亮 |
| disabled | 不可选日期降透明 |
| outside（相邻月） | 弱化显示，通常不可选 |
| has-event | 带事件标记 |
| focus-visible | 日期格焦点环 |
| loading | 数据加载中的骨架（事件数据异步时） |

### 布局与对齐
- 7 列等宽网格，行高一致。
- 头部标题居中或左对齐，切换控件两侧或右侧。
- 事件标记位置固定（如日期数字下方），不挤动数字。
- 与事件面板并排时，日历占主区，面板占侧栏。

### 移动端
- 整月网格在窄屏仍可容纳，但触控目标 ≥ 44×44。
- 可切换为「周视图 + 滑动换周」或「折叠为按天列表」。
- 事件较多时避免用点过于密集，点击日期弹出当天事件。

## 交互

### 触发与核心操作
- 切换月份：上一月 / 下一月 / 回到今日。
- 切换视图：月 ↔ 年（年视图点月份进入该月）。
- 选择日期：点某天选中。
- 查看事件：点带标记的日期展开当日列表 / 面板。

### 选中或输入行为
- 单选：点日期即选中，替换旧选中。
- 多选 / 区间：按规则选取起止或累计（若支持）。
- 相邻月日期：点后通常跳转到该月并选中。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 日期网格 | `Tab` | 进入 / 离开网格 |
| 日期网格 | `←` / `→` | 前 / 后一天 |
| 日期网格 | `↑` / `↓` | 前 / 后一周 |
| 日期网格 | `PageUp` / `PageDown` | 上一月 / 下一月（可含 `Shift` 切年） |
| 日期网格 | `Home` / `End` | 本周首 / 末 |
| 日期网格 | `Enter` / `Space` | 选中当前聚焦日期 |
| 头部控件 | `Enter` / `Space` | 切换月份 / 视图 |

### 指针与手势
- 点日期选中；点标记展开事件。
- 触摸端左滑 / 右滑切换月份（可选）。
- hover 显示日期提示，不依赖 hover 表达关键状态。

### 焦点管理
- 网格内用 roving tabindex：整个网格一个可聚焦单元格，方向键移动焦点。
- 切换月份后焦点应落在合理日期（如当月首日或原聚焦日的对应日）。
- 从事件面板返回后，焦点归位到触发日期。

### 动画与过渡
- 切换月份可做轻微滑动 / 淡入，约 200–300ms。
- 选中态切换即时或短过渡。

### 反馈
- 选中即时高亮即反馈。
- 事件数据异步时给加载指示。

### 边界交互
- 月末 / 月初对齐：补全相邻月日期，保证 7 列完整。
- 周起始日配置不同会影响列序，须全站一致。
- 大量事件：标记聚合为计数，点开看详情。
- 超出可选范围（如禁选过去日期）：禁用并说明。

## 数据流

### 输入
- **当前年月 / 视图**
- **可选范围**（最早 / 最晚）、禁用日期
- **选中值**（单日 / 区间）
- **事件数据**：按日期映射的标记（色点 / 计数 / 内容）
- 周起始日、尺寸、是否可切换视图

### 内部状态
- 当前显示年月
- 网格内当前聚焦日期（键盘导航）
- 事件数据加载状态

### 输出
- 选中日期变化事件（单日 / 区间）
- 月份 / 视图切换事件
- 日期点击事件（用于展开事件）

### 受控 / 非受控
- 选中值与当前年月均可受控或非受控，须明确。
- 展示型常只受控「选中值 + 事件数据」，年月由内部维护。

### 异步与竞态
- 事件数据按月加载：切换月份即请求，需处理加载 / 空 / 错误。
- 快速切换月份时丢弃过期响应，避免「切到 3 月却显示 2 月事件」。
- 已加载月份可缓存，减少重复请求。

### 校验与错误
- 选中越界（超出可选范围）应被拒绝或钳制。
- 事件数据失败给重试，不阻塞日历展示（日期网格仍可用）。

### 回填与序列化
- 初值日期 → 定位到该月并标记选中。
- 区间值按起止回填，跨月区间在两端分别标记。
- 事件数据按日期键回填；键格式（是否含时区、是否按天）须明确。

---

## 无障碍
- 日期网格用网格语义，每格名称读作完整日期（年 / 月 / 日 / 星期），而非仅数字。
- 今日、选中、有事件、禁用等状态有文本或属性等价，不只靠颜色。
- 全键盘可达（方向键导航 + 选中），焦点环可见。
- 头部切换控件按按钮语义，名称含目标（「上一月」）。

---

## 常见误用
- 把展示月历当作日期输入 → 缺输入与回填，应指向日期选择器。
- 事件只用色点表达且无色 / 文本等价 → 无障碍缺失。
- 网格仅用数字无完整日期名称 → 屏幕阅读器难辨。
- 周起始日与地区习惯不符 → 错位。
- 切换月异步不防竞态 → 事件错位。
- 事件过多不聚合 → 标记糊成一片。
- 触摸目标过小 → 移动端点不准。

## 边界与代价
- 事件数据异步不防竞态 → 显示错误月份数据。
- 无文本等价的颜色标记 → 无障碍缺失。
- 键盘导航不走 roving tabindex → 每个日期都进 Tab 序列，冗长或不可达。
- 可选范围不明确 → 用户选了无效日期才知错。
- 移动端照搬整月网格且目标过小 → 不可用。
