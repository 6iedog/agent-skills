# 头像

代表一个**人 / 实体**的方形或圆形图像标识，可含文字、图标或图片。

## 角色与边界

- **是什么**：一个统一尺寸的图形容器，用于标识用户、团队、应用等主体。
- **解决什么**：在列表 / 评论 / 消息中快速识别人或实体，并建立归属感。
- **不解决什么**：
  - 不解决「详情展示」 → 卡片 / 用户信息面板
  - 不解决「在线状态本身」 → 状态点（可附着在头像上，但状态语义不属头像）
  - 不解决「上传图片的完整流程」 → 上传组件
  - 不解决「品牌大图 / 插画」 → 图片组件
- **什么时候不用**：只出现一次且已有人名 → 可能不需要头像；空间极窄（如紧凑表格单元格）→ 用文字或图标。

---

## UI

### 结构解剖
- **图形容器**：固定尺寸的圆 / 方 / 圆角方形
- **内容层**：图片 / 文字缩写（首字母、姓名缩写）/ 默认图标
- **兜底层**：加载失败或缺失时的占位
- **角标位**：可挂状态点 / 徽标
- **群组容器**：多个头像重叠堆叠

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 尺寸 | 超小 / 小 / 中 / 大 / 超大 | 覆盖列表到个人主页 |
| 形状 | 圆形 / 方形 / 圆角方形 | 同一产品应统一 |
| 内容 | 图片 / 文字缩写 / 图标占位 | 图片优先，缺失降级 |
| 群组 | 单个 / 堆叠组（含 +N） | 堆叠有重叠与遮罩 |
| 可编辑 | 只读 / 可点击 / 可上传替换 | 决定交互态 |
| 角标 | 无 / 状态点 / 徽标 | 附着而非内置 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 图片正常显示 |
| loading | 骨架 / 占位底色，避免闪烁 |
| error / fallback | 图片失败显示文字缩写或图标 |
| hover（可点 / 可编辑） | 叠加微遮罩或描边，提示可操作 |
| focus-visible | 明显焦点环 |
| disabled | 降透明 |
| editable-hover | 显示「更换」遮罩 / 相机图标 |
| stacked | 群组中每个头像带描边以分隔 |

### 布局与对齐
- 头像与文字并排时，通常**顶部或中线对齐**，按行高选择。
- 缩写在容器内居中，字号随容器尺寸成比例（约容器 40%）。
- 群组堆叠：每个头像重叠一定比例，后一个压在前一个之上，末端挂「+N」。
- 与状态点 / 徽标同用时，角标锚定在右下等固定角。

### 移动端
- 可点击 / 可编辑头像命中区 ≥ 44×44（视觉可小，命中区外扩）。
- 群组堆叠不要过密，触摸端保证可辨认与可点。
- 触摸端不用 hover 表达可编辑，改用常驻遮罩或编辑入口。

## 交互

### 核心操作
- 只读：无操作。
- 可点击：跳转个人页 / 打开资料卡。
- 可编辑：点击进入上传或拍照流程。

### 选中或输入行为
- 头像本身不输入；作为选择项时的选中态由外部驱动。

### 键盘
| 场景 | 键位 | 行为 |
|---|---|---|
| 只读头像 | — | 不进入键盘序列 |
| 可点击 / 可编辑 | `Tab` | 聚焦 |
| 可点击 / 可编辑 | `Enter` / `Space` | 触发跳转 / 编辑 |
| 群组 | `Tab` | 焦点落在组容器，而非每个头像 |

### 指针与手势
- hover 显示可交互遮罩（可编辑）。
- 点击触发对应动作；触摸端点击即触发。
- 群组悬停可显示被遮挡头像的名称提示。

### 焦点管理
- 只读头像不可聚焦。
- 可交互时焦点落在包裹控件上，遮罩不单独接收焦点。
- 编辑流程结束后焦点回到头像。

### 动画与过渡
- 图片从占位到加载完成做淡入，避免跳变。
- 堆叠组新增 / 移除成员用短过渡。
- 遮罩显隐约 100–150ms。

### 反馈
- 上传成功即时替换图像即反馈；失败给错误提示并保留原图。
- 加载失败显示兜底，不出现破图。

### 边界交互
- 图片比例各异：用填充裁剪，保持一致视觉，不拉伸变形。
- 无图片且无姓名缩写：用通用图标兜底。
- 群组成员过多：超出部分收纳为「+N」。
- 头像尺寸极小：文字缩写不可读时应改用图标。

## 数据流

### 输入
- **图像地址**（可选）
- **名称**（用于生成缩写与可访问名称）
- 尺寸、形状
- 是否可点 / 可编辑、目标链接
- 角标配置（状态 / 徽标）
- 群组成员列表（堆叠模式）

### 内部状态
- 图片加载状态：loading / loaded / error
- 编辑流程的临时选择（上传前预览）
- 群组展开态（若有）

### 输出
- 点击事件（跳转 / 打开资料）
- 编辑事件：新图像文件 / 地址
- 群组展开事件（若有）

### 受控 / 非受控
- 图像地址**受控**：由外部数据传入；编辑后由外部更新。
- 组件内部仅维护加载状态。

### 异步与竞态
- 图片异步加载需处理加载 / 失败两态。
- 快速切换地址时丢弃过期图片（按地址标识），避免旧图覆盖新图。
- 上传过程中禁用二次触发。

### 校验与错误
- 图片格式 / 尺寸校验属上传环节；头像只负责显示兜底。
- 地址失效 → 降级到文字缩写 → 再降级到图标。

### 回填与序列化
- 地址与名称直接来自数据字段。
- 缩写生成规则须稳定（如取姓名首字 / 首字母），保证同一主体始终一致。
- 群组按成员标识回填，顺序稳定。

---

## 无障碍
- 头像若承载主体身份，需有等价可访问名称（如用户姓名），不能只靠图像。
- 纯装饰头像应被辅助技术忽略。
- 文字缩写对屏幕阅读器应读出完整名称而非缩写。
- 可点击 / 可编辑头像按按钮或链接语义，全键盘可达，焦点可见。
- 状态点语义需文本等价，不只用颜色。

---

## 常见误用
- 图片缺失直接显示破图 → 必须有兜底。
- 用拉伸而非裁剪适配不同比例 → 变形。
- 极小头像仍放文字缩写 → 不可读。
- 群组无「+N」收纳 → 溢出或过密。
- 触摸端依赖 hover 提示可编辑 → 不可发现。
- 头像的可访问名称缺失 → 只读作「图像」。
- 同一处圆角方形与圆形混用 → 不一致。

## 边界与代价
- 无兜底 → 破图，观感与信息双损。
- 图像地址异步且不防竞态 → 出现「换人不换图」。
- 群组成员无上限收纳 → 溢出。
- 命中区过小 → 移动端不可点。
- 可访问名称缺失 → 无语义或朗读噪音。
