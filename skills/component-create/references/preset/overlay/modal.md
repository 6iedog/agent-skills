# 模态对话框

浮出并**阻塞背景**，用户必须处理它才能回到主流程。

## 角色与边界

- **是什么**：一层覆盖主界面的容器；出现时背景被遮罩、交互被拦截，用户只能先与这层对话。
- **解决什么**：需要用户**专注完成一件事**、且不宜被主流程打断的场景——表单录入、重要信息确认、需要引用上下文的查看。
- **不解决什么**：
  - 只是一句结果反馈 → 消息提示
  - 只是给某元素补一句解释 → 文字提示
  - 只问「确定 / 取消」 → 确认弹窗（模态的特例，另有专文）
  - 长表单 / 长内容，或需保留页面上下文来回对照 → 抽屉 / 独立页
  - 不可关闭又无理由 → 不要做
- **什么时候不用**：
  - 用户需要在主界面与本层之间反复对照 → 抽屉
  - 内容只有一两行 → 气泡卡片 / 文字提示
  - 步骤多、需要嵌套 > 1 层 → 独立页 / 步骤页
  - 每个操作都弹 → 训练用户无脑关闭，反而不安全

## UI

### 结构解剖
- **遮罩层**：覆盖整个视口，压暗背景并拦截指针事件
- **容器**：承载内容的面板，带圆角、阴影、背景色与最大宽高
- **头部**：标题（左起）+ 关闭入口（右上）；可含图标、副标题
- **主体**：内容区，文本 / 表单 / 列表 / 任意自定义
- **底部操作区**：主 + 次按钮，通常右对齐；左侧可放辅助说明 / 附加链接
- **关闭入口**：右上角关闭按钮（是否提供取决于「是否允许关闭」）
- **状态占位**：主体内的加载 / 空 / 错误位

### 尺寸与外观变体
- 宽度：小 / 中 / 大 / 自适应内容 / 全屏
- 高度：自适应内容 / 固定高度（主体内滚）
- 对齐：垂直居中（短内容）/ 顶部对齐（长内容，避免顶部被裁）
- 外观：标准卡片 / 无边框 / 强调型（危险或重要）
- 复杂度：信息型（单关闭按钮）/ 表单型 / 决策型（底部两按钮）
- 滚动策略：整体滚动 / 主体滚动且头尾固定（推荐长内容）

### 视觉状态（逐条）
| 状态 | 遮罩 | 容器 / 内容 | 底部按钮 |
|---|---|---|---|
| default | 半透明压暗、拦截点击 | 圆角 + 阴影，静置 | 主次按钮常态 |
| entering | 由透明渐显 | 由略小 / 略下位移 + 淡入 | — |
| closing | 渐隐 | 淡出 + 轻微位移 | — |
| 关闭按钮 hover | — | 关闭按钮背景微亮 | — |
| 关闭按钮 focus-visible | — | 明显焦点环 | — |
| loading | — | 主体显示骨架 / spinner | 提交按钮 spinner 且禁用 |
| error | — | 错误提示条 / 主体内错误文案 | 保持可点以便重试 |
| disabled | — | — | 提交按钮降透明、不可点 |
| 强制不可关 | 拦截点击、遮罩不可点 | 无关闭入口 | 仅保留必要出口 |

### 布局与对齐 / 定位
- 居中定位；宽度受最大宽度约束，两侧留安全边距
- 长内容：**顶部对齐**并让「主体」内滚，头 / 尾保持在视野内
- 主体内滚时，滚动条只在主体内出现，不波及页面
- 视口过矮：容器最大高度 = 视口高 − 边距，超出部分内滚
- 宽度用「最小值 + 百分比」，避免小屏溢出

### 移动端
- 窄屏常改为**全屏**或**底部贴合式面板**，放弃侧边留白
- 操作按钮加高（触摸目标 ≥ 44×44），主次按钮可纵向堆叠
- 关闭入口放在拇指可达处（顶部右上或底部主按钮）
- 软键盘弹起时避免遮挡输入框：容器随键盘上移或输入框滚入视野

## 交互

### 触发与开合
- 由外部动作触发（按钮点击、菜单项、快捷键等），非常驻
- 同一时刻通常只允许一层；确需多层时见「边界交互」
- 打开即进入焦点陷阱，关闭即归还焦点

### 关闭行为
| 关闭来源 | 是否默认可关 | 说明 |
|---|---|---|
| Esc | 是 | 与遮罩开关同源控制 |
| 点击遮罩 | 视场景 | 表单 / 危险场景常关闭此项，防误关丢数据 |
| 关闭按钮 | 视可关闭性 | 强制场景不提供 |
| 操作完成 | 是 | 提交成功后由外部关闭 |
| 取消按钮 | 是 | 与遮罩开关同源语义 |

- 存在未保存内容时，任意外部关闭都要先**二次确认**（指向确认弹窗）
- 危险 / 破坏性操作提交前也要二次确认，**不把确认内置进本层**

### 键盘
| 键 | 行为 |
|---|---|
| Tab | 焦点在容器内**循环**，不逃逸到背景 |
| Shift+Tab | 反向循环 |
| Esc | 关闭（若允许）；提交中按策略决定是否忽略 |
| Enter | 触发表单提交 / 激活默认按钮 |
| Space | 激活当前聚焦控件 |
| ↑ / ↓ | 仅当内容含列表 / 单选组时用于内部导航 |

- 打开时**初始焦点**：首个可聚焦控件；表单给第一个输入；纯信息型给关闭按钮或容器本身
- 关闭后焦点**归还给触发它的元素**，不得丢到 body

### 指针与手势
- 桌面：点击遮罩关闭（若允许）；点击容器内部不关闭
- 移动端：底部贴合式可支持**下滑关闭**，并提供显式关闭按钮兜底
- 拖动 / 选择文本时误触遮罩不应关闭：区分「点按」与「拖拽结束」

### 焦点管理
- 打开前：记录当前焦点元素
- 打开后：焦点移入容器并激活焦点陷阱
- 关闭后：焦点归还记录的触发元素；该元素已不存在时退到邻近合理元素
- 背景内容 `inert` / 不可聚焦，防止 Tab 穿透

### 动画与过渡
- 遮罩淡入淡出，容器轻微位移 + 淡入，约 150–250ms
- 位移方向与对齐方式一致（居中→缩放，顶部→下滑）
- 动画期间不阻塞交互；减少动态偏好时退化为纯淡入
- 关闭动画结束后再移除节点、恢复滚动

### 反馈
- 提交中：主按钮 loading 且禁用，禁止重复提交
- 成功：由外部决定关闭本层还是切换为成功态
- 失败：**不关闭**，在主体内显示错误，保留用户已填内容

### 边界交互
- **嵌套**：模态中再开模态，层级与遮罩叠加须明确；> 1 层应重构为步骤 / 页面
- **滚动锁定**：打开时锁 body 滚动，关闭后恢复；多层叠加需计数，全部关闭才解锁
- **多次打开**：同一实例重复打开要重置内部状态（滚动位置、错误、loading）
- 与路由：可作为可深链的独立路由状态，刷新后按策略恢复或关闭

## 数据流

### 输入
- **内容**：主体内容 / 子节点
- **标题**：有 / 无（无标题时须以其它方式标识用途）
- 尺寸、对齐、是否可关闭、遮罩点击是否关闭
- 底部操作区配置：按钮文案、类型（主 / 次 / 危险）、是否禁用
- 初始数据（表单型：回填值）

### 内部状态
- open（开合，归属见下）
- loading / submitting
- 错误信息
- 主体滚动位置
- 焦点来源元素记录

### 输出
- **确认 / 提交事件**：含提交数据（表单型）
- **取消 / 关闭事件**：含关闭来源（Esc / 遮罩 / 按钮），供外部区分是否需二次确认
- 打开 / 关闭生命周期事件（供外部联动）

### 受控 / 非受控
- 受控：open 由外部持有，组件只在事件里请求开 / 关，自身不改状态
- 非受控：内部持有，提供默认打开状态
- **二选一必须明确**；混用会出现「点了不关」或「外部改了不响应」

### 异步与竞态
- 提交中**禁用关闭**（或关闭前确认），防止请求悬空
- 请求失败**不关闭**，恢复可交互并提示
- 竞态：多次打开 / 提交时用请求标识丢弃过期响应，避免旧结果覆盖新状态

### 校验与错误
- 校验在**表单层**完成，本层负责呈现错误态
- 校验失败时**阻止关闭**并聚焦到首个错误字段（表单型）
- 错误可落字段旁或主体顶部汇总条，选一种并保持一致

### 回填与序列化
- 打开时初始数据从外部传入；内部只做展示与收集
- 关闭后是否保留已填数据由外部决定；默认丢弃，需要草稿时外部持有
- 提交数据结构由外部定义，本层不预设字段

## 无障碍
- 容器标注 `role=dialog`；遮罩存在时加 `aria-modal=true`
- 标题用 `aria-labelledby` 关联；无可见标题时用 `aria-label`
- 提供焦点陷阱，Tab 不逃逸；Esc 可达
- 打开时背景内容 `inert`，读屏不被背景干扰
- 关闭后焦点归还；禁止无替代的 `outline: none`

## 常见误用
- 用它承载一句提示 → 过重，应消息提示
- 用它做长表单 → 应抽屉 / 独立页
- 嵌套模态再嵌套 → 层级混乱
- 有未保存内容却可直接关闭且无提示
- 移动端照搬 PC 居中弹窗，挤成一团
- 把破坏性确认内嵌其中，且危险按钮默认聚焦 → 回车误删

## 边界与代价
- 嵌套 > 1 层：体验崩坏，应重构为步骤 / 页面
- 内容超一屏：抽屉 / 页面优于模态
- 强制不可关：必须有明确理由，并给出退出说明
- 关闭会丢数据：必须二次确认
- 锁定滚动未计数恢复 → 关闭后页面滚不动
- 焦点未归还 / 陷阱缺失 → 键盘与读屏用户迷失
