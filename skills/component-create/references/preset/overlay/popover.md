# 气泡卡片

**锚定在某个元素旁**的轻浮层，可含**少量可交互内容**。

## 角色与边界

- **是什么**：附着在锚点元素旁的浮层，带定位避让，内部可含按钮 / 链接 / 轻量表单等可交互内容。
- **解决什么**：与某元素相关的补充操作或信息——点按图标弹出的说明卡、行内快速编辑、次级操作面板。
- **不解决什么**：
  - 仅一句**不可交互**说明 → 文字提示（与其关键区别在「是否含交互」）
  - 需要用户专注处理较复杂内容 → 模态 / 抽屉
  - 内容很长 / 结构化 → 抽屉 / 页面
  - 与某行一一对应的菜单式操作 → 下拉面板（职责相近，按是否为锚点菜单区分）
- **什么时候不用**：
  - 移动端依赖 hover 触发 → 触摸端无法触发
  - 含交互内容却仍用悬停触发 → 鼠标移出即消失，点不到
  - 内容超过少量几行 → 改抽屉 / 模态

---

## UI

### 结构解剖
- **锚点元素**：气泡依附的触发器（按钮 / 图标 / 文字）
- **浮层容器**：承载内容的面板，带圆角、阴影、边框
- **箭头**（可选）：指向锚点
- **内容区**：文本 + 可交互控件（按钮 / 链接 / 轻量表单）
- **关闭入口**（可选）：右上角关闭按钮，用于点击型
- **状态占位**：内容区加载 / 空 / 错误位

### 尺寸与外观变体
- 触发方式：点击 / 悬停 / 聚焦 / 受控
- 放置方向：上下左右共 12 个方位（含对齐方式），自动避让翻转
- 外观：带箭头 / 无箭头 / 带标题栏
- 交互性：纯信息 / 含交互控件
- 受控 / 非受控

### 视觉状态（逐条）
| 状态 | 锚点元素 | 浮层 / 内容 |
|---|---|---|
| default | 静置 | 浮层贴锚点，带阴影 |
| entering | — | 淡入 + 朝锚点方向轻微位移 |
| closing | — | 淡出 + 收回位移 |
| hover | 锚点背景微亮 | — |
| focus-visible | 锚点明显焦点环 | — |
| open | 锚点呈激活态 | 浮层可见，箭头指向锚点 |
| 内容控件 hover | — | 内部按钮 / 链接背景变化 |
| 内容控件 focus-visible | — | 内部控件焦点环 |
| loading | — | 内容区骨架 / spinner |
| error | — | 内容区错误文案 + 重试（若适用） |
| disabled | 锚点降透明、不可触发 | 打不开 |

### 布局与对齐 / 定位
- 以锚点为基准按 12 个方位计算；缺省方向随空间自动翻转
- 空间不足时优先翻转方向，其次沿主轴偏移避让视口边缘
- 浮层宽度受限，内容超宽自动换行，不做横向溢出
- 浮层与锚点间留出间距，箭头居中对齐指向点
- 滚动容器内：以可视视口为参照定位，滚动时跟随或关闭（见边界交互）

### 移动端
- **不用 hover 触发**：改为点击触发
- 空间狭小常退化为**底部贴合面板**或居中卡片
- 触摸目标 ≥ 44×44；内部控件间距加大
- 内容较多时直接改用抽屉 / 模态，不在小屏硬塞浮层

## 交互

### 触发与开合
- 触发方式：点击锚点（推荐，尤其含交互时）/ 悬停（仅纯信息）/ 聚焦 / 外部受控
- 打开：浮层出现并计算定位；同一时刻通常只显示一个气泡
- 关闭：再次点击锚点、点击浮层外、Esc、触发项完成动作后

### 关闭行为
| 关闭来源 | 是否默认可关 | 说明 |
|---|---|---|
| 点击锚点 / 切换到别处 | 是 | 点击型开合开关 |
| 点击外部 | 是 | 点击型默认行为 |
| Esc | 是 | 键盘可关 |
| 内容项完成动作 | 视场景 | 如点菜单项后自动关闭 |
| 悬停移出 | 悬停型 | 含交互时禁用此法，避免闪没 |

- 含交互内容时**不用悬停触发**：移出即消失会导致点不到内部按钮
- 内容含未保存编辑时，关闭前按策略确认

### 键盘
| 键 | 行为 |
|---|---|
| Enter / Space | 锚点聚焦时打开 / 关闭 |
| Tab | 点击型且焦点移入浮层时，在浮层内循环 |
| Shift+Tab | 反向循环 |
| Esc | 关闭并将焦点归还锚点 |
| ↓ / ↑ | 浮层含列表时可进入 / 在项间移动 |

- 初始焦点：纯信息型可留在锚点（浮层仅做说明关联）；**含交互型必须把焦点移入浮层首个控件**

### 指针与手势
- 桌面：点击锚点开合；点外部关闭
- 悬停型：移入显示、移出隐藏，须给「移到浮层」留缓冲，避免缝隙导致误隐
- 移动端：点击触发；点外部关闭；不做 hover

### 焦点管理
- 点击型含交互：打开后焦点移入浮层；关闭后归还锚点
- 纯信息型：焦点可留在锚点，浮层不参与 Tab 序列
- 悬停型：不改变焦点（悬停不应抢焦点）
- 关闭后焦点必须回到锚点，不得丢到 body

### 动画与过渡
- 淡入 + 朝锚点方向轻微位移，约 100–180ms
- 箭头与容器同步出现
- 不引起页面布局抖动（浮层脱离文档流）
- 减少动态偏好时退化为纯淡入淡出

### 反馈
- 异步内容：打开即显示加载；失败显示错误 + 重试
- 含提交动作的浮层：提交时禁用控件并 loading，成功后关闭或切换态
- 失败不关闭，保留用户输入

### 边界交互
- **点击外部关闭**：须正确识别「点在浮层内 / 锚点内 / 外部」，避免点子元素被误判为外部
- **滚动容器内定位**：随容器滚动需重算位置；容器本身滚动时可选择跟随或直接关闭
- **多个气泡**：同时只允许一个打开，打开新的先关闭旧的
- 嵌套浮层（浮层内再开一个）应尽量避免；确需时明确层级与关闭顺序

## 数据流

### 输入
- 触发方式（点击 / 悬停 / 聚焦 / 受控）
- 内容（信息文本 / 交互控件 / 轻量表单）
- 放置方向与对齐、是否显示箭头
- 是否点击外部关闭
- 初始数据（含表单时）

### 内部状态
- open
- 计算出的实际放置方向（避让结果）
- loading / error
- 焦点归属与锚点记录

### 输出
- 打开 / 关闭事件：含关闭来源
- 内部交互事件：如点菜单项、提交轻量表单的数据
- 定位变化事件（可选，供外部感知避让结果）

### 受控 / 非受控
- 受控：open 由外部持有，组件只请求开 / 关；适合与其他状态联动
- 非受控：内部持有，点击锚点自管开合
- 混用会导致「点了不关」或「外部改了不响应」

### 异步与竞态
- 异步内容要处理加载 / 空 / 错误三态
- 竞态：快速切换锚点（如列表各行）时丢弃过期响应
- 打开即请求时，关闭后才到达的响应应丢弃

### 校验与错误
- 组件只负责呈现错误；校验规则由外部 / 表单层给出
- 含轻量表单时，校验失败阻止提交并聚焦首个错误字段
- 校验失败**不自动关闭**

### 回填与序列化
- 打开时初始数据由外部传入（如当前行的值）
- 关闭默认丢弃未提交内容；需要保留时由外部持有
- 提交数据结构由外部定义

## 无障碍
- 浮层 `role=dialog`（含交互）或普通语义；纯信息可用提示语义并关联锚点
- 锚点标注展开态与控件关系（`aria-expanded` / `aria-haspopup` / `aria-controls`）
- 含交互时焦点移入并可 Tab 循环，Esc 关闭且归还焦点
- 悬停型不可作为唯一入口，键盘 / 触摸需可达
- 禁止无替代的 `outline: none`

---

## 常见误用
- 用悬停触发却内含按钮 → 鼠标移出即消失，点不到
- 承载大段内容或复杂表单 → 过挤，应抽屉 / 模态
- 移动端依赖 hover → 触摸设备无法触发
- 多个气泡互相遮挡，未限制「同时只开一个」
- 滚动容器内位置失准，浮层漂离锚点
- 点外部关闭把浮层内部点击误判为外部 → 一交互就关

## 边界与代价
- 内容超过少量几行：改用抽屉 / 模态
- 含交互内容时不要用悬停触发（会闪没）
- 需处理屏幕边缘自动翻转，否则超出视口不可见
- 与**文字提示**的关键区别：是否含交互；含交互即本组件，不可交互即文字提示
- 与**下拉面板**的区别：本组件更轻、可任意方位锚定；面板更接近菜单 / 操作列
