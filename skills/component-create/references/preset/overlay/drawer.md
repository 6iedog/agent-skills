# 抽屉

从**侧边滑入**的面板，承载详情或一段流程，通常不强制阻塞。

## 角色与边界

- **是什么**：从视口边缘滑入的面板，覆盖部分主内容，保留或半保留页面上下文。
- **解决什么**：内容较多、但不必离开当前列表 / 页面语境——查看详情、编辑表单、筛选面板、多步流程。
- **不解决什么**：
  - 一句确认 / 极简决策 → 确认弹窗
  - 必须完全打断、专注完成 → 模态对话框
  - 内容极少的一小段说明 → 气泡卡片 / 文字提示
  - 页面级长内容 → 独立页 / 全屏层
- **什么时候不用**：
  - 需要铺满屏幕展示大量内容 → 独立页
  - 用户需在两个大步之间深度对照 → 独立页
  - 移动端用很窄的侧抽屉 → 挤没内容，应用底部半屏

## UI

### 结构解剖
- **遮罩层**：可有可无（取决于是否阻塞）
- **容器**：贴边滑入的面板
- **头部**：标题 + 关闭入口；可含返回 / 步骤指示
- **主体**：内容区，通常自身内滚
- **底部操作区**：固定操作条（保存 / 提交 / 取消），长内容时悬于底部
- **边缘把手**（可选）：用于拖拽调整宽度
- **层级指示**（多级时）：面包屑 / 返回上一级

### 尺寸与外观变体
- 方向：右 / 左 / 上 / 下（右侧最常见）
- 尺寸：窄（筛选）/ 中 / 宽 / 自适应
- 阻塞性：带遮罩（阻塞）/ 无遮罩（可与主内容并行操作）
- 层级：单层 / 多级嵌套
- 宽度可调：允许拖拽调整
- 移动端：全屏 / 底部半屏

### 视觉状态（逐条）
| 状态 | 遮罩 | 容器 / 内容 | 主按钮 |
|---|---|---|---|
| default | 若有则压暗 | 贴边静置，带阴影分隔 | 常态 |
| entering | 渐显 | 从对应边缘滑入 | — |
| closing | 渐隐 | 向对应边缘滑出 | — |
| 关闭按钮 hover | — | 关闭按钮背景微亮 | — |
| 关闭按钮 focus-visible | — | 明显焦点环 | — |
| loading | — | 主体骨架 / spinner | 提交中 spinner + 禁用 |
| error | — | 错误提示，不关闭 | 可重试 |
| disabled | — | — | 降透明、不可点 |
| 拖拽调整中（可选） | — | 显示分隔线 / 光标变化 | — |

### 布局与对齐 / 定位
- 贴边定位，从指定方向滑入；其余各边贴齐或受最大尺寸约束
- 宽度用「建议宽 + 最大值」双约束，避免超宽挤没主内容
- 主体内滚，头 / 尾固定；滚动条只在主体出现
- 单侧留出主内容可见区域，让用户感知「未离开当前页面」
- 宽度接近全屏时，应改独立页

### 移动端
- 常见退化为**全屏**或**底部半屏**
- 底部半屏支持**下滑关闭**，并有显式关闭入口
- 触摸目标 ≥ 44×44；底部操作条常固定，防被键盘遮挡
- 软键盘弹起：容器上移或输入框滚入视野，底部操作条不被顶出

## 交互

### 触发与开合
- 由列表项点击、工具栏按钮、菜单项触发
- 打开时把当前对象 / 上下文作为输入传入
- 可与主内容并存：无遮罩时用户仍能操作主界面（视阻塞策略）

### 关闭行为
| 关闭来源 | 是否默认可关 | 说明 |
|---|---|---|
| Esc | 是 | 阻塞型默认支持 |
| 点击遮罩 | 视场景 | 有遮罩时通常可点；表单型常关闭此项防丢数据 |
| 关闭按钮 | 是 | 应有显式入口 |
| 操作完成 | 是 | 保存 / 提交成功后由外部关闭 |
| 下滑关闭 | 移动端 | 仅底部半屏，需有显式按钮兜底 |

- 存在未保存内容时，任意外部关闭先**二次确认**（指向确认弹窗）
- 多级抽屉：关闭子级返回父级，而非直接关闭整组

### 键盘
| 键 | 行为 |
|---|---|
| Tab | 在抽屉内循环，不逃逸到背景 |
| Shift+Tab | 反向循环 |
| Esc | 关闭当前层；多级时先关最上层 |
| Enter | 触发表单提交 / 激活聚焦控件 |
| ← / → | 多级导航时可返回 / 前进（若实现） |

- 打开时初始焦点：表单给第一个输入；详情型给关闭按钮或容器
- 关闭后焦点**归还触发元素**

### 指针与手势
- 桌面：点击遮罩关闭（若允许）；拖拽边缘调整宽度（若支持）
- 移动端：底部半屏支持下滑关闭；区分「点按」与「拖拽结束」
- 边缘拖拽调整宽度时不得触发关闭

### 焦点管理
- 打开前记录触发元素
- 打开后焦点移入抽屉，激活焦点陷阱（阻塞型必须；非阻塞型按策略）
- 多级：进入子级时焦点移入子级，返回时回到父级原位置
- 关闭后焦点归还；背景内容不可聚焦

### 动画与过渡
- 从对应边缘滑入 / 滑出，约 200–300ms，带缓动
- 遮罩（若有）同步淡入淡出
- 多级切换：父级轻微位移 / 变暗，子级滑入
- 减少动态偏好时退化为淡入淡出或直接切换

### 反馈
- 提交中：底部主按钮 loading + 禁用，禁止重复提交
- 成功：由外部关闭或切换为成功态
- 失败：**不关闭**，主体内显示错误并保留已填内容

### 边界交互
- **多层叠加**：多级抽屉须明确层级视觉与关闭顺序；> 2 层应改独立页
- **滚动锁定**：有遮罩且阻塞时锁 body 滚动；无遮罩型不锁，允许主内容滚动
- **多次打开**：同一实例复用要重置内部状态与滚动位置
- 与主内容联动：列表项切换时更新抽屉内容，而非叠开新抽屉

## 数据流

### 输入
- 当前对象 / 上下文（详情型：记录 id 或对象；表单型：回填值）
- 方向、宽度 / 高度、尺寸
- 是否显示遮罩、遮罩点击是否关闭
- 头部 / 底部操作区配置
- 层级结构（多级时）

### 内部状态
- open（本层及父级栈）
- loading / submitting
- 主体滚动位置
- 拖拽调整中的宽度（若支持）
- 焦点记录

### 输出
- **提交 / 保存事件**：含收集的数据
- 取消 / 关闭事件：含关闭来源与当前层级
- 层级导航事件（进入 / 返回）

### 受控 / 非受控
- 受控：open 与层级栈由外部持有，组件只请求开 / 关 / 跳转
- 非受控：内部持有当前层级
- 多级场景强烈建议**外部持有层级栈**，避免状态错乱

### 异步与竞态
- 详情型：打开即拉数据，显示加载态；失败显示错误 + 重试
- 提交中禁止关闭；失败不关闭
- 竞态：快速切换不同对象时丢弃过期响应，避免「点 A 显示 B」

### 校验与错误
- 校验在表单层，本层呈现错误态
- 校验失败阻止关闭（或关闭前确认）并聚焦首个错误字段
- 加载失败与提交失败要区分呈现

### 回填与序列化
- 打开时按当前对象拉取 / 注入初始数据
- 关闭默认丢弃；需要草稿时由外部持有
- 多级：进入子级时携带父级上下文；返回时保留父级已填内容

## 无障碍
- 容器 `role=dialog`（阻塞型配 `aria-modal=true`）；非阻塞型可视为补充分区
- 标题用 `aria-labelledby` 关联，无可见标题用 `aria-label`
- 焦点陷阱（阻塞型必须）、Esc 可达、关闭后焦点归还
- 多级抽屉用层级标识让读屏用户知晓当前位置
- 禁止无替代的 `outline: none`

---

## 常见误用
- 抽屉套抽屉再套抽屉 → 层级过深
- 极短内容也开抽屉 → 过重，气泡卡片即可
- 移动端用很宽的侧抽屉 → 挤没内容，应用底部半屏
- 未保存可直接关
- 完全并行却仍需「专注」→ 该用模态

## 边界与代价
- 多级抽屉 > 2 层：应改独立页
- 宽度接近全屏：不如直接用页面
- 有未保存内容时关闭要二次确认
- 无遮罩却锁滚动 / 有遮罩却不锁，都会造成体验割裂
- 与**模态对话框**的区别：抽屉保留页面语境的「滑入感」，适合详情 / 流程；模态适合必须打断的短任务
