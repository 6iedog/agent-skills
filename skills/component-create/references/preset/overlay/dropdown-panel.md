# 下拉面板

**锚定式浮层**，由一个触发点展开一组**操作命令或导航项**，选中即触发动作，而不是把值回填到触发器。

## 角色与边界

- **是什么**：绑定在触发器旁的浮层，内容是「可执行的动作 / 可跳转的目标」列表，可分组、可分多级。
- **解决什么**：一个触发点收纳多个操作，避免主界面被按钮铺满——表格行「更多」、工具栏溢出、右键上下文。
- **不解决什么**：
  - 不承载「选中值回填到触发器」的语义（触发器上不显示所选内容）→ 单选 / 多选下拉
  - 不承载表单字段（输入框、开关、日期选择）→ 气泡卡片 / 内联表单
  - 不需要用户确认即时执行的危险操作 → 仍需二次确认弹窗
  - 内容长篇、需要停留阅读 → 抽屉 / 模态框
- **什么时候不用**：
  - 只有一两个操作 → 直接平铺按钮，不必藏进菜单
  - 选项数量巨大且需检索 → 下拉选择器 / 命令面板
  - 需要用户「看到一个值」再决定 → 下拉选择，而非操作菜单

## UI

### 结构解剖
- **触发器**：按钮 / 图标按钮 / 文本 / 表格行内的「更多」；展开态常伴随箭头翻转或高亮
- **面板**：锚定的浮层容器，含列表
- **菜单项（行）**：左侧图标（可选）+ 主标签 + 右侧快捷键提示 / 子菜单箭头
- **分组标题**：把项按类别归组的小标题
- **分隔线**：分组之间或危险区块之前的分隔
- **子菜单**：某项展开的下一级面板
- **危险项**：删除、移除等破坏性操作的项，视觉区隔
- **空 / 加载位**：项为异步得到时的占位

### 尺寸与外观变体
- 尺寸：紧凑（密集操作）/ 常规；影响行高、内边距、字号
- 外观：带边框 / 阴影浮层；浅色 / 深色
- 触发器形态：按钮 / 图标按钮 / 纯文本 / 表格行内；对齐：面板与触发器哪条边对齐（左 / 右 / 居中）
- 是否含图标、快捷键提示、子菜单箭头

### 视觉状态（逐条）
| 状态 | 触发器 | 面板 / 菜单项 |
|---|---|---|
| default | 常态按钮 / 图标 | 面板隐藏 |
| hover | 触发器背景微亮 | 悬停项背景微亮 |
| focus-visible | 明显焦点环 | 键盘高亮项与 hover 同样明显 |
| open | 触发器激活态（按下 / 高亮）+ 箭头翻转 | 面板出现 |
| active（按下项） | — | 项背景加深 |
| disabled | 触发器禁用则打不开 | 该项降透明、不可点、无高亮 |
| loading | 可显示 spinner | 面板内骨架 / spinner |
| empty | — | 面板内空状态文案 |
| danger | — | 危险项文字用语义危险色 |

- 键盘高亮与鼠标悬停必须是**同一套**视觉，避免「键盘走到的项」看不出来。
- 危险项与普通项必须**视觉区隔**（颜色或分隔线），防止误点。

### 布局与对齐 / 定位
- 面板锚定触发器，边界对齐方式随触发器类型选择（工具栏溢出菜单常右对齐，普通按钮常左对齐）
- **靠近视口边缘自动避让**：下方空间不足则向上翻转，左右不足则调整对齐边
- 子菜单在父项旁侧展开，空间不足时翻转到另一侧
- 面板有最大高度，项多时**列表内滚动**（不撑满整屏）
- **表格行 / 工具栏内使用**：面板脱离行容器（避免被行裁剪 / 滚动容器裁掉）；行滚动时面板跟随或关闭；行内触发器靠右时面板右对齐，防止出屏

### 移动端
- 桌面式锚定浮层在小屏体验差：改为**底部弹层 / 动作面板**从底部升起
- 触摸目标 ≥ 44×44，行高加大
- 危险项通常单独置于弹层顶部并加确认
- 长列表可滚动，必要时提供拖拽关闭

## 交互

### 触发与开合
- 打开：
  - 左键点击触发器
  - 键盘：聚焦触发器后 `Enter` / `Space` / `↓` / `↑`（`↓` 打开并聚焦首项，`↑` 打开并聚焦末项）
  - **右键上下文形态**：在目标区域右键（或长按）弹出，面板锚定指针位置
  - 悬停触发（较少用）：移入展开、移出收起，延迟防抖；一般只用于菜单栏一级
- 关闭：再次点击触发器、`Esc`、选中某项（当该项会关闭时）、点击外部、`Tab` 移出、窗口尺寸变化、滚动
- 面板自动避让视口边缘

### 关闭行为
- 点击外部任意处关闭
- `Esc` 关闭并**把焦点归还触发器**
- 点击会触发导航 / 动作的项：先执行动作再关闭
- 点击**不会**关闭的项（如切换开关类项）需明确设计为「保持打开」
- `Tab` 离开面板即关闭（菜单为临时浮层，不参与页面 Tab 序列）
- 页面失焦 / 切换标签页 → 关闭

### 键盘
| 键位 | 行为 |
|---|---|
| `Enter` / `Space` | 触发器上打开；面板内触发高亮项 |
| `↓` / `↑` | 打开菜单并聚焦首 / 末项；面板内上下移动高亮 |
| `Home` / `End` | 跳至首 / 末项 |
| 字母键 | **typeahead**：跳到以该字母开头的项，连续输入按前缀匹配 |
| `→` | 有子菜单时展开子菜单 |
| `←` | 在子菜单内返回上一级 |
| `Esc` | 关闭当前层；在子菜单内先关子菜单 |
| `Tab` | 离开并关闭整个菜单 |
| 项内快捷键 | 若项标注了快捷键，在菜单外按下应能直接触发（由使用方实现） |

- 禁用项在键盘遍历中**跳过**（不停留高亮），或可停留但 `Enter` 无效——需二选一并在文档中说明。

### 指针与手势
- 移入项高亮；点击项执行
- 有子菜单的项：悬停或点击展开子菜单，指针移向子菜单时不能因「离开父项」而收起
- 移动端：点触发器 → 底部动作面板；点项执行或展开；点空白 / 拖拽关闭

### 焦点管理
- 打开：焦点进入面板（首个可选项，或按触发键决定首 / 末项）
- 关闭：焦点**归还触发器**，不得丢失到 body
- 子菜单展开：焦点可进入子菜单并可返回父级
- 右键上下文形态：关闭后焦点回到右键时的目标元素

### 动画与过渡
- 面板出现 / 消失：淡入淡出 + 与方位一致的轻微位移，约 100–200ms
- 子菜单展开：侧向位移
- 触发器箭头翻转
- 不引起布局抖动

### 反馈
- 选中项**短暂闪现**激活反馈后关闭（若有明显延迟）
- 异步项：打开时加载；失败显示错误 + 重试
- 危险项执行后由结果提示（消息条等）反馈，菜单本身不承担

### 边界交互
- 项数超过可视高度：列表内滚动，并对高亮项做**滚动定位**
- 面板贴近视口底 / 右：自动翻转或改对齐边
- 触发器在滚动容器中滚动出屏：关闭面板跟随
- 快速连点触发器：开合防抖，避免闪过
- 右键菜单：多处右键只保留一个，新右键替换旧的

## 数据流

### 输入
- **菜单数据**：项列表，每项含 `{ 标签, 图标?, 快捷键?, 是否禁用?, 危险?, 子菜单? }`，并支持分组与分隔
- 触发器配置：尺寸、图标、标题、对齐方式、触发方式
- 状态：加载 / 空 / 错误；受控开关（可选）由外部控制开合

### 内部状态
- open（开合）
- 高亮索引（键盘导航）
- 展开的子菜单层级
- typeahead 缓冲（连续字符匹配）
- 列表滚动位置

### 输出
- **选择事件**：被触发项的标识（不是值回填，而是「选了哪个动作」）
- open / close 事件（供埋点或联动）
- 右键形态下附带触发上下文（在哪一行 / 哪个元素上右键）

### 受控 / 非受控
- 非受控：内部自管开合
- 受控：开合由外部持有，组件只在事件里抛出「请求打开 / 关闭」
- **二选一必须明确**，混用会出现「点了不开」或「关闭无效」

### 异步与竞态
- 异步菜单项（如权限过滤后的操作）需处理加载 / 空 / 错误三态
- **竞态**：后发请求先返回时丢弃过期结果
- 打开即请求的场景要有 loading，避免空面板闪一下

### 校验与错误
- 组件不做业务校验；但**禁用逻辑**（因权限 / 状态不可用的项）应在此层体现为 `disabled`
- 危险项可在项内标注，但二次确认由确认弹窗承担

### 回填与序列化
- 菜单**不涉及值回填**（这与下拉选择的关键区别）
- 若某些项承载「切换某状态」，其当前状态可体现在项上（勾选标记 / 文案），但仍不是表单值

## 无障碍
- 触发器：`button` + `aria-haspopup="menu"` + `aria-expanded`
- 面板：`menu` 角色；项 `menuitem`，子菜单父项 `menuitem` + `aria-haspopup`
- 分组标题、分隔线用对应角色表达，避免被当作可选项
- 禁用项标 `aria-disabled`
- 全键盘可达：`↑↓` 移动、`Enter` 触发、`Esc` 关闭、`←→` 进出子菜单
- 焦点必须被正确管理（进入面板、归还触发器），否则屏幕阅读器用户失焦
- 危险项语义可由标签文字本身表达（如「删除」），不依赖颜色

---

## 常见误用
- 把表单字段（输入框 / 开关）塞进操作菜单 → 语义错误，应用下拉选择或气泡卡片
- 危险操作与普通操作混排且无区隔 → 误点
- 多级子菜单层级过深（> 2 级）→ 难导航，应收敛
- 无键盘导航 / 焦点不归还触发器 → 键盘用户不可用
- 只有一两个操作也做成菜单 → 多一次点击，直接平铺按钮
- 触发器上试图显示「已选值」→ 混淆了菜单与下拉选择
- 在可滚动表格行内直接用锚定面板但未脱离裁剪容器 → 面板被裁掉

## 边界与代价
- 菜单**不承载选中回填语义**；一旦需要「显示选中值」应换下拉选择
- 层级 > 2 级：难用，尽量收敛
- 危险项必须与普通项**视觉区隔**（分隔线 / 危险色）
- **必须**支持 `↑↓` 移动、`Enter` 触发、`Esc` 关闭且焦点归还触发器
- 表格行 / 工具栏内使用必须处理容器裁剪与滚动定位，否则面板显示异常
- 移动端应换底部动作面板，照搬桌面锚定浮层会很难点
