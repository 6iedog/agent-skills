# 固钉

把某个元素**钉在视口内固定位置**：滚动超过阈值后它固定不动，容器滚出后按边界解除。

## 角色与边界

- **是什么**：包住目标元素的容器，当页面 / 滚动容器滚过阈值时，使目标固定在视口某偏移处，直到父容器滚出边界才释放。
- **解决什么**：让某个元素（工具条、表头、侧边操作区、目录）在滚动较长内容时保持可见，而无需改动整页骨架。
- **不解决什么**：
  - 不解决「整页固定顶栏 / 侧栏」 → 布局容器
  - 不解决「元素本来就在固定区里」 → 直接放在固定容器
  - 不解决「横向滚动时钉住某列」 → 表格的列固定能力
  - 不解决「仅仅想让它 sticky 到父容器」的纯样式需求 → 可优先用原生粘性定位
- **什么时候不用**：能用原生**粘性定位**满足（元素粘在最近的滚动祖先内）→ 优先用它，无需本组件；目标本就在固定骨架里 → 不必再钉。

---

## UI

### 结构解剖
- **占位元素**：原位置保留的空白，防止元素固定后内容跳动
- **目标元素**：被固定的内容本体
- **固定容器**：承载目标并施加固定定位
- **偏移量**：固定时距视口某边的距离（常等于固定顶栏高度）

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 固定边 | 顶部 / 底部 | 常见为顶部固定 |
| 触发方式 | 滚动过阈值后固定 / 始终固定 | 常为前者 |
| 阈值 | 距顶某距离触发 | 触发点 |
| 偏移 | 固定后距视口边的距离 | 需考虑已有固定顶栏 |
| 边界容器 | 无（跟随到底）/ 有（父容器滚出即释放） | 决定何时解除固定 |
| 占位 | 保留 / 不保留 | 不保留会导致内容跳动 |
| 与原生粘性定位的关系 | 替代 / 补充 | 粘性定位可行时优先原生 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| normal（未触发） | 元素在文档流原位，随页面滚动 |
| pinned（已固定） | 元素脱离文档流贴住视口某边 |
| transition（固定瞬间） | 由原位切换到固定的瞬间，可能出现跳变需抑制 |
| unpinned（解除） | 父容器滚出边界 / 回到阈值上方，恢复文档流 |
| 固定中加阴影 | 固定后常加阴影 / 底色以区别于内容（可选） |

- 固定与解除的瞬间**不得引起内容跳动**，占位是必需品。

### 布局与对齐
- 固定后的**偏移要叠加已有固定区高度**：若页面已有固定顶栏，固钉的偏移不能是 0，否则被压在顶栏下。
- **宽度要处理**：元素脱离文档流后宽度可能塌缩或拉满，需锁定其原宽度以保持对齐。
- **边界容器**：若指定了父容器，父容器底部滚过时固钉解除，避免钉到下一个区块上面。
- 占位元素高度应与目标一致，解除时才不跳动。

### 移动端
- 移动端视口高度小，固定元素更易遮挡内容 → 固定区要更矮或可收起。
- 固定偏移要避让系统安全区（刘海 / 手势条）。
- 与其他固定元素（顶栏、底部操作栏）叠加时，需明确层级，避免两层固定互相遮挡。
- 软键盘弹出时视口高度变化，固定元素位置需重新计算，不能停在键盘之下。

## 交互

### 核心行为
- 页面 / 容器滚动超过阈值 → 固定；回到阈值以上或父容器滚出 → 解除。
- 阈值与偏移由配置给出，可随视口尺寸变化重算。
- 是否在固定后改变外观（加阴影）由使用方决定。

### 指针与手势
- 固钉本身不响应指针；被固定的内容若含交互，交互随元素一起保持可用。
- 触摸端滚动页面即触发固定 / 解除，无特殊手势。

### 键盘
| 场景 | 行为 |
|---|---|
| 固钉容器 | 不进入键盘序列 |
| 目标内可聚焦元素 | 固定 / 解除时仍可聚焦；聚焦时不得被固定元素遮挡 |

- **聚焦元素必须可见**：键盘滚动到被固定区遮挡的元素时，浏览器滚动应与固钉配合，避免焦点被盖住。

### 焦点管理
- 固定 / 解除不改变焦点位置，也不夺焦。
- 固定元素内可聚焦元素保持原有焦点顺序。

### 动画与过渡
- 固定 / 解除本身通常瞬时；外观变化（如阴影）可用短过渡。
- 避免固定切换时元素产生位移抖动：切换瞬间的定位计算要连贯，必要时对齐元素的固定前后坐标。

### 反馈
- 固定后通过外观变化（阴影 / 底边线）传达「已贴住」，帮助用户区分固定与内容。

### 边界交互
- 窗口尺寸变化 → 重新计算阈值、偏移与宽度。
- 内容高度变化（异步加载）→ 重新评估固定时机与占位高度。
- 页面存在多个固钉 → 层级与偏移需协调，避免互相遮挡。
- 滚动容器非视口时，以该滚动容器的边界为基准。

## 数据流

### 输入
- 触发阈值、固定边、偏移量、边界容器引用、是否保留占位、目标宽度。
- 当前是否处于某固定区之下的偏移补偿值（如顶栏高度）。

### 内部状态
- pinned（是否已固定）。
- 当前生效的偏移与宽度（经测量得出）。

### 输出
- 固定 / 解除事件（供埋点或联动，可选）。
- 不携带业务表单值。

### 受控 / 非受控
- 默认非受控：内部按滚动位置自行判断。
- 若需外部强制显隐，可提供受控开关，此时内部不再自行判断。

### 异步与竞态
- 滚动监听需节流 / 合并，避免高频计算。
- 测量（偏移、宽度）在布局变化后需重新执行；异步内容加载后也要重测，否则固钉宽度 / 位置错误。
- 阈值附近来回滚动可能反复切换 → 需保证切换稳定，不抖动。

### 校验与错误
- 无校验；属定位容器。

### 回填与序列化
- 无值概念；阈值、偏移等配置可来自数据，变化时同步刷新。

## 无障碍
- 固钉是**纯视觉固定**，应从可访问树中作为中性容器，不额外朗读。
- **不得因固定而遮挡聚焦元素**：键盘滚动到被固定区盖住的元素时，必须能露出（滚动补偿）。
- 固定 / 解除不改变阅读与焦点顺序。
- 固定元素若含交互，需保持全键盘可达与焦点可见。
- 移动端固定元素要避让安全区，否则内部按钮可能不可点。

---

## 常见误用
- 无占位元素 → 固定瞬间下方内容跳动。
- 偏移不含已有固定顶栏高度 → 被压在顶栏下面。
- 已知可用原生粘性定位却仍上本组件 → 多余复杂度。
- 固定后不锁宽度 → 元素拉满或塌缩，与页面不对齐。
- 不设边界容器 → 钉到不该钉的后续区块上。
- 无节流的滚动监听 → 滚动卡顿。
- 多个固钉互不协调 → 叠加遮挡。
- 固定区盖住聚焦元素 → 键盘用户看不到所在位置。

## 边界与代价
- **占位是必需品**，否则固定时布局跳动。
- 偏移必须叠加已有固定区高度，否则被遮挡。
- 可用原生粘性定位时**优先原生**，本组件是补充而非默认。
- 滚动监听必须节流，否则影响滚动性能。
- 固定元素遮住聚焦内容是硬缺陷，必须有滚动补偿。
- 移动端必须避让安全区与软键盘带来的视口变化。
