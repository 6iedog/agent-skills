# 布局容器

负责**页面级骨架**的容器族：把页面分成头 / 侧 / 内容 / 底等区域，并决定谁固定、谁滚动、谁自适应。

## 角色与边界

- **是什么**：一组配合使用的结构容器（顶部区、侧边区、内容区、底部区、内容外壳），共同搭出页面的整体骨架。
- **解决什么**：整页的分区、固定顶栏 / 侧栏、以及**哪一块滚动**的归属问题。
- **不解决什么**：
  - 不解决「内容区内部的列对齐」 → 栅格
  - 不解决「一组元素的排列与间距」 → 弹性布局 / 间距组件
  - 不解决「可拖拽改宽度的分栏」 → 分隔面板
  - 不解决「滚动到阈值固定某个元素」 → 固钉
- **什么时候不用**：只是局部区域排版 → 弹性布局 / 栅格；页面本身由更外层的框架（如全局导航壳）提供骨架 → 本容器只用作内容外壳。

## UI

### 结构解剖
- **顶部区**：页头 / 顶栏，常固定、含标题与操作
- **侧边区**：左侧或右侧栏，常固定宽度，可折叠
- **内容区**：主体，承载页面内容，通常唯一滚动区
- **底部区**：页脚 / 底栏，可固定
- **内容外壳**：统一的内边距与最大宽度，包裹主体内容
- **分区空隙 / 背景**：区域间的分隔与层次（靠背景或间距）

### 尺寸与外观变体
| 轴 | 取值 | 说明 |
|---|---|---|
| 顶栏 | 无 / 固定 / 不固定 | 固定顶栏不随内容滚动 |
| 侧栏 | 无 / 左 / 右 / 双侧 | 位置与数量 |
| 侧栏行为 | 固定宽 / 可折叠 / 可拖拽 | 折叠是交互，拖拽属分隔面板 |
| 底部 | 无 / 固定 / 不固定 | 固定底栏常承载全局操作 |
| 滚动归属 | 内容区滚动 / 整页滚动 | 核心决策，影响固定落点 |
| 内容外壳 | 有 / 无 | 控制内边距与最大宽度 |
| 背景层次 | 同色 / 区分 | 用背景区分顶栏 / 侧栏与内容 |

### 视觉状态（逐条）
| 状态 | 表现 |
|---|---|
| default | 各区域按配置就位 |
| 侧栏折叠 | 侧栏宽度收窄或隐藏，内容区随之变宽（需过渡） |
| 顶栏滚动变化 | 滚动时是否加阴影 / 变底色（配合滚动状态） |
| 内容过长 | 由既定滚动区滚动，固定区不动 |
| 窄屏收起 | 侧栏收起为抽屉或图标栏 |

- 布局容器自身无 hover / focus / disabled；交互来自其内部子组件（折叠按钮等）。

### 布局与对齐
- **滚动归属必须唯一且明确**：要么整页滚动、要么内容区滚动，不要两者同时，否则出现双滚动条与固定失效。
- **固定顶栏 / 侧栏要留空间**：内容区需留出与固定区等高的偏移，否则内容被压在顶栏下。
- 侧栏宽度由设计体系给定；可拖拽时另见分隔面板。
- 内容外壳统一内边距与最大宽度，保证不同页面主体左右一致。
- 分区背景层次要克制，通常只区分顶栏 / 侧栏与内容两层。

### 移动端
- 侧栏在窄屏收起为**抽屉**（从侧滑入）或图标栏，不长期占宽。
- 固定顶栏 / 底栏要避让系统安全区（刘海、手势条）。
- 移动端优先**整页滚动**，减少嵌套滚动带来的手势冲突。
- 触摸端折叠 / 展开入口 ≥ 44×44。

## 交互

### 核心行为
- 侧栏折叠 / 展开：切换侧栏显隐与内容区的宽窄。
- 抽屉式侧栏：窄屏从侧边滑入、点遮罩或关闭键收起。
- 顶栏滚动响应：滚动过阈值后加阴影 / 变底色（可选，属滚动状态联动）。

### 选择 / 状态行为
- 布局本身无选中概念；导航高亮等属于导航组件。

### 指针与手势
- 抽屉式侧栏：从边缘滑入、点遮罩关闭；可支持边缘滑动唤出（谨慎，易与系统手势冲突）。
- 折叠手柄点击即切换；可拖拽改宽属分隔面板的能力。

### 键盘
| 键位 | 行为 |
|---|---|
| `Tab` | 按顺序在顶栏、侧栏、内容、底栏间移动焦点 |
| `Esc` | 抽屉式侧栏打开时关闭，焦点回到触发按钮 |
| 折叠按钮 | `Enter` / `Space` 切换展开 / 收起 |

- **地标间的跳转**：浏览器支持在页面地标（head / nav / main 等）间跳转，骨架容器应使用正确区域语义以受益于此。
- 键盘用户的焦点顺序应为：顶栏 → 侧栏 → 内容 → 底栏，与视觉顺序一致。

### 焦点管理
- 抽屉式侧栏打开时应把焦点移入侧栏，关闭后回到触发按钮。
- 固定区不劫持焦点；内容区滚动时不改变焦点位置。
- 侧栏折叠后其中元素应移出可访问序列，避免「Tab 到不可见内容」。

### 动画与过渡
- 侧栏折叠 / 展开：宽度或位移过渡，约 150–300ms，内容区同步让位。
- 抽屉滑入 / 滑出同侧栏过渡。
- 顶栏滚动态样式变化用短过渡，避免闪烁。

### 反馈
- 折叠 / 展开的视觉变化即反馈；无独立提示。

### 边界交互
- 窗口尺寸跨过断点时，侧栏在「常驻」与「抽屉」间切换，需平滑且不丢状态。
- 内容超出固定区高度 → 由滚动区处理，固定区不跟随。
- 嵌套布局容器时滚动归属会打架，应避免深层嵌套。

## 数据流

### 输入
- 结构配置：是否顶栏 / 侧栏 / 底栏及其位置、固定与否、滚动归属。
- 侧栏状态：展开 / 折叠（初始值与是否外部控制）。
- 内容外壳的内边距与最大宽度。
- 断点定义（决定侧栏何时收起）。

### 内部状态
- 侧栏展开 / 折叠（非受控时）。
- 抽屉开合（窄屏）。
- 滚动状态（顶栏是否已滚过阈值）。

### 输出
- 侧栏折叠 / 展开事件（供持久化「用户偏好」与外部联动）。
- 滚动状态变化事件（可选）。
- 不携带业务表单值。

### 受控 / 非受控
- 侧栏折叠态默认非受控（内部自管）；需要外部统一控制（如记住用户偏好由外层管理）时受控。
- 抽屉开合通常内部自管，触发来自外部按钮。

### 异步与竞态
- 无业务异步；滚动状态计算需节流。
- 响应式断点切换与用户手动折叠可能冲突：断点切换后应尊重用户意图并保持可预期。

### 校验与错误
- 无校验；属结构容器。

### 回填与序列化
- 侧栏折叠偏好应可持久化，回填后保持用户上次状态。
- 断点变化时，回填的偏好需与当前断点兼容（窄屏强制抽屉）。

## 无障碍
- 用正确的**区域语义**（banner / navigation / main / complementary / contentinfo 等等价语义）标注头、侧、内容、底，使辅助技术可在区域间跳转。
- 一个页面**只有一个主内容区域**；其余归为主内容的补充或导航。
- 抽屉 / 折叠侧栏：打开移入焦点、关闭回到触发；展开 / 收起的可访问状态同步。
- 折叠隐藏的侧栏内容需移出可访问序列。
- 移动端固定顶 / 底栏不得遮挡聚焦元素（聚焦时需滚动到可视区）。
- 键盘焦点顺序与视觉顺序一致。

---

## 常见误用
- 固定顶栏却不给内容区留偏移 → 内容被盖住。
- 同时整页滚动与内容区滚动 → 双滚动条、固定失效。
- 侧栏折叠后元素仍可 Tab 到达 → 焦点跑到不可见区域。
- 固定区挡住聚焦元素 → 键盘 / 读屏用户看不到所在位置。
- 用布局容器承载导航高亮等业务状态 → 职责错位。
- 移动端侧栏仍常驻占宽 → 内容区被压缩。
- 深层嵌套布局容器 → 滚动归属与固定关系混乱。
- 顶栏 / 侧栏背景与内容无层次 → 分区不清，也难固定。

## 边界与代价
- **滚动归属必须唯一**，两者并存是硬缺陷。
- 固定区**必须**给内容留偏移，否则内容被遮。
- 区域语义不可省，否则辅助技术无法跳转。
- 隐藏侧栏必须移出可访问序列。
- 深层嵌套骨架会破坏固定与滚动关系。
- 移动端固定区必须避让安全区，否则按钮不可点。
