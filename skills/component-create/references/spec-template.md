# 规格文档模板（强制七段）

产出**约束描述**，不写实现代码。样式值指向样式源，不复制、不新造。

## 1 角色定义（含「不解决什么」）

- 它是什么、解决什么问题。
- **「不解决什么」必须写**：不写边界，模型会在不该用它的时候用它。

## 2 使用流程

从用户视角走一遍：看到 → 加载 / 空 / 错误 → 选择或输入 → 确认提交 → 取消返回。
把每步的界面对应写清。

## 3 Props 契约

| 名称 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| … | … | … | … | 影响什么行为 |

- 默认值尽量指向样式源或既有约定，不凭空定。
- 变体轴（如 size / tone / multiple）逐条列出，说明每轴影响什么。

## 4 状态全枚举

逐条列出，**disabled 与 readonly 分别定义**：

default / hover / focus-visible / active / **disabled** / **readonly** / loading / error / empty

- disabled：不可交互、不可提交、不进表单值。
- readonly：可读、可聚焦，值照常提交。

## 5 键盘与无障碍

- 键盘可达、focus-visible 可见（禁止无替代的 `outline: none`）。
- 键位：Enter / Space 激活，Esc 关闭，列表类方向键移动。
- 图标按钮必须有可访问名称（`aria-label` 等）。
- 移动端触摸目标 ≥ 44×44。

## 6 Do & Don't

| Do | Don't |
|---|---|
| 该用它的时候 | 不该用它的时候 |
| 正确搭配 | 常见误用 |

把该组件**最常见的误用**写进 Don't（素材来自预设提示词）。

## 7 可扩展插槽

预留的扩展点：内容插槽、前缀 / 后缀、自定义渲染、事件钩子。
说明扩展点的**稳定契约**，避免使用方 hack。
