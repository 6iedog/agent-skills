# 微信读书播客文稿

## 一句话

微信读书把每集的 AI 文稿存在应用私有 LevelDB 里，**打开过该集「AI 文稿」页才会落库**；
本技能负责「触发落库 → 解析 → 按集导出带时间戳的 md」。

**节目是输入，不是本技能的属性。**

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 导出一部有声书/播客的全部文稿，做成本地可读的 md | 只想看一两句话（直接截图/口述即可） |
| 按时间点取某集的一段文案（写稿、做笔记引用） | 下载音频文件（本技能只取文字） |
| 跨集搜索某句话出自哪一集哪一秒 | 需要联网公开 API（走缓存，不需要账号接口） |
| 定期补新更集的文稿 | 处理非微信读书的内容 |

## 铁律

1. **必须暂停播放再读文稿页**。AI 文稿页会跟随播放进度**自动滚动**，不暂停就会一直漂。
2. **播完一集会自动跳下一集**，文稿页也跟着换。每切一集都要重新核对标题并暂停。
3. **只读不写**。本技能只从设备拉缓存、只往本地写文件；不要在设备上删数据。
4. **没有对外动作**。导出到本地随便；上传、发布、发消息前必须先问用户。

## 前置条件

- 微信读书 Android 客户端已登录，且**要抓的专辑至少被打开过一次**
- adb 可连（模拟器 `adb connect 127.0.0.1:5555`，真机开 USB 调试）
- 设备**已 root**（缓存位于 `/data/data/com.tencent.weread/...`，需要 `su`）
- 本机有 `ffmpeg`（只有需要截图像素分析时才用，正常流程用不到）

## 流程

### 0 · 探路（第一次用某台设备时）

```bash
cd <skill>/scripts
python scan.py --list --pull          # 拉一份缓存，列出缓存里出现过的所有专辑
```

输出里 `播客=是` 的那行就是有声书/播客，记下 `albumId`。
**不确定 albumId 时**：在手机上打开那个节目播一下，再 `--pull` 一次，它就会出现在列表顶部附近。

### 1 · 建索引

```bash
python scan.py --album <albumId> --pull     # 拉最新缓存并建索引 index_<albumId>.json
```

输出会告诉你：集数、有文稿几集、缺哪几集、总字数。
若提示"按时长兜底匹配"，说明有几集的缓存 key 被 LevelDB 前缀压缩了，**抽查一下**这几集开头对不对（见 references 的坑）。

### 2 · 补缺（有缺集时）

```bash
python warm.py --index index_<albumId>.json --missing --wait 20 --pull
```

它会自动：回播放页 → 暂停 → 按标题跳到该集（远距离用「目录」面板）→ 打开 AI 文稿 → 等 N 秒 → 返回。
跑完 `--pull` 会重新拉缓存并刷新索引。**这是最慢的一步**，每集约 20–30 秒。

只想补指定几集：`--ep 5 --ep 65`；只跑一段：`--range 1 20`。

### 3 · 导出

```bash
python export.py --index index_<albumId>.json --out "D:/播客/<节目名>"
```

产物：

```
<输出目录>/
├── 目录.md                    表格：集数 | 标题 | 时长 | 字数 | 句数 | 时间轴 | 首句
├── 001_<标题>.md              每集一个，正文逐句带 [mm:ss]
└── 分集索引.csv               （加 --csv 才有）
```

`目录.md` 的标题列默认是指向单集文件的 md 链接；要纯文本表格加 `--no-links`。

### 4 · 按位置取用（不导出整套时）

```bash
python fetch.py --index index_X.json --ep 65                      # 整集
python fetch.py --index index_X.json --ep 5 --from 01:30          # 1:30 之后
python fetch.py --index index_X.json --ep 5 --from 01:00 --to 02:30
python fetch.py --index index_X.json --q 关键词 --from 06:50       # 按标题定位
python fetch.py --index index_X.json --find 关键词                 # 跨集：哪一集哪一秒
```

时间写法：`90` / `90s` / `1:30` / `01:30` / `1:02:03` 都行。

## 产物长什么样

单集文件：

```markdown
# 第 5 集 · 正心篇｜《实事求是》：为什么比"第一性原理"更高级？（三）

*时长 06:16 · 143 句 · 1525 字 · 毛选心法：中国人的破局思维与成事智慧*

[00:00] 第三是情绪化。
[00:03] 我们太容易被情绪带着跑，
[00:06] 焦虑的时候觉得天要塌了，
```

目录表格（列与 `分集索引.csv` 完全一致）：

```markdown
| 集数 | 标题 | 时长 | 字数 | 句数 | 时间轴 | 首句 |
| ---: | --- | ---: | ---: | ---: | :---: | --- |
| 1 | [序：为什么说…（一）](001_序：….md) | 09:30 | 2295 | 214 | 有 | 听众朋友们大家好，… |
```

## 脚本清单

| 脚本 | 作用 |
|---|---|
| `scripts/wb.py` | 公共库：adb、dump 重试、LevelDB 拉取、JSON 抽取、时间轴切片。不单独运行 |
| `scripts/scan.py` | 枚举专辑 / 建索引 `index_<albumId>.json` |
| `scripts/warm.py` | 触发缺集文稿生成（UI 自动化） |
| `scripts/export.py` | 导出 `目录.md` + 每集 md（+ 可选 csv） |
| `scripts/fetch.py` | 单集 / 时间段 / 跨集搜索取用 |

所有脚本都用 `WEREAD_WORK` 指定工作目录（默认 `~/.weread-podcast`），缓存快照存在 `<WEREAD_WORK>/ldb_*/main`。

## 出问题先看这里

- 拉不到缓存 / 权限拒绝 → 设备没 root，或 `su` 没授权
- `uiautomator dump` 报 `could not get idle state` 并拿到旧界面 → 播放器在动，**先暂停**，`wb.rdump` 会重试
- 某集文稿一直是空的 → 该集可能真的没有 AI 文稿（不是所有集都生成），或打开后没等够，把 `--wait` 调大重试
- 时间轴对不上（内容像别的书）→ 兜底匹配串台了，见 `references/cache-and-keys.md` 的「前缀压缩」

细节：`references/cache-and-keys.md`（缓存路径、key 结构、posInfo 语义、兜底匹配的坑）、
`references/android-ui.md`（adb/坐标/dump/剪贴板兜底方案）。
